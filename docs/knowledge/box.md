# 箱体理论（Darvas Box）+ 本项目箱体五阶段

## 1. 一句话

价格大部分时间在一个"箱子"里来回，箱顶和箱底是供需暂时平衡的价位；**突破箱顶跟进、跌回箱内认错**，箱子一层层往上叠就是趋势。
适用：个股 / 指数 / ETF 的**位置判断、挂价、止损、做 T 区间**。是本项目市况改造"位置层"的主骨架。

## 2. 核心概念

**达瓦斯原版（Nicolas Darvas, 1950s）**
- 箱顶：股价创新高后，**连续 3 天未再创新高** → 该高点定为箱顶。
- 箱底：箱顶确定后，股价回落的低点**连续 3 天未再创新低** → 定为箱底。
- 买入：放量**突破箱顶**；止损挂在**新箱子的箱底**下方（或原箱顶下方一点）。
- 只做创新高、放量的强势股（他叫"技术—基本面"：基本面选行业，箱体管时机）。
- 移动止损：新箱子形成后，止损上移到新箱底。

**通用箱体（交易区间）观念**
- 箱顶 = 阻力（供给集中），箱底 = 支撑（需求集中）；突破后**角色互换**（旧箱顶变新支撑）。
- 箱体越久、触碰次数越多，突破越有效（与威科夫"因果定律"同源）。
- 假突破：突破后快速回到箱内 → 反向信号（威科夫的 Spring / UTAD）。

## 3. 本项目口径（`scripts/quotes/indicators_db.py`）

- `box_hi / box_lo` = **近 20 日收盘价**最高 / 最低（用收盘不用最高最低，单日长影线不撑大箱子；10/18 牧原 38.30 针案）。
- `box_pos` = (收盘 − box_lo) / (box_hi − box_lo)，0 = 箱底，1 = 箱顶。
- `regime`：er20（效率比）< 阈值 + 箱宽 ≤ BOX_W + 上下沿各触碰 ≥ TOUCH 次 → "交易区间"；er20 高且均线多头 / 空头排列 → "上涨趋势 / 下跌趋势"；其他 = "无规则"。
- 止损候选 `stops.box_lo`、仓位 `size_1pct_10w`（1% 风险倒推股数）已在 indicators.jsonl 里。

**箱体五阶段（10/20 市况改造 R 系列，位置层）**
| 阶段 | 机械口径（初稿） | 典型应对 |
|---|---|---|
| 向下破位 | 收盘 < box_lo（前一日 box_lo）且 er20 走高 | 不接刀；等新箱底（3 日不创新低）|
| 下沿超跌反弹 | box_pos ≤ 0.2，且出现止跌（威科夫 SC/ST、长下影、量能衰竭）| 左侧轻仓试错，失效位 = 箱底 − 0.5×ATR |
| 中部震荡 | 0.2 < box_pos < 0.8 | 区间高抛低吸 / 做 T 最舒服；不追 |
| 上沿超涨回踩 | box_pos ≥ 0.8 未突破，或突破后 ≤2 日回到箱内 | 减仓 / 高抛；突破失败按 UTAD 处理 |
| 向上突破 | 收盘 > box_hi 且量 ≥ 20 日均量 ×1.5，次日不回箱 | 右侧跟进，止损 = 原箱顶下方 |

## 4. A 股适配与坑

- **涨跌停截断**：突破日常常直接涨停，"放量"口径要改成"换手率"或"封单额"；跌停破位同理。
- **20 日窗口对不同股性要调**：游资连板票 20 日箱子太大、意义弱；宽基 / 银行 20 日偏短。可按近 60 日振幅分位调整窗口（与做 T"参数按近 30 日振幅分布定"同一纪律）。
- **指数箱体与个股箱体共振**才可靠：个股向上突破但指数在"向下破位"阶段，突破失败率高。
- **除权**：indicators 已前复权；用原始价挂单时要换回（row_of 的 raw/c 比例）。

## 5. 在本项目里怎么用

- **02 市况**：多指数（上证 / 中证2000 / 创业板 / 恒生科技 / 纳指 ETF）各给一个五阶段标签，进事实包"位置表"（TODO 市况改造 R3）；市况结论必须和位置表多数方向一致，不一致要写理由（R1 evidence[]）。
- **04 选股**：右侧导师（R10 分时追击型）候选优先"向上突破"阶段；左侧低吸导师优先"下沿超跌反弹"。
- **06 挂价**：挂价 / cancel_below / stop_below 优先锚在 box_lo、box_hi、原箱顶，而不是固定百分比；与锚偏离闸（3%）配合时，箱体价位给出"这个偏离是不是已经跨过关键位"。
- **做 T**：中部震荡阶段 T 的高抛 / 低吸价按箱体内振幅中位定；进入"向上突破"阶段暂停高抛（防卖飞）。
- **07 复盘**：每笔亏损单标注买入时的阶段，统计"在上沿超涨回踩阶段买入"的亏损占比。

## 6. 局限与证伪

- 箱子画法有主观性（窗口、收盘 vs 影线），不同窗口给出不同结论 → 固定口径并版本化，改口径要回测对比。
- 强趋势里箱体信号很少（一直在突破），弱趋势里假突破频繁。
- 证伪：3 年全 A 回测五阶段之后 5 / 10 日收益分布，阶段间差异不显著就退回"描述语言"。
