# 威科夫（Wyckoff）方法

## 1. 一句话

价格由供求决定；大资金（"综合人" Composite Man）的建仓与出货会在**交易区间**里留下可识别的量价痕迹——先看区间在吸筹还是派发，再决定站哪边。
适用：个股 / 指数**底部、顶部**的阶段判断；"放量不涨 / 缩量回踩"这类量价语言的统一口径。不适用：消息驱动的一字板、流动性极差的小票。

## 2. 核心概念

**三大定律**
- **供求定律**：需求 > 供给 → 涨；反之跌。量价是供求的唯一可观测投影。
- **因果定律**：区间里积累的"因"（横盘时间与宽度）决定区间突破后的"果"（走多远）。传统用点数图横向计数估算目标。
- **努力与结果定律**：成交量 = 努力，价格位移 = 结果。两者背离是转折线索（放巨量但价格不走 = 有人在对面接 / 派）。

**综合人**：把市场上所有大资金想象成一个人，他要低价吸足筹码、拉升、高价派发。散户该做的是读懂他的动作，而不是猜消息。

**吸筹区间（Accumulation）五阶段**
| 阶段 | 事件 | 含义 |
|---|---|---|
| A 止跌 | PS 初步支撑 → **SC 恐慌抛售**（巨量长阴/长下影）→ AR 自动反弹 → ST 二次测试（缩量回到 SC 附近不破或小破） | 下跌被止住，SC 低点 + AR 高点框出区间 |
| B 筑因 | 区间内反复 ST，量逐步收敛 | 大资金在区间里吸筹，时间越长"因"越大 |
| C 测试 | **Spring 弹簧**（跌破区间下沿后迅速收回）/ Shakeout 震仓；随后低量 Test | 最后一次洗出浮筹；Spring 后缩量测试不破=供给枯竭 |
| D 走强 | **SOS 强势信号**（放量大阳穿越区间）→ LPS 最后支撑点（回踩缩量不破） | 需求占上风；LPS 是经典买点 |
| E 趋势 | 脱离区间（JAC 跳过小溪 → BU 回踩确认） | 上涨趋势展开 |

**派发区间（Distribution）**：镜像——PSY 初步供给 → **BC 抢购高潮** → AR 自动回落 → ST → **UTAD 上冲回落**（假突破）→ **SOW 弱势信号** → LPSY 最后供给点 → 下跌。

## 3. A 股适配与坑

- **T+1 + 涨跌停**：SC / BC 常以跌停打开、涨停炸板的形式出现；"一日 Spring"在 A 股常被涨跌停截断成两天，判定要用 2 日窗口。
- **题材股的区间很短**：游资票的"吸筹"可能只有 3~5 天，五阶段压缩；威科夫更适合**指数、权重、中军、ETF**，以及持有期 ≥5 天的导师。
- **量能口径**：A 股有明显的"节前缩量 / 指数成分调整放量"等制度性量能，判断"努力"前先剔除日历效应。
- **政策冲击**：政策底 / 国家队入场的巨量，形似 SC 但"因"来自场外，后续不一定走完 B~E。

## 4. 可机械化的判定（本项目数据）

数据：`downloads/market/<日>/kline_day.jsonl`（OHLCV）、`indicators.jsonl`（box_lo / box_hi / box_pos / regime / atr14_pct / er20）、分钟线 `kline_minute.jsonl`、3 秒盘口 `book_snap.jsonl`。

| 事件 | 机械口径（初稿，待回测定阈值） |
|---|---|
| SC | 当日跌幅 ≥ 1.5×ATR14、量 ≥ 20 日均量 ×2、收盘位于日内区间上半部（长下影）或次日不再创新低 |
| ST | SC 后 3~20 日内再次接近 SC 低点（±1×ATR），量 ≤ SC 日量 ×0.6 |
| Spring | 收盘价跌破 box_lo 后 ≤2 日内收回 box_lo 之上，且跌破日量不放大（≤20 日均量 ×1.2）|
| SOS | 收盘突破 box_hi、涨幅 ≥ 1×ATR14、量 ≥ 20 日均量 ×1.5 |
| LPS | SOS 后回踩，最低价不低于区间中轴（box_pos ≥ 0.5），回踩日量 ≤ SOS 日量 ×0.5 |
| 努力与结果背离 | 量 ≥ 均量 ×2 但 |涨跌幅| ≤ 0.3×ATR14（放量滞涨 / 放量不跌）|
| UTAD | 收盘站上 box_hi 后 ≤2 日内跌回区间且量放大 |

全部可由现有日线 + indicators 零 token 算出，适合做成事实包"量价事件"一节，而不是让模型自己看图。

## 5. 在本项目里怎么用

- **02 市况（位置层）**：与箱体五阶段配合——箱体给"在哪"，威科夫给"区间性质"（吸筹 / 派发 / 不明）。例：指数在 box 下沿 + 出现 SC/ST → "下沿超跌反弹"概率上调；在上沿出现放量滞涨 / UTAD → "上沿超涨回踩"概率上调。
- **04 选股**：持有期 ≥ 5 天的导师（暗里着火 / 梅月路 / 悟道 / 含笑）候选里，LPS / Spring 后 Test 优先；短线连板导师不用。
- **06 挂价与失效**：Spring 买点的失效位 = Spring 低点；LPS 买点失效位 = 区间中轴；比固定百分比止损更有依据。
- **07 复盘**：亏损单复盘时问一句"当时是否在派发区间里买（BC 后 / UTAD 后）"，把"买在派发区"作为可统计的错误类型。
- **做 T**：区间内（B 阶段）T 的胜率最高；进入 D/E 阶段后 T 容易卖飞（与牧原 / 中行振幅分布一起看）。

## 6. 局限与证伪

- 阶段标注**事后容易、事中难**：Spring 和真破位当天长得一样，只能等 1~2 日确认——机械口径必须带确认窗，不许用当日收盘后才知道的信息回填当日决策。
- "综合人"是拟人化隐喻，A 股题材资金是多方博弈，不存在单一意图。
- 证伪方式：对历史 3 年全 A 跑上表口径，统计 SOS / LPS / Spring 后 5 / 10 / 20 日收益分布与胜率，和随机日期对比；**跑不赢随机就降为纯描述语言，不进规则**。
