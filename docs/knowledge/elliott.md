# 波浪理论（Elliott Wave）

## 1. 一句话

市场情绪的涨落呈**5 浪推动 + 3 浪调整**的分形结构；三条铁律限制数浪，斐波那契比例给出回撤与目标的参考位。
适用：**指数级别的大位置判断**、目标位 / 失效位估算。在本项目里主观性最强、权重最低，主要当"情景假设生成器"。

## 2. 核心概念

**基本形态**
- 推动浪（Impulse）：1、2、3、4、5，其中 1/3/5 顺势，2/4 逆势调整；内部结构 5-3-5-3-5。
- 调整浪（Corrective）：A、B、C。
- 一个完整周期 = 8 浪（5 推动 + 3 调整），每一浪又由更低一级的浪构成（分形，级别从超级循环到微浪）。

**三条铁律**（违反即数浪错误）
1. 第 2 浪的回撤**不超过第 1 浪起点**（不回撤 100%）。
2. 第 3 浪**不能是 1、3、5 中最短的**一浪（通常最长、最强）。
3. 第 4 浪**不与第 1 浪价格区间重叠**（倾斜三角形例外）。

**常用指引（不是铁律）**
- 交替原则：2 浪与 4 浪形态交替（一个急跌 / 锯齿，一个横盘 / 平台）。
- 斐波那契比例：2 浪常回撤 1 浪的 50%~61.8%；3 浪常为 1 浪的 1.618 倍；4 浪常回撤 3 浪的 38.2%；5 浪常与 1 浪等长，或为 1~3 浪长度的 0.618。
- 延长浪：1、3、5 中通常只有一浪延长（A 股多为 3 浪延长）。
- 4 浪调整常回到更低一级第 4 浪的区域。

**调整浪类型**
| 类型 | 内部结构 | 特征 |
|---|---|---|
| 锯齿形 Zigzag | 5-3-5 | 急跌型，C 浪常 ≈ A 浪 |
| 平台形 Flat | 3-3-5 | 横盘型，B 浪接近或超过 A 浪起点 |
| 三角形 Triangle | 3-3-3-3-3 | 收敛，多见于 4 浪或 B 浪 |
| 复合调整 | W-X-Y 等 | 时间换空间 |

## 3. A 股适配与坑

- **政策市**：政策冲击常让浪形"断档"（直接跳到新结构），用政策节点重置数浪起点。
- **个股浪形不可靠**：题材股受资金和消息驱动，浪形基本无意义；只用于**指数和大市值 / 宽基 ETF**。
- 同一段走势可以有多种合规数法 → 必须同时写"首选数法 + 备选数法 + 各自的失效位"，否则不可证伪。

## 4. 可机械化的判定（本项目数据）

- 铁律可机械检查：给定一组摆动高低点（可用缠论"笔"或 ZigZag 指标提取），检查 2 浪不破 1 浪起点、3 浪非最短、4 浪不入 1 浪区间。
- 斐波那契位可机械计算：已知 1 浪 / 1~3 浪长度后，给出 2 浪 50 / 61.8% 回撤位、3 浪 1.618 目标、4 浪 38.2% 回撤位、5 浪等长目标。
- **数浪本身不机械化**（级别划分和起点选择是主观判断）；本项目只机械化"给定一种数法 → 算出参考价位 + 检查是否违反铁律"。
- 数据：指数日线（kline_day 的 sh000001 / sz399006 / sh000852 等）、`indicators.jsonl`。

## 5. 在本项目里怎么用

- **02 市况（预判层）**：对上证 / 创业板写"首选数法 + 备选数法"，各自给 1~3 日的路径情景与失效价位 → 转成"偏强 / 震荡 / 偏弱"概率的一个输入（不能单独决定结论）。
- **趋势天哥类导师**：他的语言里有"右侧大阳线之后再提仓位""调整到位"等，可用波浪的"调整浪是否走完（C 浪 ≈ A 浪 / 三角形收敛）"给他的"等待条件"一个价格化的锚。
- **07 复盘**：只复盘"数法的失效位是否被触发、触发后是否及时切换到备选"，不复盘"数对没数对"。

## 6. 局限与证伪

- 事后总能数对、事中多解，是最常被批评为不可证伪的理论。
- 本项目的使用纪律：**每次使用必须写失效价位**；失效即切换备选，不许事后改数。
- 证伪：统计 02 里写过的波浪情景在 1~3 日内的命中率，与不带波浪情景的 02 结论对比；无增益就从 02 证据表里移除。
