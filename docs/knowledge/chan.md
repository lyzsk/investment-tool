# 缠论（缠中说禅技术分析理论）

## 1. 一句话

把 K 线按严格的几何规则逐级归并成"分型 → 笔 → 线段 → 中枢 → 走势类型"，任何走势都是"趋势或盘整"，用**背驰**判断走势结束，用**三类买卖点**定位进出。
适用：**多级别结构定位**（日线在哪一段、30 分钟在哪一段）、买卖点复核。在本项目只做**辅助校验**，不做主信号（原因见 §6）。

## 2. 核心概念

**K 线包含处理**：相邻两根 K 线一根的高低点完全包含另一根时，按当前方向合并（向上取高高、向下取低低），处理完后才能找分型。

**分型**
- 顶分型：连续三根（处理后）K 线，中间一根的高点最高、低点也最高。
- 底分型：中间一根低点最低、高点也最低。

**笔**：相邻的顶分型与底分型连接；新笔要求顶底分型之间**不共用 K 线且至少有一根独立 K 线**（老笔：分型间至少 5 根 K 线）。

**线段**：至少由**三笔**构成，且前三笔必须有重叠部分；线段的结束用"特征序列"的分型判定（缺口与否两种情况）。

**中枢**：某级别走势中，**被至少三个连续次级别走势类型所重叠的部分**。
- ZG = 三段高点中的最低者，ZD = 三段低点中的最高者；中枢区间 [ZD, ZG]（要求 ZG > ZD）。
- 中枢延伸、扩张、新生：离开中枢的次级别走势回抽不回中枢 → 新中枢可能形成。

**走势类型**
- 盘整：只有一个中枢。
- 趋势：两个或以上**依次同向**、不重叠的中枢（上涨 / 下跌）。
- "走势终完美"：任何走势类型终将完成，完成后转为另一种走势类型。

**背驰**：同向的后一段走势力度 < 前一段（常用 MACD 柱面积或黄白线高度比较）。
- 趋势背驰：最后一个中枢之后那段 vs 前一个中枢之后那段 → 趋势可能结束。
- 盘整背驰：离开中枢的两段比较。

**三类买卖点**（以买点为例，卖点镜像）
| 买点 | 定义 | 风险 |
|---|---|---|
| 一买 | 下跌**趋势背驰**的低点 | 左侧，最便宜但最容易错 |
| 二买 | 一买后第一次次级别回调**不破一买低点**的位置 | 介于左右之间 |
| 三买 | 次级别走势**向上离开中枢**后，回抽的低点**不回到 ZG 之上方以内**（低点 > ZG） | 右侧，确认度最高，常对应突破后回踩 |

**区间套**：在大级别买点区域内，逐级向下找小级别背驰来精确定位进出时点。

## 3. A 股适配与坑

- **涨跌停与跳空**：一字板会让分型 / 笔的判定失真（一根 K 线覆盖多日走势），连板票基本不适用。
- **级别选择决定一切**：同一时刻日线是一买、5 分钟可能是三卖；结论必须**带级别**写。
- **T+1**：小级别（1 / 5 分钟）买点当天无法卖出，区间套只能用在"决定今天在哪买 / 明天在哪卖"，不能做日内来回（除 T+0 品种：转债、ETF）。
- 网上版本众多，笔 / 线段的细节规则不统一 → 本项目若实现，必须固定一个开源实现口径并注明。

## 4. 可机械化的判定（本项目数据）

- 日线：`downloads/quotes/daily/<code>.json`、行情库 kline_day；分钟线：`kline_minute.jsonl`（收盘后，关注集）、`open15_minute.jsonl`（全市场开盘 15 分钟）。
- **可直接机械化**：包含处理、分型、笔（确定性规则）；中枢 [ZD, ZG]；MACD 面积背驰。
- **难机械化**：线段特征序列在缺口情况下的判定；不同实现口径差异大。
- 建议实现顺序：分型 → 笔 → 用"笔中枢"（三笔重叠）近似线段中枢 → 三买 / 三卖判定（离开中枢 + 回抽不回中枢）。三买 ≈ 箱体"向上突破后回踩不回箱"，可与箱体口径交叉验证。
- 可选开源实现参考：czsc（Python，缠中说禅技术分析工具），先读口径再决定是否引入依赖。

## 5. 在本项目里怎么用

- **02 市况**：指数日线标注"当前在第几个中枢、是否出现趋势背驰"，作为位置层的第二意见（与箱体五阶段交叉；两者打架 → 降低结论置信度）。
- **06 挂价**：右侧导师的追价买点，若对应 30 分钟级别三买，失效位 = 中枢 ZG；比"日内低点"更有结构依据。
- **07 复盘**：追高亏损单检查"买点是否落在背驰段末端"（典型：量化小号 10/20 11:00 追斯菱 +15%，日内高点附近）。
- **做 T（T+0 品种）**：纳指 ETF / 转债可用 1 分钟 / 5 分钟笔做区间套；T+1 股票只用于定"明天的高抛位"。

## 6. 局限与证伪

- 主观性与口径分歧大，"事后都能画对"；**不进入驱动器硬约束**，只作为事实包里的结构描述。
- 背驰的 MACD 参数、面积算法会改变结论，必须固定参数。
- 证伪：机械实现后在 3 年数据上统计三买 / 三卖后 5 / 10 日收益，与箱体"向上突破后回踩"对比；不显著优于箱体就不引入（奥卡姆剃刀：能用箱体解释的不用缠论）。
