### 配套纪律（已立法，写代码时别丢）
- `R-PNL-TRUE`：解套/盈亏口径 = 账户级（市值+现金 vs 初始投入），禁止只看每股成本——已实现亏损不因股价回来而自动恢复
- `R-FACTOR`：因子加权可复算（权重表在 STRATEGY.md §9），一致性<0.6 禁给 >50%
- 目标校准：第一年目标=月度胜率>60%+回撤<10%+跑赢大盘 20-40pt；一年 10 倍不做承诺（那是杠杆+幸存者偏差领域）
- **审计红线**：paper_state 持仓变动必须有成交记录+哈希链（9/23 已出"成交0笔但持仓变化"断链事故，写代码时把"状态变更必须伴随不可篡改日志"做成硬约束）

## 四大智能体特点摘要（2026-09-23 hermes 整理，按可借鉴度排序）

### 1. TradingAgents（开源多角色辩论框架）
- **结构**：四组分析师（基本面/技术面/情绪面/新闻面）→ 多空研究员**辩论** → 交易员综合 → 三位风控（激进/保守/中性）再辩论 → 最终决策
- **核心机制**：任何单子必须经过"多头 vs 空头"对抗后才允许产生；角色间用结构化报告通信而非自由聊天
- **抄什么**：我们的"辩论制输出"原型就是它；角色=4分析师可砍成 2（技术面脚本算+新闻面LLM判），风控三选一简化为一致性阈值（R-FACTOR）

### 2. AI Hedge Fund（开源，virattt）
- **结构**：巴菲特/芒格/木头姐/阿克曼等**大师人格 agent** + 估值/技术/情绪分析师 → 组合经理仲裁
- **核心机制**：人格不是cosplay——每个大师 agent 内置该流派的真实决策规则（巴菲特=护城河+安全边际打分，阿克曼=激进主义催化）；人格间结论冲突时由组合经理按规则分配权重
- **抄什么**：这就是我们的"桃哥/k3-inv/豆神"人格矩阵原型；注意它的人格=**可执行规则集**而非风格描述——我们 STRATEGY.md 的 R 系列规则就是对的做法

### 3. AlphaArena / nof1.ai（实盘 AI 交易竞赛）
- **结构**：前沿大模型（GPT/Claude/Gemini/Grok/DeepSeek/Qwen）各拿真金白银 $10k 在 Hyperliquid 上实盘交易，**同一 prompt、同一工具、公开净值排行榜**
- **核心发现**：①相同工具下各模型盈亏差异巨大——差距在风控不在预测 ②爆仓的模型都死于过度交易+杠杆 ③简单 prompt+好工具 > 复杂 prompt+差工具 ④净值是唯一能说话的指标
- **抄什么**："先活下来"是复利的前提（我们的回撤<10%目标的出处）；它的实时净值榜=我们 paper NAV 曲线的对标形式；**少即是多的 prompt 哲学**——规则要精不要多

### 4. Qlib + RD-Agent（微软，研究自动化）
- **结构**：Qlib=AI 量化平台（数据/因子/回测全套基建）；RD-Agent=LLM 驱动的**研究循环**：读论文/研报 → 提假设 → 自动写因子代码 → 回测 → 读结果再迭代
- **核心机制**：假设→代码→回测→反馈的全自动闭环；基建重（数据层投入大）但复利强
- **抄什么**：我们的"案例卡→规则→回放→沉淀"循环就是穷人版 RD-Agent；假期 P1 的"条件化参数引擎"本质上是把 RD-Agent 的假设验证循环搬到做T参数上

### 附：FinRobot / QuantConnect Lean
- FinRobot（AI4Finance）：财报分析/研报生成 agent 平台——我们的"涨停分析消化"可参考其报告结构化思路
- QuantConnect Lean：成熟量化引擎，LLM 可当信号插件——若未来要接实盘券商 API，它是现成底座

### 共同基因（四家的交集=我们的设计原则）
1. 角色窄化+结构化通信（防上下文污染）
2. 对抗后才决策（辩论/多空校验）
3. 风控优先于预测（回撤是第一大敌）
4. 闭环反馈驱动进化（净值/回测是唯一裁判）
5. 数据基建先行（都是先建管道再谈智能）
