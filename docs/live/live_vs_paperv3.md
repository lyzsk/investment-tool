# live line vs paper v3 · 叫醒方式 + chain 逐项对比（10/25）

> 两者跑的是**同一个执行器**（`scripts/paper_line/executor.py` 的 V3 类）。live line 的线定义为 `kind=mimic, mode=watch, live=True`，也就是 paper v3 的"拟人线 · 盯盘模式"再加几处 live 专属分支。下表"相同"的项是同一段代码。
> paper v3 的口径以 10/23 那天实际跑的为准，10/24 起改的公共部分（02 共用、harness 闸、K线结构等）两边都有，单独注明。

## 一、叫醒（触发）

| 触发 | paper v3（盯盘模式） | live line | 差别 |
|---|---|---|---|
| 盘前首跑 | 09:00 全部线并行 | **08:35 起串行分组**（第 1 条写好共享缓存，之后每 3 条一组，组间最多等 240 秒） | 只是时间提前、排队，不影响叫醒次数 |
| 09:20 竞价复核 | 每条线都叫模型 | **10/25 起同 paper v3**：每条留下的线都叫模型；先用代码对照盘前情景表，结果附在叫醒原因里（"全部落在情景内…" / "偏离…"）。开关 `LIVE_AUC_SKIP=1` 才是"全落在情景内就不叫"（原模块 7 口径，按你"漏叫代价大"的原则默认关掉） | 默认一样，多带一份对照结果 |
| 09:25 竞价定格 | 只机械撮合 | 撮合前**再对照一次**情景表：落在某个情景 → 停用其他情景独有的单；**偏离 → 叫模型** | live 只会**多叫**，不会少叫 |
| 成交 | 叫 | 叫 | 相同 |
| 价格出 band（持续 ≥ PAPER_BAND_HOLD_S 秒） | 叫 | 叫 | 相同 |
| 06 写的 wake 失效条件命中 | 叫（不占上限、不看冷却） | 叫 | 相同 |
| 市况翻转 / 心跳 | 叫 | 叫 | 相同 |
| 空仓提醒 10:30 / 13:30（导师通常有仓位时） | 叫 | 叫 | 相同（live 起步就有你的真实持仓，基本不会触发） |
| 14:51 尾盘版 | 叫 | 叫 | 相同 |
| 叫醒上限从 10:30 起算 / 排队上限 13 | 有 | 有 | 相同 |
| 缓存保温（空闲 50 分钟发短句续期） | 有 | 有（休眠的线不保温） | 休眠线不保温 |
| **09:19 后没留下的线** | 无此概念（11 本都跑全天） | **休眠：不叫模型、不保温；已挂的单照样机械撮合**；你说"恢复 N"随时加回（加回会立刻叫醒一次） | live 专属，是你定的"留 / 暂停"机制 |
| 02 刷新 | 10/23 时每本自己写 02；10/24 起共用 02 会话，机械条件刷新，**不叫醒线**，附在下次叫醒消息里 | 同（共用） | 10/24 起相同 |

结论：**live line 的叫醒 = paper v3 盯盘模式的叫醒**，另外多了两处：09:25 偏离情景时多叫一次，没留下的线休眠。09:20 原来会少叫一次，10/25 已经改成默认和 paper v3 一样。

## 二、chain 各步

| 步 | paper v3（10/23） | live line | 差别 |
|---|---|---|---|
| 线 | 固定 11 本：拟人盯盘 3（芷影 / 刘忆青 / 土豆）+ 计划模式 3 + 芷影带 03 + 芷影噪声对照 + 决策T 银行 / 纳指 等 | 当天名单动态生成：入选导师（近 20 日 ≥10% 且日均 ≥0.2%、5 日内有净值）+ 桃哥 / 卢本圆；10/26 = 6 条 | live 不带对照组 / 计划模式 / 决策T（你 10/25 停掉） |
| 账本起点 | 前一交易日本线收盘状态（第一天 10 万空仓） | **你最近一份收盘真实持仓 + 现金**（去掉中国银行） | live 每天从真实仓位起步 |
| 盘前首跑材料 | 共享开头 + skill + 导师近况 + 必查 | 同 + 实盘线说明（INTRO_LIVE：目标赚钱、可以因教训偏离导师、要对你的持仓给动作） | 说明文字不同 |
| 01 事实包 / 必查 | build_01 + must_check | 同一段代码；10/24~25 新增的项（K线结构 / 同逻辑邻居 / 案例正负标签 / 全体导师同票样例 / 电报点名）两边都有 | 相同 |
| 02 | 10/23：每本自己写 | 10/24 起两边都用共用 02；10/25 加方向证据包（导师 T−1~T−3 买卖 / UP 近 3 日 / 发哥命中率 / 指数 K 线 / market-skill） | 10/24 起相同 |
| 03 | 只有"芷影带 03"那一本跑 | **不跑** | 等你定开不开（TODO ❓7） |
| 04 | ASK04 + harness 必填 + 内容闸（拟人线） | 同 | 相同 |
| 05 | 机械风控（导师动态新开上限、当日 −3% 暂停新买、单票上限） | 同 | 相同 |
| 06 | 规则单 + wake + 本线记忆 | 同 + **盘前版写计划表（情景 × 动作，scenarios）** + **每只有挂单的票写 kline 看法**（箱体 / 结构 / 后市 / 概率引用） | live 多两段输出 |
| 推送 | 每次出版推（PAPER_PUSH_LINES 白名单） | 盘前不逐条推，09:12 合成一条盘前汇总（带序号）；09:19 起只推留下的线 | live 推得少、集中 |
| 晚上核销 | paper 核销 + 和导师真人对比打分 | 同（导师线）；UP 线没有真人逐笔，只核销单子 | 相同 |

## 不自信点
