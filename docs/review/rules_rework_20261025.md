## 五、不自信点（全局）

1. **一笔仓的结果口径是我定的**：新开仓起点 = cases_auto 的 new_open 买入，到同票后续所有卖出的 pnl 简单平均（不按股数加权）；和 strong_next 的"买 → 首笔卖"口径不同，FIFO 残单可能混进来。两种口径的方向一致，但数字会差 1 个点左右。
2. **"三类打法"和"昨收合计仓"都是机械字段**：打法来自 cases_auto 的 play 标签，仓位来自 case_log 日卡"昨收持仓（合计）"行，个别日缺；R38 / R39 的情境表各格 n 在 12~89 之间，**次日高开格里低吸比直接卖差（n=7 / 8）**只能当线索。
3. **"题材是否还在"没法回测**（题材标签 2026-01-15 起才有、只覆盖涨停 / 大涨股），R39 没按它分；10-23 两只的题材延续没核。
4. **箱体位置是我按 kline_struct.py 的段式箱体算法、用买入日之前的日线重算的**（价 = 买入均价，33% / 66% 分档线是我定的）；4 个导师都 85%~94% 买在箱体上部及以上，箱体位置主要用来区分结果，n 小的格只作参照。
