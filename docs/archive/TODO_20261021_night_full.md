### ★4 为什么有了翻转和指数事件还要心跳 / 两者区别 / 能不能合并（21:5x 你问）

- 两者区别：

  - **指数事件** = "从我上次重定到现在，上证走了多少"：只看上证，离**本链上次重定**的价格移动 ≥ θ（0.23%）就触发，不管方向；每条链的起点不同，所以每条链触发时刻不同

- 为什么还要心跳：两类事件都没有的最长空档，20 天中位 **72 分钟**、最长 139 分钟（10/21 午后 0 次翻转）；两类都只看大盘，看不到本链自己的事——持仓在区间里慢慢磨、候选票里出了新涨停、导师习惯在 14:30 前后动手、10 万空仓的链一直没买进；心跳是"安静太久就自己看一眼"的兜底，而且任何触发都会把它往后推，**只在安静时才花钱**
