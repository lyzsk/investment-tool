- E16 **Teachers-Students 怎么落地**（你的初衷：没有训练硬件，用付费 LLM + 系统工程近似专项模型）：对应关系——"权重"=画像/规则/指纹/案例库这些文本 + 小统计模型（逻辑回归、查表，CPU 就能训）；"训练数据"=导师 md（因）+ 账本（果）；"梯度更新"=蒸馏和 07 复盘改写这些文本；"损失函数"=分层拟人度（学像）→ 相对照抄老师的风险调整收益（学强）；"验证集"=前向的交易日；"推理时算力"=01→07 链。缺的两块：①改写没有验证（→二B-11 版本化+回滚）②学强阶段的统计门槛（等有线过了学像阶段再设计）。分阶段闸门：学像 → 学强 → 子学生，每一代都锚市场真实结果
- E17 **07 全跑**：你 10/16 晚定——16 条链 + 对照组每天都跑 07（约 $40/天），兜底也跑
- E18 **导师统计模型结果**（`docs/research/mentor_model_20261016.md`）：①只在**方向层（加/减/不动）**普遍赢基线（全体准确率 69% vs 照抄昨天 52%，7 位显著赢）；出不出手几乎全由"昨天做没做"决定，模型赢不了延续；打法不随市况变，用本人打法频率就够 ②画像规则编成特征**增益≈0**——规则本身大多成立（隔夜仓日卖出率 86% vs 其他 43%），但信息已被"昨天出手/昨仓/空仓"吸收；画像规则更适合当硬闸和解释，不适合当统计特征 ③大盘状态对出不出手、加减都没有增量 ④基线账户（照统计模型出单）10/08~16 比 LLM 链**更像导师**（总仓误差、单票最大仓显著更小），但收益中位 −6.1% vs LLM −2.3%；样本只有 4~7 天，不下结论。下一步按 A2：基线建议注入 facts，LLM 默认接受方向/出手/仓位、要改写理由，某层连续 20 天改得更差就锁住
