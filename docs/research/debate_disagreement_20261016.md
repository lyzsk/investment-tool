# 03 多空辩论"保留分歧"：外部证据、我们的现状、改法与 A/B（2026-10-16 晚）

> 起因：`ai_trading_frameworks_20261016.md` 发现 10/12~10/16 的 03 裁判 70 次里 68 次判"多"，并引了"只有保留分歧的干预能提高 Sharpe"（arXiv 2609.29701）。本文回答三件事：这个干预原文到底怎么做的；我们的 03 为什么成了常数；怎么改、怎么验证。
> 约束：没有改任何真文件，没有调用 `claude -p`。补丁只在副本上打和自测：`scripts/temp/debate_dev/apply_debate.py`（`--check` 结果 PASS）。统计脚本是 `scripts/temp/debate_dev/stats_03.py`，原始结果在 `stats_03.json`，自测输出在 `check_output.txt`。论文原文、配置和代码片段下载在 `scripts/temp/debate_dev/dl/`。

## 〇、结论先说（6 条）

> 10/16 晚按用户反馈更新了三处：①对照组 control 也改用新 03；②空方折算系数 k 改为动态（[1,2]，先验 1.5，按链滚动校准）；③新增 ⑥"偏空假设的证据"和校准回放脚本。

1. **原文的"保留分歧"和我们以为的不一样。** 2609.29701 的干预发生在聚合**之前**：两个 agent 互评、修订之后，如果组合的 JS 散度跌到修订前的 80% 以下，就强制重新修订一次，同时给一段"保持独立判断"的提示，并且硬性限制修订幅度（最多改 2 只票、每只最多改 5 个百分点）。目的是不让各家的独立信号在聚合前被抹平。它**没有**把分歧度传给下游，也**没有**按分歧缩放仓位。效果是 Sharpe +0.14（p=0.028，35 个配对场景）。但这个配置是从 18 种配置里挑出来的，加入第三个 agent 后效果降到 +0.04（不显著），用的是历史季度回测，没有交易成本，也可能有训练泄漏。证据级别：**弱到中**。
2. **我们的 03b/03s 本身不存在原文那种失败模式**：两个独立会话互相看不见，不会被对方带着走。**分歧是在 03j 裁判这一步被抹掉的**，而且是模板写死的。三条规则是元凶："必须分出高下"、"看空降权：空方要拿出多方两倍的证据才能胜"、"证据平衡时跟随先行层，给最小试错仓"。70 份裁判正文里 61 份明确援引了看空降权，15 份直接写"空方未达两倍"。空方论据并不弱：长度中位数 709 字，多方 691 字。所以问题不在空方，而在聚合规则：它把软信息压成了 argmax，还加了一个不对称的先验。
3. **分歧其实一直有，只是没有字段装它。** 18/70 份裁判正文写了"吸收空方赢下的子项"之类的话，但 contract 只有 `winner`、`decisive_reason` 和 `follows_leading_layer`（`follows_leading_layer` 70/70 都是 true）。驱动器没有任何代码机械地读 03 的结论，下游只能读正文。02 的态度和 03 也对不上：0915 版 02 判"中立/空"、03 却判"多"的有 32 次，其中 23 次 06 照样下了买单。
4. **改法一句话**：03j 不再二选一，改成给多空两方各打一个"经核验仍成立的论据强度"分（0-100，两方独立打，不是零和），再加少数派风险和翻转条件。驱动器用**有效空分 S' = S/k** 算倾向、分歧度和折扣系数。k 是空方折算系数，按用户 10/16 晚的定法取 [1,2]、先验 1.5，按链用近 20 个交易日的分数和标签滚动拟合，再向 1.5 收缩；有标签样本不足 5 个时直接用 1.5。下游只用两处：①往 04/05/06 的约束块里注入"03 分歧"摘要，k 和样本数也写进去；②0915 盘前、分歧高或倾向空时，**追价买单**（挂价≥现价锚、开盘即成交）的单票金额乘以 0.75/0.5/0.25 打折，回踩条件单不受影响。仓位下限、能力圈、导师风格都不动（方案 A）。**对照组 control 也用同一套新 03**（10/16 晚用户定）。
5. **"LLM 天生偏空"这个前提，外部证据并不一致，我们自己的数据也证明不了。** 外部研究里，收益预测类的多发现 LLM 偏乐观；交易 agent 类的多发现 LLM 在牛市过度保守；还有研究发现偏差因模型而异（详见 ⑥）。我们的 03s/03b 是被指派立场的辩手，测不出模型本身的偏向。02 态度这 5 天偏空（多 4 / 中立 24 / 空 14），而上证这 5 天里 3 天下跌，所以看空在方向上未必是错。因此 k 先按用户先验 1.5 上线，同时写了校准回放脚本 `calib_replay.py`：70 次调用，约 $67，约 3.6 小时；只跑有标签的 37 次，约 $36。只做了 dry 跑，没有真跑。
6. **花不花这 12% 要用对照来定，不能靠论证。** 03 占账面成本 12.2%（5 天 $169），每条链串行约 8 分钟。我设计了一个三臂交叉 A/B（现状 / 保留分歧版 / 停 03）。拟人度不比现状差、而且分歧不是常数，才保留新 03；否则按奥卡姆剃刀停掉 03。

## ① 外部证据（分强 / 中 / 弱）

### 1.1 核心论文：2609.29701 的 JSD 干预到底是什么（弱~中）

[Huang 等, *Multi-Agent Debate for Explainable Trading*, arXiv 2609.29701（斯坦福，2026-08-31）](https://arxiv.org/abs/2609.29701)。代码在 [GitHub cs372research](https://github.com/TheClassicTechno/cs372research/)，干预规则见 `eval/interventions/rules.py`，配置见 `vskarich_ablations/ablation_7/debate_configs/strict_intervention_th08.yaml`，两个文件我都读过。

| 项 | 原文做法 |
|---|---|
| 流程 | propose（各 agent 独立给组合权重）→ critique（互评）→ revise（修订）→ **[干预检查点]** → CRIT 打分 → judge 聚合（LLM 裁判，或者直接对各 agent 权重取平均） |
| 分歧怎么表示 | 各 agent **组合权重分布**之间的 Jensen-Shannon 散度（含现金权重）。`collapse_ratio = JS_修订后 / JS_提案时` |
| 触发 | ratio < 0.8，并且提案时 JS ≥ 0.10（本来就一致的不算"塌缩"），最多重试 1 次 |
| prompt 怎么写 | 按角色写的"DEBATE DIVERSITY PROTOCOL"，要点是"不要只因为别人同意就放弃有证据的论点""快速达成一致需要明确理由""修订前复查原论点；至少捍卫一条原论点（除非已被证伪）；指出正在形成的共识里一个薄弱点；说出最不同意哪个 agent、为什么" |
| 关键的硬约束 | **重试时组合最多改 2 只票、每只最多改 5 个百分点**（`revision_limits`；正文写的是"max 10%"，和配置不一致）。正文说只加提示语的"软"版本**没有可测效果** |
| 怎么传给下游 | **不传**。保留下来的是"各自独立的组合"，再交给 judge 聚合。judge 的 prompt 里有一句"即使驳回也要记录最强反对意见（disagreement preservation）"，但最终只输出一个组合 |
| 仓位是否随分歧变化 | **否**。原文没有测试"分歧→仓位缩放" |
| 实验设置 | gpt-5-mini（温度 0.3），2 个 agent（宏观+技术），1 轮；35 个季度场景（2021Q4~2025Q3，3~35 只美股），季度初建仓、持有一个季度；**不计交易成本** |
| 效果 | Ablation 7（35 对配对）：Sharpe +0.143（配对差的标准差 0.368，t≈2.3，p=0.028），Sortino +0.25，收益 +0.83pp（不显著），最大回撤不变 |
| 同文里的反例 | ①加入第三个 risk agent 后（A8），同样的干预只剩 +0.04（不显著）；②A11 阈值设 0.6 时，9 次里只触发 1 次；③推理质量和 Sharpe r=0.07；④4 个 agent 辩 5 轮反而亏钱，现金比例从 10~50% 收敛到 55~61%（谄媚趋同）；⑤所有配置跑赢 1/N 等权的比例只有 33% |
| 可信度扣分 | Ablation 6 先在 3 个场景上扫了 18 种配置（2/3 个 agent × soft/moderate/strict × 阈值 0.65/0.8），挑出 strict-0.8 后才上 35 个场景，p 值没有做多重比较校正；回测窗口落在模型训练期内（作者自己承认可能泄漏）；单篇论文，没有独立复现 |

**对我们的含义**：这篇论文支持的是"**聚合前不要让独立信号塌缩**"（集成多样性），不支持"分歧越大仓位越小"这条具体映射。后者要从下面几类证据去找。

### 1.2 支撑"保留分歧"机制的证据

| 结论 | 出处 | 级别 | 和我们的关系 |
|---|---|---|---|
| 集成误差 = 成员平均误差 − 多样性项。成员个体不变时，分歧越大，集成越好 | Krogh & Vedelsby, NIPS 7（1994，[proceedings](https://papers.nips.cc/paper_files/paper/1994)） | **强**（理论） | 03j 取 argmax 等于把多样性项清零 |
| 多 agent 辩论的增益大部分来自多数投票；辩论本身是鞅，不提高期望正确率；能起作用的是"让正确信号权重更大"的定向干预 | [Choi 等, *Debate or Vote*, NeurIPS 2025 Spotlight, 2508.17536](https://arxiv.org/abs/2508.17536)（[代码](https://github.com/deeplearning-wisc/debate-or-vote)） | **中强**（理论 + 7 个 NLP 基准，不是交易） | 03b/03s 独立给分再机械聚合，就是 vote 式。不需要裁判"说服"出一个赢家 |
| 辩论会让 agent 从对改成错（从众、谄媚）；混入较弱的 agent 会拖累整体 | [Wynn 等, *Talk Isn't Always Cheap*, 2509.05396](https://arxiv.org/abs/2509.05396) | 中 | 支持 03b/03s 继续互不可见（10/4 拆环立法是对的） |
| LLM 口头报出的置信度系统性偏高（多落在 80~100%），不能直接当概率用 | [Xiong 等, ICLR 2024, 2306.13063](https://arxiv.org/abs/2306.13063) | 中强 | 两方分只做**粗档位**（高/中/低），不当概率，不做连续 Kelly |
| "语言置信度不是可交易的概率"；强反向证据合理的反应是**降置信度/减仓**，而不是翻向 | [Ye 等, *The Alpha Illusion*, 2605.16895](https://arxiv.org/abs/2605.16895)（立场文） | 中（论证） | 改法是"打折"，不是"翻空" |
| 同一 agent 多次运行结果不一致可以当不确定性信号：只在一致时作答，正确率高 6~14pp，代价是只覆盖 54~62% 的题 | [Mehta, 2602.11619](https://arxiv.org/abs/2602.11619) | 中（NLP） | 分歧→弃权/降级的一般依据 |

### 1.3 "分歧→仓位/是否交易"的相关做法（对比用）

| 做法 | 出处 | 级别 | 机制 | 结果 / 局限 |
|---|---|---|---|---|
| **共识闸（CGX）** | [Bajgora 等, *Consensus-Gated Execution*, Electronics 2026 15(15):3453](https://www.mdpi.com/2079-9292/15/15/3453) | 弱（加密、C 级；页面被拦，只读到检索摘要） | Bull/Bear 辩 3 轮 → 元评估器给共识分 → 低于阈值就**不交易** | 波动率 −86%、CVaR −86%，收益没有提高；共识分只落在 22~52%，从来没到过 80%，所以**阈值稍动一点，拦截率就剧变** |
| **按跨 agent 一致性加权（TrustTrade）** | [Li 等, 2603.22567](https://arxiv.org/abs/2603.22567) | 弱（只读了摘要） | 多个独立 agent 的信号按语义和数值一致性加权，有分歧的信号打折 | 把 LLM 交易从"极端高风险高收益"拉回到中风险中收益 |
| **前向/反向两条推理路径的 JSD 当锚** | [Chen 等, 2609.11709](https://arxiv.org/abs/2609.11709) | 弱（医疗诊断） | 用两种不同分解得到的后验之间的 JS 散度给 agent 排序或加权 | 在 agent 有分歧的子集上增益最大 |
| **按预测概率定仓位（bet sizing）** | López de Prado, *Advances in Financial Machine Learning*（Wiley 2018）第 10 章 | 中（经典量化实践，不是 LLM） | 仓位 = f(预测概率)，并**离散成几档**，避免信号抖动带来过度交易 | 我们用的 1/0.75/0.5/0.25 四档就是这个思路 |
| **分歧本身就是收益信号** | Diether, Malloy & Scherbina, *JF* 2002（[doi](https://doi.org/10.1111/1540-6261.00490)） | 强（在它的领域） | 分析师预测分歧越大，股票后续收益越低（卖空受限时，乐观者定价） | 是"人类分析师 × 个股横截面"，不是 LLM 辩论；只能说明"分歧有信息量"在金融里有先例 |

**小结**：能直接迁移过来的是"**不要在聚合时塌缩**"（强/中证据）和"**分歧→降级/弃权**"（中/弱证据，主要在降风险，不在提收益）。"分歧→仓位打几折"的具体系数，没有任何一篇能给我们校准，只能先当先验，再由 A/B 检验。

## ③ 改法设计（保留分歧版 03，`DEBATE_V2`）

### 3.1 原则

- **独立性保留**：03b/03s 仍然是独立会话、互不可见（10/4 立法不动）。对应原文"聚合前不塌缩"，以及 Debate or Vote 的"vote 式聚合"。
- **软聚合代替 argmax**：裁判不再选胜方，给两方各打一个分。分歧度由驱动器从两个分数**机械算**，不采信模型自报的倾向（`lean` 只作参考，不一致时打 WARN，以复算为准）。
- **粗档位**：LLM 打的分没有校准（Xiong 2024），所以只分 3 档分歧度和 4 档系数（López de Prado 的离散化思路）。
- **方案 A**：分歧只调"追价单的单票金额"和"提醒 05/06 对照少数派风险"，不改仓位下限、能力圈、出手时段这些导师行为约束。对照组 control 也用同一套机制（10/16 晚用户定），这样"导师链 − 对照组"的减法里两边的 03 是同一版本。
- **不对裁判透露下游用法**：prompt 只说"分数只反映证据，下游用法由驱动器决定"，避免裁判为了让下游敢下单或不敢下单而调分。

### 3.2 contract

- 03b/03s：原字段 + `concede_if`（认输条件：竞价或早盘出现什么可观测事实，本方就认输；要带具体数）。只有处理组必填。
- 03j：`{"bull_score":0-100,"bear_score":0-100,"lean":"多|空|均衡","minority_risks":[...],"flip_triggers":[...],"fabricated":[...],"decisive_reason":"..."}`
  - 校验：两个分数都是 0-100 的数；flip_triggers ≥1 条；**较弱方分≥20 时 minority_risks ≥1 条**（这是保留分歧的唯一出口）；处理组写成旧的 winner 格式要回炉；未改模板的链照旧走 winner 校验（双格式兼容）。
  - 撤销：必须分出高下、看空降权、证据平衡时跟随先行层给试错仓。编锚的论据由"直接判负"改成"不计分并列入 fabricated"。

### 3.3 驱动器的机械映射

```
有效空分 S' = S / k（k∈[1,2]，见 3.3b）
p = B/(B+S')；margin = |p-0.5|×2；双方都弱 = max(B,S) < 40（用原始分）
倾向：p≥0.6 多；p≤0.4 空；其余 均衡
分歧度：margin<0.2 或双方都弱 → 高；margin<0.5 → 中；否则 低
追价折扣系数：(多,低)=1.0  (多,中)=0.75  (空,中)=0.5  (空,低)=0.25  其余(均衡/高/双方都弱)=0.5
```

举例（k=1.5）：B=50、S=45 → S'=30，p=0.625 → 多/中，系数 0.75。B=40、S=70 → S'=46.7，p=0.46 → 均衡/高，系数 0.5。要倾向空，需要 S ≥ 1.5×1.5×B ≈ 2.25B（p≤0.4 ⇔ S' ≥ 1.5B）。也就是说，k=1.5 比旧的"写死两倍"更宽松一些，但仍然对空方设了门槛。

### 3.3b 空方折算系数 k（10/16 晚用户定）

- **用户本意**：LLM 天生偏空，所以要约束空方。原意是空方证据约为多方的 1.5 倍才算偏空，并且应在 [1,2] 内动态调整；旧模板写死 2 倍不对。
- **实现**（`debate_k` / `debate_fit_k`，每次 03j 通过时现场算，失败就用 1.5，不阻断链）：
  1. 样本：本链在当天之前、最近 20 个有 03 分数的交易日，取 `live-*/debate.json` 里的 (B, S)。如有 `results/<chain>/debate_seed.jsonl`（校准回放产出，经用户批准才写），也并进来。
  2. 标签：
     - **tzzb 导师链** = 导师真人当日方向，口径同 `mimicry_score.py` 的 L2：去掉价格漂移后的净权重变化 >+5% 资产记为净加 +1，<−5% 记为净减 −1；不动或无数据的日子不计。
     - **B 站 UP 链和对照组** = 上证指数从 d−1 收盘到 d+1 收盘的涨跌，|涨跌|<0.3% 不计。选 d+1 收盘，是因为 0915 买单 T+1 才能卖，这个窗口覆盖买入后第一个可卖日。只用 cut 日之前已收盘的数据，所以 d 日的标签要到 d+2 才进入拟合，as-of 不会偷看。
  3. 拟合：k 在 [1, 2] 上按步长 0.05 网格搜索，取使 sign(B − S/k) 与标签一致数最多的 k；并列时取离 1.5 最近的。
  4. 收缩：k = (n·k_fit + 10×1.5)/(n + 10)，n 为有标签样本数；**n < 5 时直接用 1.5**。
- **留痕**：k、k_fit、有标签样本数/有分数天数、标签口径写进 `debate.json`、`pos_constraints.json.debate`、日志行，以及 `03_debate.md` 里新插入的"驱动器复算"块（插在末个 contract 块之前，contract 和哨兵不变，幂等）。04/05/06 的约束块里也有一行"空方折算 k=…（样本… ; 标签=…）"。
- **冷启动**：10/12~16 的旧 03j 没有两方分，所以上线后头 5 个交易日内各链 k=1.5。要提前有样本，就跑 `calib_replay.py --run --write-seed`（见 ⑥）。
- **我对这个设计的保留意见**（对抗式审查）：①标签和"03 想回答的问题"不完全一致。03 问的是"今天按本导师框架该不该做多"，tzzb 标签是"导师今天实际加没加仓"，UP 标签是"大盘涨没涨"。②一致率是 0/1 指标，网格上会有大片并列（自测里就有这种情形），所以加了"并列取 1.5"和收缩。③大盘标签对所有 UP 链和对照组是同一个序列，几条链的 k 会高度相关。④如果 LLM 实际偏多而不是偏空，按设计 k 最低只到 1，不会去约束多方；k 的区间 [1,2] 本身就带着"偏空"的先验。这一点需要用户知情。

## ⑥ 偏空假设的证据（10/16 晚补）

用户设 k 的前提是"LLM 天生偏空"。下面分别看外部证据和我们自己的数据各能说明什么。

### 6.1 外部文献：结论不一致，取决于任务

| 研究 | 任务 | 结论方向 | 级别 |
|---|---|---|---|
| Chen、Green 等, *What Does ChatGPT Make of Historical Stock Returns?*（[AEA 2026 年会](https://www.aeaweb.org/conference/2026/program/paper/zNrQ4Yn6)，[AFA](https://afajof.org/management/viewp.php?n=170324)） | 给历史收益，让 GPT-4o/Claude 3.5/Gemini 2.5 预测下月收益 | **偏乐观**：GPT-4o 平均预测 2.0%，实际 1.12%；但低估上行尾部；外推过去收益；用价格而不是收益来呈现数据时变悲观；改 prompt 纠不过来 | 中强（设计干净，但是收益预测任务、美股，只读了摘要和二手介绍） |
| FINSABER, [2505.07078](https://arxiv.org/abs/2505.07078)（KDD 2026） | FinMem/FinAgent 二十年回测 | **牛市过度保守、熊市过度激进**：不是一贯偏空，而是对市况反应错位 | 中强 |
| Huang 等, [2609.29701](https://arxiv.org/abs/2609.29701)（本文 ①） | 多 agent 辩论配置组合 | 4 个 agent 辩 5 轮后，现金比例从 10~50% 收敛到 55~61%：**多轮讨论趋于保守** | 弱~中 |
| Lee 等, *Your AI, Not Your View*, [2507.20957](https://arxiv.org/abs/2507.20957) | 多空论据平衡或不平衡的投资情景 | **偏差因模型而异**：多数模型偏好科技股、大盘股和**逆势**策略；偏差会演变成确认偏误 | 中 |
| Fin-Bias, [2605.09106](https://arxiv.org/abs/2605.09106)（转引 Jia 等 2024） | 金融决策中的人类偏差 | LLM 与人类相似，有风险厌恶和损失厌恶 | 中（只读到检索摘要） |
| Wang 等, [2606.08283](https://arxiv.org/abs/2606.08283) | 鹰派/鸽派 agent 配置商品 ETF | 偏差来自 prompt 给定的先验（鸽派先验失准），辩论只是把两边平均 | 弱 |
| TradeTrap, [2512.02261](https://arxiv.org/abs/2512.02261) | 记忆被投毒后的交易 agent | 收敛到"保守而低效"的惰性状态 | 弱 |

**归纳**：问 LLM"会涨多少"时，它多半**偏乐观**；让 LLM 当交易 agent 做"买不买、仓位多大"的决定时，它多表现为**风险厌恶、保守**，尤其在牛市里和多轮讨论之后。我们 03 里的"空方"大多在论证"今天别买/少买"，更接近后者，所以用户的假设有**部分**外部支持。但是：①没有任何一篇给出"空方证据要打几折"这个量级，1.5 和 [1,2] 都是先验；②FINSABER 说熊市里反而过度激进，偏差方向随市况变化，这支持 k 要动态，不支持 k 恒大于 1；③逆势偏好（Lee 等）在追涨型导师身上可能表现为"偏空"，在低吸型导师身上则可能相反，所以偏差是按导师分的，这一点支持按链分别校准。

### 6.2 我们自己的数据：能说明什么、不能说明什么

**不能说明"LLM 偏空"的部分：**
- 03b/03s 是**被指派立场的辩手**，论据的长短和强弱反映的是指派，不是模型本身的倾向。两边长度几乎一样（多方 691 字 / 空方 709 字，空方更长的占 51%）。
- 旧 03j 判多 68/70，是"看空降权"和"必须分出高下"规则的产物（61/70 份援引了降权），说明的是规则的效果，不是模型的倾向。15 份写了"空方未达两倍"，但这只说明空方没到两倍，看不出是否超过了 1 倍。

**有一点信息，但被行情混淆的部分：**
- 02 态度没有"降权"规则约束，5 天里是多 4 / 中立 24 / 空 14（另有 33 次缺 stance 字段）。看起来偏空，但上证同期 5 天里 3 天下跌（10/9 收盘 3813.8 → 10/16 收盘 3716.3，−2.6%），偏空在方向上可能是对的。只有 5 天、而且是单边下跌，**区分不了"偏空偏差"和"判断正确"**。
- tzzb 导师真人在 25 个有方向的链-日里净加仓 14、净减仓 11。旧 03 判"多"、真人当日净加仓的一致率是 12/21 = 57%，和"真人净加占 56%"的基础比例几乎相同，说明旧 03 对真人方向**没有预测力**。02 判"中立"的 9 天里真人净加 6 天、净减 3 天，似乎链比真人更谨慎，但 n=9，不能下结论。

**校准回放能补什么**（`calib_replay.py`，见 6.3）：用新 03j prompt 对 70 个历史链-日重新打分，得到中立裁判给出的 (B, S)。可以测：①S−B 的系统偏移（均值、中位、S>B 的占比、符号检验）；②按标签分组：如果真人净加或大盘涨的日子里 S 仍明显高于 B，就是偏空的证据；③拟合出 k。**局限**：①打分的裁判和辩手是同一个底座模型，偏移里混着"辩手论证质量"和"裁判偏好"两样东西；②10/12~15 的大盘标签全是"跌"，所以 UP 链和对照组这一批样本**对 k 没有辨识力**，只有 tzzb 链 21 个有正有负的标签可用，k 的置信区间会很宽；③回放用的是今天的 persona/rules（10/12 之后又蒸馏过），有轻微前视。

### 6.3 校准回放脚本（只写好、只跑了 dry，没有真跑）

- 脚本：`scripts/temp/debate_dev/calib_replay.py`。依赖 `apply_debate.py --check` 生成的副本驱动器和新模板。
- 做法：每个链-日建一个沙盒 run_dir（`calib_runs/<skill>/<日>/`，只复制 01/02/03b/03s 四个输入文件），拼 prompt = as-of 声明 + 新 03j 模板 + 画像注入 + 方案 A 补充 + 回放说明（旧陈词没有 concede_if，flip_triggers 由裁判自己推）。然后串行调用 `claude -p`，一次一个，子进程不弹窗，并且占用驱动器的全局并发槽。用同一个 `v03` 校验，不合格回炉 1 次。累计花费超过 `--max-usd`（默认 80）就停，可以断点续跑。跑完自动分析，结果写到 `calib_runs/analysis.json`。`--write-seed` 会把 (B, S) 写进 `results/<chain>/debate_seed.jsonl` 给驱动器冷启动用，因为要写真 results 目录，需要用户批准。
- dry 结果（`calib_dry_output.txt`）：70 个链-日（16 条链 × 5 天，buchitudou0 没有 03），prompt 中位 6254 字、最长 21341 字；有标签的 37 个，其中 tzzb 21 个、上证 16 个（16 个全是"跌"）。
- **成本估算**（按 10/12~16 旧 03j 实测 70 次：均值 $0.915、中位 $0.902、P90 $1.203，中位耗时 174 秒）：

| 跑法 | 调用次数 | 预计账面花费 | 串行耗时 |
|---|---|---|---|
| 全量 `--run` | 70（另加约 5% 回炉） | **约 $67**（$63~$84） | 约 3.6 小时 |
| `--run --labeled-only` | 37 | 约 $36 | 约 1.9 小时 |
| 只跑 tzzb 有标签的（`--labeled-only --skills <12 个 tzzb>`） | 21 | 约 $20 | 约 1.1 小时 |

  账面价不是实付；gravitex key 的系数为 1。
- 我的建议：如果目的是检验偏移（①②），跑全量 70 个；如果只想要 tzzb 链的 k 初值，跑 21 个就够。两种都不能回答"UP 链和对照组的 k 是多少"，那要等出现上涨日的标签。

## ⑤ 不自信点

1. **原文效果能否迁移最不确定**：+0.14 Sharpe 来自从 18 种配置里挑出的配置，三 agent 版本没有复现，是季度持有的美股回测，不计成本，可能有泄漏。而且原文的机制是"聚合前防塌缩"，我们的用法是"软聚合 + 分歧打折"，**两者不是同一个干预**。
2. **两方分可能又变成常数**：裁判可能习惯性地打出类似"70/45"的组合（模板示例已经改成 `<0-100>`，避免照抄），那样分歧度又不携带信息。这正是 M1 要测的。
3. **阈值和系数完全是先验**（0.6/0.4、margin 0.2/0.5、弱信息线 40、系数 1/0.75/0.5/0.25），没有数据可校准；LLM 打的分也没有校准。
4. **和方案 A 的冲突**：开盘追价是部分导师的常规动作（liuyiqing 40% 的买入在竞价/开盘），分歧高时打折可能让链更不像导师。tzzb 链的仓位下限按导师真仓算，用条件单凑下限可能不成交，收盘仓位会低于导师。这两点都靠 M4 判断。
5. **撤销"看空降权"违背了 10/9 用户令**（当时的拟人目标是"敢选票"）。我的判断是：追价闸只限制开盘追价的单票金额，条件单和仓位下限都不动，所以"敢选票"仍然保留。但这需要用户拍板。
6. **样本量**：一周 4 条链，每链每日约 1~2 笔 0915 买单，收益类指标（M5/M6）基本没有检验力，只能看粗的行为差异。交叉设计只能部分消除"导师不同"和"行情不同"两种混淆。
7. **统计口径**：06 买单和 02 stance 取自 `slots/0915/`（缺了才用顶层文件）；看空降权、空方子项是关键词计数，可能有误判（比如"空方胜出不了"也会被计入）；成本是账面价。
8. **k 动态化的风险**：①k 的标签（真人加没加仓 / 大盘涨没涨）和 03 的问题（今天按导师框架该不该做多）不是同一件事；②一致率指标粗、并列多，样本少时 k 基本被收缩回 1.5；③UP 链和对照组共用一条大盘标签，k 会同涨同跌；④区间 [1,2] 只允许约束空方，如果实测 LLM 偏多，这个设计纠正不了；⑤10/12~16 是单边下跌周，任何基于这周的 k 都可能把"判断对了"错当成"偏差"。
9. **对照组也改之后**，A/B 期间 A/C 臂的"导师链 − control"减法混入了 03 版本差异（见 4.1），只能看 B 臂。
10. **外部材料读得不全**：CGX 的页面被拦（HTTP 400），只读到检索摘要；TrustTrade 和 2609.11709 只读了摘要；Debate or Vote 的结论来自摘要和检索汇总，没有逐节精读；2609.29701 的 HTML 附录 B.9/B.10 表格渲染缺失，数值是我从代码仓配置和正文反推的（t≈2.3 和 p=0.028 对得上）。
