**一句话总结**: 五个项目里,能说清"每一步依据是什么"的是 PA_Agent(字段级)和 price-action-lab(三层 + 规则卡);能证明"这样推理能赚钱"的一个都没有;唯一认真验证的(PA_Agent 的 research)反而证明了大部分 PA 方向性说法没有信息量。所以我们**学它们的结构,但概率必须用我们自己的 A 股数据算,并且每个都和基准比**。

### 最值得借鉴的 3 点

1. **逐根字段化 + 程序事实不许覆盖**(PA_Agent): 每根 K 线固定输出 `bar_type / role / context_effect / trapped_side / follow_through / reason`,bar_type 由程序算,叙述只能引用。原型已照搬前四个字段。
2. **每个概率都要配一个基准**(PA_Agent research): "冲高回落 45%"本身不是信息,"同状态 45% vs 不加条件 33%"的差才是。它的结论也是给我们的警告: 方向信息很薄,真正有用的多半是"哪些情形不要做"。原型里每个数都并列基准。
3. **三层: 先机械计数 → 再资格审核 → 再叙述,任何一层都能说"不知道"**(price-action-lab): 对应我们就是 ① KD 定义 / 箱体 / 板型机械识别 → ② 样本数、和基准的差够不够、样本外有没有站住 → ③ 才写成推理链里的一句话;差不够的因子要明说"无增量",不能拿来讲故事。

## 三、改造方案

### A. 可解释推理链(每一步一个数据依据)

推理链每一步都是一条结构化断言,不是一句话:

```
{步: "抛压①: T 日最高价那档", 断言: "T+1 冲到 T 最高的概率", 价位: 3.73(收盘 +7.8%),
 依据: "全市场同状态样本(票型=炸板 + 涨跌档 2~5 + 前一日首板 + ATR 3~6% + …)", n: 123,
 数值: 25.2%, 基准: 18.2%(同票型 + 涨跌档), 差: +7.0, 置信: 低(n<200), 失效: "题材 / 消息没进样本"}
```

顺序照 albrooks-perspective 的"背景 → 信号 → 风险 → 陷阱",换成 A 股能算的东西:

1. **逐根(K5→K1)**: 形态(PA_Agent 口径 + 涨跌停 K 线单独认板型,KD3)→ 谁在买(封板资金在涨停价、收盘高于均价 = 当天买的人赚钱)→ 谁被套(炸板 = 涨停价买入的人被套 x%;收盘低于当天均价 = 当天买的人整体亏 x%;长上影 = 那段是卖压区)→ 哪里有支撑(长下影、未补缺口)→ 命中哪条 KD / KS。数据: 日线 + `minute_path`(首次触板、开板次数、板上成交占比、最低时刻、尾盘 30 分钟)。
2. **背景**: 段式箱体(KD1,draw_box)、20 日收盘箱体位置(KD7)、近 5 日成交里多少量的成本在现价之上(套牢盘)、情绪(全市场封板家数及升降温)、龙虎榜前三席位、导师近 7 天同票逐笔。
3. **关键价位逐个过**: T 最高(高位买入者解套位)、T 典型价(当天买入者平均成本)、T 最低、缺口、箱体上下沿、涨停价。每个价位算 P(T+1 摸到)、P(摸到后收回 / 守住),和基准比。**这就是用户说的"K1 买的人在 K2 顶部卖"的可计算版本**。
4. **多空力量 = 因子消融**: 在核心状态(票型 + 涨跌档 + 前一日票型 + 波动档)里,只把一个因子换掉(情绪中 vs 其他、升温 vs 其他、套牢盘档、箱体位置……),看 T+1 收盘中位和涨停率差多少。**差小于阈值的因子在推理链里只能写"无增量",不能拿来讲故事**。龙虎榜 / 导师 / 题材后面要用同样的办法验证后才进链。
5. **情景**: T+1 走法 top 概率(和基准并列)+ 全分布 + 极端情景。
6. **转换条件**: 9:25 就能看到的竞价开盘档 → 走法怎么变(例: 北新路桥开在 0~3% 时涨停概率从 9.8% 升到 23%)。下一步再加 10:00 的条件(前 30 分钟有没有摸到 T 典型价)。
7. **T+2 分支**: 按 T+1 前两种走法分别给 T+2 的分布。

叙述层(以后如果要让 LLM 把它写成人话)的规矩照 price-action-lab: 价位和概率由脚本算,LLM 只能引用;写出来的数字和脚本输出对不上就打回(PA_Agent 的 coherence_checks 做法)。

### B. 和 scen_v2 的统计概率怎么结合

- **分工**: scen_v2 给"会怎么走"(8 种走法的全概率、top3、极端情景);推理链给"为什么这么走"和"什么条件下换成另一个"。
- **怎么对上**: 每种走法其实是关键价位事件的组合 —— 冲高A杀 = 摸到 T 最高 / 涨停价后收回;深V = 跌破 T 最低后收回;单边下跌 = T 典型价都没摸到。所以每个 top3 情景下面挂: ① 它由哪几个价位事件构成;② 这些事件在同状态样本里的条件概率;③ 转换条件(竞价档 / 早盘 30 分钟)。
- **接口建议**(等 scen_v2 定稿,不改它的文件): 请 scen_v2 那边暴露两个东西 —— 走法判定函数(唯一出处,原型现在是照它文档串独立实现的一份,定稿后应该改成 import)和同状态样本的下标 / 样本键,这样推理链和情景概率用的是**同一批样本**,不会出现两套数对不上。
- **不重复**: 原型的 `T+1 走法` 一节在 scen_v2 定稿后应该删掉,直接显示 scen_v2 的 top3,原型只保留价位事件、因子消融和转换条件。

### C. 书图学习: 46 张图变成"形态卡"

**卡片格式**(放 `skills/market-skill/references/kline_study/cards/<KD 或形态 id>.md`,一张卡一个形态):

| 字段 | 内容 | 来源 |
|---|---|---|
| 图 | 书图路径 + 书名 / 图号 | img/ 现有 46 张 |
| 定义 | 书中原文要点(≤5 行) | 已有 book_*.md |
| 识别口径 | 机械规则 + 参数(指向 `kline_defs.P`) | KD 条目;没有的要补 |
| A 股坑 | 涨跌停截断、T+1、游资周期短 | KD 条目 |
| 我们的统计 | n / h1·h3·h5 分布 / 和基准的差 / 两段 / 置信 / 截至日 | KS 条目或新回测 |
| 我们的图 | 全市场近 2 年**最典型的 3 个实例**(按识别口径打分最高的),用 draw_box 同款画法出图 | 新做 |
| 反例 | 识别出来但走反的 3 个实例 | 新做 |

## 四、原型 `scripts/kline_study/pa_reason.py`

- 用法: `scripts/venv/Scripts/python.exe -X utf8 scripts/kline_study/pa_reason.py 002307 2026-10-23 [--json out.json] [--rebuild]`
- 零 token,不调 LLM;只发 SELECT(连接口径抄 `plan_review.py` 的 db(),另加会话只读);首次建全市场缓存约 55 秒(`results/kline/_pa_reason_cache.npz`,57MB,2024-01-02 起 333 万行),之后一只票约 5 秒。
- 样本: 沪深主板 + 创业板 + 科创板、非 ST;只用信号日 ≤ T−2 的样本(T 收盘时它的 T+1、T+2 都已走完)。同状态 = 票型 + 涨跌档 + 前一日票型 + 波动档 + 情绪 + 套牢盘档 + 20 日箱体位置,不到 100 个样本就从后往前放宽。
- **口径坑(写在代码里了)**: 库里 `kline_day.amount` 在 2026-10-09 之前**全是 NULL**,所以历史样本拿不到真实成交均价,统计口径统一用典型价 (高+低+收)/3 近似"当天买入者成本";个股逐根描述里有成交额的日子另报真实均价。

### 原型自己暴露出来的事实(对抗式审查)

- **大部分"讲故事"的因子增量很小**: 三只票里,情绪档、情绪升降温、套牢盘档、波动档的消融差多数在 ±1 个点以内;真正拉开差距的是**票型 + 前一日票型 + 波动档**这类 K 线状态本身,以及个别情况下的箱体位置。这和 PA_Agent research 的结论同向: 方向信息很薄。所以推理链最有用的部分是"价位事件的概率"和"转换条件",不是"多头强所以……"这类叙述。
- **"同状态"放到 7 个条件时样本很快掉到 100 左右**(北新路桥 n=123),差值 ±5 个点以内基本都在噪声里;所以置信最高只给到"中",n<200 一律"低"。

## 五、不自信点

1. **原型没有做任何样本外 / 前向验证**: 所有概率都是 2024-01~2026-10 的同期历史频率;这段行情偏题材牛,换到冷市可能整体偏移。
2. **典型价近似成交均价**: 库里 10/09 之前没有成交额,"当天买入者成本"在历史样本里用的是 (高+低+收)/3;炸板 / 尾盘拉升这类分时形态很偏的票,两者能差 2~4 个点(北新路桥 10/23 真实均价 3.62,典型价 3.51)。
3. **基准选择会改变"差"的大小**: 我用"同票型 + 涨跌档"当基准;换成全样本,差会大得多、看起来更"有信息"。哪个基准对用户最有意义,需要用户定。
4. **样本相互重叠、同日相关**: 同一天几十只炸板票的结果是相关的,n 看起来大,有效样本要小得多;没做按日聚类的标准误(KS3 / KS4 复核时就因为这个降了级)。
5. **走法 8 种是我照 scen_v2 文档串独立实现的**,阈值细节可能和 scen_v2 定稿版不一样;定稿后要改成直接 import,否则两边数对不上。
6. **题材 / 消息 / 龙虎榜 / 导师 只展示、没进概率**: 这几样对百洋股份、北新路桥这种游资票可能才是主因(第 1 次考试 KS7 就是 K 线统计没抓住题材爆发),原型没量化它们。
7. **外部项目只读了代码和文档,没运行**: PA_Agent 的 LLM 输出质量、price-action-lab 的回测数字我都没有复现,只能按它们自己写的报。albrooks-quant 是 404,没看到。
8. **书图建卡的 token 估算是粗估**(按一张图约 1 千多 token);实际以第一张卡试做为准。
