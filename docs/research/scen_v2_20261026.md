## 一、结论

### 1. 样本外对比

切分方式: 训练集是 T 在 2024-01-02 ~ 2026-06-26 的样本(T+2 也落在测试期之前);测试集是 T 在 **2026-07-01 ~ 10-21** 的样本,共 343,678 行。其中"强势异动票"(票型 0~7)20,397 行。
两条基线:
- 基线①: 全市场基础概率;
- 基线②: 只按票型的条件概率。这里的"票型"是 10 类 × 10cm/20cm × ST/非ST。

| 口径 | 指标 | **v2 模型** | 基线② 票型 | 基线① 全市场 |
|---|---|---|---|---|
| **强势异动票**(n=20,397) | 单日 log-loss(越小越好) | **1.466** | 1.555 | 2.101 |
| | 单日 top1 命中 | **51.4%** | 50.4% | 49.5% |
| | 单日 top3 命中 | **78.8%** | 76.5% | 70.6% |
| | 两日组合(64 种) log-loss | **2.859** | 2.985 | 3.682 |
| | 两日组合 top3 命中 | **49.2%** | 47.9% | 47.5% |
| 平常票: 箱体震荡 / 趋势(n=323,281) | 单日 log-loss | **0.549** | 0.588 | 0.610 |
| | 单日 top3 命中 | 97.24% | 97.25% | 97.26% |
| | 两日 top3 命中 | 84.4% | **85.0%** | 85.1% |
| 活跃平常票: 票型 8~9 但近 20 日 ≥2 次涨停(n=17,457) | 单日 log-loss | **1.235** | 1.355 | 1.438 |
| | 单日 top3 / 两日 top3 | 86.9% / 60.1% | 86.9% / **61.4%** | 86.9% / 61.4% |

逐个看:
- **强势异动票: 全面赢两条基线**(置信中)。单日 log-loss 比票型基线低 5.7%,top3 高 2.3pp,两日组合 top3 高 1.3pp。
  - 失效条件: 测试期只有 7~10 月约 80 个交易日,换一个市况段(比如单边暴跌月)不一定成立。
  - 拆到 8 个强势票型看,单日 log-loss **8 个全赢**。单日 top3 有 7 个赢、1 个输: 跌停失败 79.5% 对 80.0%。
  - 两日 top3 有 1 个输: 断板 57.3% 对 57.7%。
- **平常票: 概率更准,但 top3 没有赢**(置信高)。log-loss 低 6.6%。但平常票 85% 的情况都是"震荡",谁的 top3 都差不多能命中。两日 top3 反而比基线低 0.6pp。
- **活跃平常票: 两日 top3 输给基线 1.3pp**(置信中)。单日 log-loss 是赢的。
- **全市场合计**: 单日 log-loss 0.603(票型基线 0.645),两日 top3 82.4% 对 82.8%,两日 top3 小输。

**平常票 / 活跃平常票的两日 top3 赢不了基线,这里如实写出,没有再调参。**

### 2. 极端情景校准(强势异动票,单日,样本外)

| 情景 | 实际发生率 | 预测前 5% 那批实际发生率(模型 / 票型基线) | 分档: 预测均值 → 实际(n) |
|---|---|---|---|
| 涨停 | 9.3% | **41.9%** / 34.7% | 10~20%档 14.1 → 11.6(5147) · **20~30%档 23.9 → 21.3(1640)** · 30~50%档 37.3 → 33.1(661) · ≥50%档 61.4 → 63.2(299) |
| 跌停 | 6.1% | **24.0%** / 14.4% | 10~20%档 14.0 → 13.8(2625) · 20~30%档 24.4 → 19.9(979) · **30~50%档 36.8 → 19.9(527)** · ≥50%档 60.8 → 45.9(111) |
| 冲高A杀 | 6.0% | **18.7%** / 14.1% | 10~20%档 14.7 → 11.8(2317) · 20~30%档 24.1 → 18.5(1506) · **30~50%档 32.5 → 18.9(196)** |
| 深V | 5.9% | **37.4%** / 19.9% | 10~20%档 13.6 → 13.9(2156) · 20~30%档 23.6 → 16.2(433) · 30~50%档 39.4 → 51.3(234) · ≥50%档 64.1 → 73.4(222) |

逐个看:
- **涨停校准基本准**。用户问的"预测涨停 20% 的那批",实际是 21.3%(预测均值 23.9%,n=1,640),置信中高。
- **深V 和涨停的区分度明显好于基线**。挑出模型最看好的 5%,实际深V率 37% 对基线 20%,涨停率 42% 对 35%。
- **跌停和冲高A杀在 ≥20% 的高档系统性偏高**: 预测 30~50% 的,实际只有 19~20%。**跌停 / 冲高A杀给出 ≥20% 时,只当"比平时高好几倍"看,不要当字面概率。**置信中。
  - 推测原因: 7~10 月市况偏暖,训练期里的杀跌段被带进来了。

### 3. 改造中踩到并修掉的三个坑(否则上面的数会很好看但是假的)

1. **"同一天同一个值"的市场列 = 给每一天发身份证。**
   - 第一版把情绪、指数原值直接喂进 GBDT,早停又用的是随机切出来的验证集。树把训练期每一天的真实大盘走势背了下来。
   - 结果: 样本外"深V 预测 ≥50%"那一档,预测均值 60.9%,实际只有 **3.3%**(n=763);强势票 log-loss 1.580,**输给票型基线**。
   - 改法: 市场列按训练期每日值的五分位分 5 档;加交互约束(一条树枝最多用 1 个市场列);早停改用训练期最后 40 个交易日;平常票的模型干脆不放市场列。
2. **稀疏数据的"缺失 = 数据期之前",成了时代标记。**
   - 龙虎榜(2025-01 起)、导师账本(2025-09 起)、分时(2026-05-28 起)、题材(2026-01 起)、电报(2026-03 起)这 5 组一起放进模型,强势票 log-loss 从 1.471 变差到 1.499。
   - 只在各自有数据的时期公平比较,每组的增减都在 ±0.007 以内,属于噪声级: 龙虎榜 +0.004(变差),导师 −0.006,题材 −0.007,电报 +0.001。
   - 改法: 这 5 组**不进模型**,改为在输出里给"同类证据",也就是同票型真实样本的分布,带 n,供人工判断。用户点名要的龙虎榜和导师卖出后走势,都在这一块。
   - 消融还发现情绪组拿掉更好: 两个随机种子平均 1.4735 → 1.4641,种子噪声约 0.004。情绪也移到证据里(给"同情绪档"的真实分布)。指数组留着,拿掉会变差 +0.025。
3. **ST 票混进票型。**炸板票里 26% 是 ST(ST 的炸板 = 摸 +5%),跌停率差一截。基线、证据、近邻都改成按 ST / 非ST 分开。

## 三、怎么用、怎么建、要多久

```
# 必须用 anaconda python(项目 venv 没装 sklearn)
C:/Users/admin/anaconda3/python.exe -X utf8 scripts/kline_study/scen_v2.py all                 # 每晚一条, 实测约 3.5 分钟(24 核)
C:/Users/admin/anaconda3/python.exe -X utf8 scripts/kline_study/scen_v2.py 002307 2026-10-23   # 单票预测, 6~9 秒
```

- `all` 依次做: 特征表全量重建(约 2 分钟,3,071,010 行,parquet 561 MB)→ stronghot_core 训练(eval + prod,约 25 秒)→ nomkt_core 训练(约 80 秒)→ 混合样本外评估(约 30 秒)。
  - 全量重建已经够快,所以没做真正的增量。
  - 必须等收盘数据(日线 / 龙虎榜 / 账本 / 分钟)入库后再跑。
  - prod 模型用全部有标签数据训练,轮数取 eval 早停结果 ×1.1。
- `scen(code, T, horizon=2, kind="prod")` 返回(字段名都是中文):
  - 票型、状态摘要;
  - 全部 8 种走法 × 模型 / 票型基线 / 全市场基线;
  - **top3_单日**、**top3_两日**: 每个情景都有概率、两条基线、因子贡献(按组 + 单因子)、最像的 50 个同情景样本的 T+1 / T+2 路径分位、代表样本(真实开高低收按百分比套到本票价格;有分钟线就带 240 点分时);
  - **极端**: 涨停 / 跌停 / 冲高A杀 / 深V 的 T+1 概率(模型 + 基线)和 T+2 概率、两天内至少一次涨停 / 跌停,不在 top3 但 ≥3% 的各给代表样本;
  - 因子贡献、同类证据、导师卖出同票后的历史走势、样本外摘要、置信。
- 因子贡献的算法: 把一个因子(或一组)换成同大类(强势 / 平常)近一年随机 300 个样本的值,看概率变多少。它**不是因果**,组间有交互,加起来也不等于总偏离。
- 代表样本的选法: 加权 kNN(20 个关键特征标准化 + 权重,票型不同加罚),在"实际走出该情景"的样本里取最像的;分钟线日子优先(距离不超过最近那个的 1.5 倍)。
- **画图**: `draw_future.draw_v2(截图, "daily" | "intra", 代码, scen() 的输出, 输出目录, 截止日, C=, g=)`。
  - 每个情景(top3 两日组合 + 极端)各出一张,日 K 续画 2 根,分时 / 五日续画 2 天(有分钟线画真实分时,没有就按开高低收画示意)。
  - 文字面板写情景名、概率(含票型基线)、2 天的开高低收、近邻 50 样本的收盘分位、单因子贡献 top3、置信、代表样本出处。
  - 旧的 `daily()` / `intraday()` 原样保留。**`kline_inbox.py` 没改。**
  - 用 10/24 收件箱的天娱数科截图做过冒烟测试,日 K 和五日都能画,测试图已删。
  - 主会话接入要注意两点: ① `scen()` 的 T 传**截止日**(10/23),不是 next_day;② kline_inbox 如果用 venv 跑,要么给 venv 装 sklearn,要么用 anaconda 子进程调用。

## 五、不自信点

1. **模型挑选和最终评估用的是同一段测试期。**前后比了约 8 个变体(原值 / 分档 / 去市场列 / 只强势 / 含活跃票 / 分流方式 / 去稀疏组 / 去情绪),报告的"赢多少"偏乐观。真正干净的样本外要从 10/26 起滚动记账,建议每晚把 `scen()` 对当天强势票的预测存下来,次日对答案。
2. **测试期只有 7~10 月约 80 个交易日、一种市况。**强势票 2 万行来自这 80 天,同一天的票高度相关,有效样本远小于 2 万。我没算置信区间。
3. **指数组的贡献(0.046)也是按天的列**,可能只在这一段市况里成立。
4. **跌停 / 冲高A杀高档偏高**: 给 ≥20% 时实际低 5~17pp。
5. **两日组合是条件独立假设拼出来的**,平常票和活跃平常票的两日 top3 输给基线。
6. **因子贡献是单因子替换法,不是因果。**比如"票型 = 炸板 → −2.4pp"的意思是"换成其他强势票型的平均",不能理解成"炸板让它少涨"。
7. **同类证据是原始条件频率**,没控制其他因子,也没按年份查稳定性。比如海欣股份的低吸型席位那条。
8. **导师持有数用逐笔腿累加**,账本起点前的老仓看不到,可能低估。正负样本标签来自 `tzzb_ledgers.json`,没有逐个核对 negstats。
9. **段式箱体是因果版**(每天只用当天之前的数据),和 `draw_box.py` 事后画的箱体可能不完全一样。
10. **成交额是估算的**(量 × 开高低收均价),库里 2026-10 之前没有成交额和换手率。
11. **分钟线只有 100 天**,很多代表样本没有真实分时,画图会退回示意线。分时形态口径今晚改过一次: 原来把第一分钟收盘当开盘,北新路桥这种秒板票被判成了探底回升。
12. **一次没复现的异常**: 某一轮 `scen()` 里北新路桥的"同类证据"全部返回 n=0。之后单独调用和整轮重跑 3 次都正常,原因没查明。
13. 预测只用了 T 收盘前的信息,**周一竞价、周末消息都没进模型**。
