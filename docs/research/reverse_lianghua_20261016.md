## 不自信点

1. **概率分布的似然比是主观的**。「App 按钮式整分数」「卖单整数价」两条强证据指向人手下单, 但程序也可以模仿(券商 API 按可用资金分数下单 + 整数限价)。
2. 现金推算依赖净值表 asset × (1-收盘仓位) 得到早盘可用资金, 忽略了两融/在途资金/费用; 「30 秒内同票连续腿并为一单」可能把部分成交拆开或把两单合并。整分数占比可能被低估。
3. 选股负样本=全市场(含北交所/ETF), 没有行业/概念库, 「同题材候选」只能用 md 涨停分析的题材(覆盖不全)。选股不可复现可能部分是特征不全造成的, 不一定是主观。
4. 分钟层只覆盖他**买了**的票; 全市场同时刻的盘中状态我们没有(10/09 前无全市场分钟线), 所以「盘中选股」无法检验, 只能检验「已选中的票在何时买」。
5. 回放的模拟买价: 规则票没有分钟线时用 (O+H+L+C)/4 代理, 买入时点误差会被这个代理放大/缩小; 次日按开盘价卖(竞价)。港股/转债/日内 T 不在回放里。
6. 版本切换用的是单切点 t 检验, 多指标多重比较, |t|≥3.5 也可能有假阳性; 港股占比在 3 月、8 月有明显簇, 可能是题材驱动而不是程序换版本。
7. 时间外只有约 55 个交易日、~140 笔新开仓, 覆盖率的 95% 区间大约 ±5 个百分点。

## 建议

- **A-lianghuaxiaohao 链不建议改成「规则出单、LLM 只做异常复核」的全规则模式**: 选股层时间外命中接近随机, 规则出的票和真人基本不重合。
- 可以改成**混合模式**: 执行层(次日开盘窗清仓 + 竞价/连续竞价按缺口 + 满仓 + K≈2~3 只 + 1/K 资金分配 + 09:3x~09:5x 买入窗 + 不在回落中买)用 `--signal` 的规则零 token 固化; 选股仍交 LLM(或改为「候选池规则 + LLM 在池内挑 2~3 只」, 池子由 `--signal` 输出的 candidates 提供)。
- 先修 mentor_fingerprint 的科创板成交量口径(10/09 前 ÷100), 否则指纹表「成交额≥30 亿/换手≥20%」对科创票是放大的。
- 想继续逼近选股: 需要全市场盘中分钟线(至少候选池 Top200)回补, 和行业/概念归属库; 有了再用本脚本的 `rank_eval` 框架复测。
