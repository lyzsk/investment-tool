# 条件单组离线测试 + 区间引擎(10/25 夜, 只用现有数据, 零 token, 没上线)

> 范围: 用户 10/25 看 10/23 回放后指出"卖得太急、固定价一碰就成交、二封后封板价卖掉"。今晚做了 区间引擎 + 条件单组模拟器, 用 10/23 五个案例和 10/12~10/23 十个交易日的批量样本离线测。**不接实盘、不改 executor**。
> 「封板状态」原型(board_state.py)按 10/25 晚的调整改由主会话做, 本文不涉及。
> 口径: 收益一律扣 0.1% 单边成本; "相对收盘" = 卖出均价相对当天收盘(>0 = 比拿到收盘卖得好); "区间位置" = 卖价在决策时刻之后当天最高 / 最低之间的位置(0 = 最低, 1 = 最高); "卖飞" = 最后一笔卖出后当天又涨 ≥3%。置信: 高 = 多日稳定 + n≥300; 中 = 方向一致但只有部分日子成立; 低 = 被一两天主导或 n 小。

**一句话**: 条件单组的价值是**防止卖在下跌半山腰、防止低吸买在半山腰、防踏空**(改的是分布尾部); 它不制造 alpha, 均值上和"分两次卖"差不多。真正决定盈亏的仍是"卖不卖 / 买不买"和当天的市况。封板票上, 回落阈值用 1%(不是 2~3%); 二封票在这 10 天的数据里, "回封就卖"并不比"封住拿着"差。

## 一、产物和用法

| 文件 | 做什么 |
|---|---|
| `scripts/live/range_engine.py` | 区间引擎。`python range_engine.py query <代码> <D> <HH:MM>` → 同状态样本之后 30 / 60 分钟 / 到收盘 最高·最低·收盘 的 n / P10 / P25 / P50 / P75 / P90 / 均值 / 最差 / 最好, 以及 碰到均价 / 开盘价 / 昨收 / 涨停 / 跌停 / 再创新低 的概率。`selftest` 断言: 特征只用当时及以前的数据(截断后重算等于全天算)、**改掉 T 之后的数据结果不变**(不偷看)、分位单调、海欣股份 09:36 状态对得上(现价 8.16, 均价 8.26, 绿柱) |
| `scripts/live/bracket_sim.py` | 条件单组模拟器。字段对齐 executor 10/25 的 `type: "cond"`(ref / dir / pct / book / arm / after; "日内最高 / 最低" = 单子生效后的最高 / 最低); 扩展字段(executor 还没有): gate(反抽 / 恐慌盘卖完 / 站上均价且放量 / 第 n 次开板 / 时刻)、px_from(挂价取区间引擎分位)、pct = {amp_k}(按振幅) 或 {q}(按区间引擎分位)、unless_filled(低吸成交就不追)、cancel_below(跌破就撤)。`selftest` 断言 9 条撮合语义 |
| `scripts/live/bracket_offline.py` | 离线测试: `cases`(10/23 五个案例)、`batch`(急跌卖 / 低吸买 + 敏感性)、`board [--reseal]`(封板 / 二封)、`exec`(只用 executor 现有字段) |
| `results/_bracket/` | 原始结果 json + md 表; `analyze_batch.py` / `analyze2.py` / `analyze_board.py` 是本文配对、分日、分振幅、分市况、消融数字的来源; `cache/`(约 530MB)是分钟矩阵和样本池缓存, 可删, 删了重跑 `range_engine.py build` 约 2 分钟 |

**区间引擎做法**: 样本池 = D 之前 40 个交易日、每只股票每 2 分钟一个时点(10/09 起关注集用 1 分钟 OHLC, 更早的用 240 点收盘价路径, 高 = 低 = 收)+ D 当天 T 之前已经走完的 30 / 60 分钟窗口。按 11 个特征分桶: 涨跌停状态(封涨停 / 碰过涨停现在开着 / 在跌停 / 碰过跌停)、板块(主板 / 创业科创 / ST)、离分时均价、1 分钟 MACD(绿柱 ≥3 / 绿 1~2 / 红 1~2 / 红 ≥3)、时段、开盘后最大跌幅、离日内最低的反弹、RSI6、开盘缺口、量能(近 5 根 / 前 30 根)、日线 20 日箱体位置; 样本 < 40 就按 箱体 → 量能 → 缺口 → RSI → 反弹 → 跌幅 → 时段粗分 → MACD 的顺序逐级放宽, 输出里写明放宽到第几级、去掉了哪些。查询一次约 5 毫秒(第一次加载样本池约 9 秒)。

**撮合规则**: 逐分钟按 开→低→高→收(阳线)/ 开→高→低→收(阴线)走; 限价价格穿过才全部成交, 只碰到挂价成交剩余的 50%, 开盘跳空越过挂价按开盘价; 挂在涨停价卖 / 跌停价买, 碰到就全部成交(有排队的对手盘); 条件单命中按 买一 / 卖一(触发价向下 / 向上取整到分)一次成交; 一根 K 线 高 = 低 = 涨停 时买不进、= 跌停 时卖不出; 决策只用到本根收盘, 下一根才开始撮合。

**和主会话统计的交叉核对**: 海欣股份 10/23 09:36(离均价 −1.23%、绿柱、开盘后跌 −4.1%), 区间引擎给"之后 60 分钟碰到均价 47%", 和主会话 n=1621 的"转红时离均价 1~3% 的 47% 能碰到均价"一致(口径不完全同: 我这里还没转红)。

## 四、条件单参数建议(给 06, 对齐 executor 10/25 的 `type: "cond"` 字段)

振幅 = 本票 D 之前 20 个交易日"日内最高 / 最低 −1"的中位数(必查里要给这个数, executor 的 pct 只收数字, 06 自己乘)。急跌样本的振幅三分位界: 3.9% / 5.6%。

| 用途 | 写法 | 建议 pct | 依据(n / 置信) |
|---|---|---|---|
| 封板拿着、开板就走 | `ref: "涨停价", dir: "down", pct: 1, book: "b1", qty: 全部或一半` | **固定 1%**(主板), 不按振幅缩放; 不要用 2~3% | 3.3(a) n=467: 1% −0.04, 2% −0.45, 3% −0.65, 0.3×振幅 −0.18(相对碰板就卖); 中 |
| 二封后拿着 | 同上 pct 1 | 1%;**并且 06 要知道: 这 10 天"回封就卖"平均更好 0.5%**, 拿着的理由必须来自导师规则 / 题材地位, 不能只因为"封住了" | 3.3(b) n=158, 7/9 天; 低~中 |
| 反抽后防卖飞(移动止盈) | `ref: "日内最高", dir: "down", pct: 0.8×振幅, after: 第一档`(clip 1.5%~6%) | **0.8×振幅**(振幅 4% → 3.2%; 振幅 6% → 4.8%); 0.25~0.5 太紧 | 3.1 敏感性, 三个振幅档一致; 中 |
| 反抽时机(executor 没有反抽信号时的近似) | `ref: "日内最低", dir: "up", pct: 0.8×振幅, side: "SELL", qty: 一半` + 上一行移动止盈管剩余 | 0.8×振幅 | E3 n=1332: −0.54 / 卖飞 11%, 接近 A; 中 |
| 低吸没买到防踏空 | `ref: "日内最低", dir: "up", pct: 0.5×振幅, side: "BUY", book: "a1", qty: 一半` | **0.5×振幅**; 高振幅票(>5.6%)可用 0.8 | 3.2: 踏空 19% → 1.4%, 均值不降; 中 |
| 反抽前的硬止损 | 不建议(急跌后的持仓) | — | A' 均值 −0.23、48% 被止损; 中 |
| 低吸撤单(不接飞刀) | 价格跌破恐慌低点 −3% 撤买单 | executor 没有"撤单条件", 先用 wake 叫醒 | G 失败率 8.4% vs 立即买 19.7%; 中 |

**挂价分档(限价单)**: 卖第一档 = 区间引擎"同状态之后 60 分钟最高"的 P50(要更多成交用 P25); 低吸两档 = "之后 60 分钟最低"的 P50 / P25。模型不写数字, 写 `px_from`; 上线前需要 pack / 必查把区间引擎的 P25 / P50 / P75 直接算成价格给 06。

## 六、上线建议

按用户 10/25"条件单明天上线"(主会话已在 executor 加了 `type: "cond"`), 本次数据支持的先后顺序:

1. **先上: 封板票"开板回落 1%"**(`ref: 涨停价, dir: down, pct: 1`)。最清楚的一条: 阈值单调(1% > 2% > 3%), 9 天里 5 天和"碰板就卖"打平、右尾更长。06 的 why 里要写"拿着的理由"(导师规则 / 题材地位), 因为二封情境下拿过夜这 10 天平均是亏的。
2. **先上: 移动止盈 0.8×振幅** 管"卖了一半之后的剩余"(`ref: 日内最高, dir: down, after: 第一档`)。卖飞率降得最多, 三个振幅档一致。
3. **先上: 低吸的防踏空 0.5×振幅**(`ref: 日内最低, dir: up, side: BUY`)。前提: executor 补"第一档 / 第二档成交了就作废"(本次 unless_filled), 不补的话会差约 0.2%、失败率 8% → 12%。
4. **后上(要改 executor)**: 术语表"反抽"信号(红柱 ≥3 + RSI6>80 + 价 ≥ 均价 −0.2%)作为条件单的生效条件(gate); 挂价 `px_from` 由区间引擎给; 低吸的"跌破恐慌低点 −3% 撤单"。在这之前用 E3 近似(日内最低反弹 0.8×振幅 卖一半)。
5. **不上**: 急跌后持仓的反抽前硬止损; "第 2 次开板后才开始算回落"(n_open 门槛, 两个口径都差)。
6. **06 的提示词要改的口径**: 卖急跌持仓时, 不许在绿柱 / 均价下方按固定价卖(术语表已写); 已经在冲高里(RSI 高)的票别等反抽, 直接按区间分档挂(百洋股份教训); 引用统计要分"当天"和"次日", 两个都要。

## 七、不自信点

1. **只有 10 个交易日**, 10/22 和 10/23 两天占急跌样本 42%、方向相反。所有"均值"结论都可能翻; 只有"尾部变化"(卖飞、P10)和"阈值单调"(1% > 2% > 3%、0.25 < 0.8)比较可信。
2. **分钟线撮合是近似**: 一根 K 线内的先后顺序是猜的(开→低→高→收 / 开→高→低→收); 炸板那一下 3 秒快照可能直接从涨停跳到 −3%, 分钟线上看不出, 1% 回落阈值的实际成交价可能比模拟差; "只碰到成交 50%"这个假设没验证。
3. **样本只有关注集**(约 1000 只, 10/09 起有 1 分钟 OHLC), 偏强势股; 区间引擎更早的样本只有收盘价路径(高 = 低 = 收), 会低估盘中最高 / 最低的分布宽度 —— 引擎的 P50 / P75 挂价可能偏保守。
4. **"拿过夜"按次日开盘估值**, 实际导师多在次日冲高时卖; 用次日最高估值结论会不同(没算, 因为次日最高事先不可得)。
5. 急跌样本的定义(开盘后 60 分钟内跌破开盘 −3%)是我定的, 没和用户 / 主会话的"急跌"口径对齐; 主会话的 n=1621 统计是"急跌后 MACD 转红", 起点比我晚。
6. 区间引擎的分桶边界和放宽顺序是拍的, 没调参也没做样本外校准(比如"P50 的实际命中率是不是 50%")—— 这是上线前最该补的检查。
7. 案例里的"导师怎么卖"只有百洋股份(刘忆青、芷影)和太极股份(芷影)有当天逐笔, 海欣股份、北新路桥(只有买)、吉大正元没有, 案例对比"条件单 vs 导师"只有两只票。
8. 没测"延迟确认"(触发条件连续满足 N 次才下单), 1% 阈值下它可能很重要。
