## 〇、先说结论

1. **能用，建议周二上线，但只当"参考附件"，不当买卖依据**（置信 中 · n=98 道考题，两个时间窗）。按我人工判读，默认权重下检索出的案例 **75% 像、25% 部分像、0 不像**（n=147 个案例 / 49 道题；判的人就是写检索的人，有自评偏差，置信 中低）。按另一套更严的机械规则判，"像"只有 46%（10/20~10/23）和 53%（10/09~10/16）。
2. **权重：结构为主**。推荐 **结构 0.7 / 拓扑 0.2 / 语义 0.1**（置信 中 · n=98 题）。几种"结构占大头"的配法（0.5/0.3/0.2、0.7/0.2/0.1、0.8/0.1/0.1、只看结构）彼此之间的差距在误差范围里；**只看语义、只看拓扑这两种明显更差**（比 0.5/0.3/0.2 低 8~25 个百分点，两个窗口方向一致，置信 中高）。
3. **放宽顺序比权重重要**。先去掉"总仓位→市况→箱体位置"这三项，再把持仓、开盘、价位"并邻档"，最后才真去掉——比"一条一条直接删"格子小得多（平均 31 vs 184 笔），像的比例也不低。把顺序反过来（先删最重要的）像的比例掉一半（严判 23~36% vs 46~53%，置信 中高 · n=98）。
4. **三个重点案例**：K1 太极股份——找到了同一手法（悟到空方为悟道 竞业达：炸板次日跌停开、补仓后 36 分钟反抽卖 +6.9%；还有芷影自己 2025-12-08 海王生物"竞价低吸 + 开盘高抛"的原文）。K2 百洋股份——**库里真正同类（炸板收跌 + 深套 + 次日越跌越买）只有 8 个买入案例**，最像的那个是负样本（鳄狼King 中百集团，3 天 −20%）。K3 澳弘转债——找到 10-12 澳弘"转债 −2.5% / 正股 −6.3% 还竞价买"，但暴露出一个问题：**3 天标签不适合秒进秒出的人**。
5. **事件本体抽查 30 条：30 条连接都对得上 md 原文**（置信 中 · n=30）。但"阶段 / 本波第几天"字段有 2/20 错（md 题材名每天在变，导致本波天数被重置）；席位风格 md 里没有，没法核。
6. **速度**：查询本身约 0.1 秒（情境 10 ms + bge-m3 一句话 40~90 ms + 检索打分 20~60 ms）；命令行一次约 1.2 秒（含 Python 启动和载入索引）。每晚增量建索引约 2 分钟；第一次全量建约 17 分钟。

**说明（偏离设计的地方，都有理由）**
- **cases_auto.jsonl 没有单独再建一份**：它和 bs_leg 是同一批交易，单独建会让同一笔交易出现两次；它的打法标签通过日卡成交行的方括号标签带进来了。
- **sample_lib 的样例也没有原样搬进来**：同样是同一批逐笔腿；我按决策点重新切，并且**标签按查询日 D 截断重算**（sample_lib 的标签用了全部后续行情）。标签口径照用户 10/25 定的：X = 买入前 30 日日振幅中位，T+1~T+3 任一天最高 ≥ 买价×(1+X%) 为正；3 天都没冲到且 T+3 收盘 < 买价为负；其余为平。
- **"板型买点"换成了"昨日状态 + 动作类"**：sample_lib 的板型用的是买入当天全天走势（它的文档里自己写了"不是盘中可用的信号"）。检索要在盘中用，所以只用决策时已知的东西：昨日状态（涨停 / 炸板·收涨 / 炸板·收跌 / 跌停 / 大涨 / 大跌 / 平）+ 动作类（买：竞价 / 打板 / 追涨 / 低吸 / 平价；卖：日内T / 止损 / 冲高止盈 / 止盈 / 平走，只用成交价相对开盘和昨收、时刻、浮盈来定）。
- **卖出也有标签（我提议的，置信 低）**：卖后 T+1~T+3 任一天收盘 ≥ 卖价×(1+X%) 为负（卖飞）；3 天收盘都没到、且 T+3 收盘 ≤ 卖价为正（卖对）；其余为平。用户没定过这个口径，请过目。

### 2. 四层怎么落地的

1. **硬条件过滤（格子）**：品种（股票 / 转债 / 妖债，妖债 = 价格 ≥ 200 或日振幅中位 ≥ 6%）、方向——这两项永不放宽；然后是 昨日状态、动作类、价位档（成交价较昨收）、开盘区间（D 当天开盘价，09:25 已知）、持仓状态（未持有 / 浮盈 0~5% / 浮盈 >5% / 被套 0~5% / 被套 >5%，**按决策价算浮盈**，当天更早买的也算进去）、连板高度、正股开盘区间（转债专用）、箱体位置、市况（T−1 上证强平弱 × 涨停家数冷中热）、总仓位，另加"当天加仓位置"（首笔 / 加仓·更低 / 加仓·更高）参与打分。
2. **拓扑加分**：同票 0.5、同题材 0.3、同梯队位置 0.1、同席位（昨日龙虎榜同营业部）0.25、同导师 0.2，封顶 1。题材 / 梯队 / 席位全部来自事件本体，**只用 D 前一交易日及以前的**。
3. **语义排序**：bge-m3（本地 ollama，请求带 keep_alive=30m）。查询那句话 vs 案例文字（情境 + 日卡成交 + 竞价 + 解读 + md 推测，**不含结果**）。
4. **正负标签**：截至 D 重算。附件里**正样本只从正样本账户里挑**；负样本可以来自任何账户，并且标题就写"如果错了（只当教训，不当依据）"。

### 4. 严禁偷看未来：怎么保证的，查过没有

- 案例只取 d < D；标签只用 D 之前的行情重算（还没走完 3 天的标"待核"）；"之后怎么卖的"只显示 D 之前发生的。
- 日卡"解读"和 md 推测是事后写的：**案例的次日 ≥ D 时，不显示解读，语义向量也换成不含解读的版本**（另存了一套"基础向量"）。
- 原文库只取"已知日 < D"；cases.md 的已知日 = 段落里提到的最晚日期。
- 查询情境：只用 D 之前的日线 + D 的开盘价 + 成交价；D 的最高 / 最低 / 收盘在读行情时就截掉了。

## 二、验证怎么做的

- **考题**：10/20~10/23 四位导师（芷影攫心、刘忆青、不吃土豆0、做手德融）的真实买卖，按决策点切出 **48 题**，加 1 道虚拟题 K3（10-23 不吃土豆0 的账本还没抓到，见第四节），共 **49 题**。另取 **10/09~10/16 同四位导师 49 题做对照窗口**（权重、规则都是在 10/20~10/23 上调的，对照窗口用来检查是不是调过头了）。
- **每题**：跑 8 组权重 + 4 种放宽 / 过滤做法，每种取 3 个案例（正 2 + 负 1）。
- **两种判法**：
  - **人工判**（我自己逐题读附件）：只判默认权重这一组，147 个案例。像 = 处境（昨日状态、开盘 / 价位、持仓盈亏）和动作都对得上；部分像 = 有一两处明显不同（比如浮亏 −2% vs −12%，竞价 vs 午后）；不像 = 处境或动作根本不同。
  - **机械严判**（和检索打分不同源，用来比较各组权重）：数值近 = 开盘差 ≤2 点、成交价差 ≤2 点、浮盈差 ≤4 点，三项对上 ≥2 项；行为近 = 日卡行为标签一致（买：主打法 + 执行方式；卖：卖出类型），或日卡"手法类"一致。两项都满足才算像。日卡标签和手法类部分是事后口径，所以**只用于评估，不进检索**。
- **误差**：同一只票同一天拆成多题，题目之间不独立 → 按"票 × 日"成簇 bootstrap 2000 次，给 90% 区间和"与 0.5/0.3/0.2 的配对差"。

## 三、结果

### 1. 像的比例

**人工判（默认权重 0.7/0.2/0.1，10/20~10/23，n=147 个案例 / 49 题）：像 110（75%）· 部分像 37（25%）· 不像 0。**（置信 中低：判的人就是写检索的人；硬过滤保证了格子里的票在大类上一定对得上，所以"不像"为 0 不奇怪。）
- 正样本 65/98 像（66%），负样本 45/49 像（92%）。负样本更像，说明**和当下最像的历史案例里，赔钱的不少**——这本身是信息，附件里如实给。
- 人工判 vs 机械严判：两边都判"像"60 个，机械更严（人工像、机械部分像 46 个）；机械判"像"的 67 个里人工也判像 60 个（90%）。

**机械严判，各组权重 / 做法（"像"的比例；括号里是成簇 bootstrap 和 A 的配对差 90% 区间）**

| 方案 | 10/20~10/23（调参窗口，n=147） | 10/09~10/16（对照窗口，n=147） |
|---|---|---|
| A 结构 0.5 / 拓扑 0.3 / 语义 0.2（设计稿例子） | 46% | 52% |
| B 0.3 / 0.3 / 0.4 | 44%（−5~0） | 51%（−4~+1） |
| **C 0.7 / 0.2 / 0.1（推荐）** | **46%（−3~+3）** | **53%（−2~+4）** |
| D 0.4 / 0.4 / 0.2 | 46%（−2~+2） | 50%（−5~0） |
| E 等权 | 44%（−4~+1） | 51%（−4~+1） |
| C2 0.6 / 0.2 / 0.2 | 44%（−6~+1） | 54%（−1~+4） |
| C3 0.8 / 0.1 / 0.1 | 48%（−2~+7） | 54%（−4~+6） |
| C4 0.6 / 0.3 / 0.1 | 46%（−2~+3） | 54%（−1~+5） |
| F 只结构 | 48%（−3~+8） | 51%（−7~+4） |
| G 只语义 | **29%（−25~−10）** | **37%（−23~−8）** |
| H 只拓扑 | **37%（−18~−3）** | **39%（−20~−7）** |
| 放宽顺序反转（先删最重要的） | **23%（−38~−11）** | **36%（−24~−7）** |
| 旧放宽（10/25 初版：一条一条直接删，不并邻档） | 39%（−15~−1） | 49%（−10~+4） |
| 动作类不做硬过滤（只打分） | 46%（−4~+5） | 51%（−6~+3） |
| 不做硬过滤（全库直接排序） | 44%（−11~+4） | 54%（−5~+8） |

读法：
- 结构占大头的几组（A / C / C3 / F）彼此差不出来；**只靠语义、只靠拓扑都明显差**（两个窗口都差 8~25 点）。推荐 C 是因为它两个窗口都排在前面、又保留了一点语义和拓扑（语义负责挑原文、在结构打平时排序；拓扑负责"同票、同席位"这类人一看就懂的理由）（置信 中 · n=98 题）。
- 拆开看：语义只管"行为像不像"时不算差（只语义的"行为近"59~63%，C 是 67~73%），但它挑出来的案例数值上常对不上（只语义的"数值近"50~71%，C 是 74~89%）。
- **"不做硬过滤"挑出来的 3 个案例并不比过滤后差**——硬过滤的价值主要在**分布**：不过滤的话"格子"就是全库 4,000 多笔，那个分布没有意义（置信 中）。
- 对照窗口整体比调参窗口高 5~7 点，没有看到"在 10/20~10/23 调过头、换个窗口就塌"的迹象（置信 中 · n=49+49 题）。

### 2. 放宽

- 默认放宽顺序：去掉总仓位 → 去掉市况 → 去掉箱体位置 → 并邻档持仓状态 → 并邻档开盘区间 → 并邻档正股开盘区间 → 去掉品种（转债 / 妖债）→ 并邻档价位档 → 去掉连板高度 → 去掉开盘区间 → 并邻档昨日状态 → 去掉正股开盘区间 → 去掉动作类 → 去掉价位档 → 去掉持仓状态。（"并邻档"= 有序档位放宽到相邻一档；持仓状态并成"未持有 / 浮盈 / 被套"三类；昨日状态并成"强 / 炸板 / 平 / 弱"。）
- 49 题全部要放宽：放宽步数 2 步 2 题、3 步 4 题、5 步 12 题、6~9 步 19 题、10 步以上 12 题（10/20~10/23）。**格子 n ≥ 15 这条线对 14,000 个决策点来说偏高**，硬条件 10 项全对上的格子基本不存在（置信 高）。
- 最常用到的是前 5 步（总仓位 49 次、市况 49、箱体 47、持仓并邻档 43、开盘并邻档 43）；"去掉持仓状态"一次都没用到。

### 3. 速度（n=49 题，10/20~10/23）

| 环节 | 中位 | 最大 |
|---|---|---|
| 情境计算（读行情、算特征） | 10 ms | 50 ms |
| bge-m3 一句话（热状态） | 40~90 ms | 180 ms |
| 检索打分 | 20~60 ms | 110 ms |
| 命令行一次（含 Python 启动 + 载入索引） | 约 1.2 s | — |

- 原来实测一句话要 2 秒多，**原因是请求地址写 localhost，Windows 先试 IPv6 失败再回落**；改成 127.0.0.1 后 15~90 ms（置信 高）。
- 建索引：第一次全量 embed 约 2.2 万段，约 17 分钟（GPU）；之后按文字 hash 增量，每晚约 1.5~2.5 分钟（实测 100~140 秒，新增 embed 不到 15 秒）。

### K1 · 10-23 太极股份（芷影攫心 竞价低开 −8.2% 低吸降成本）

- **真实情况**：10-22 首板次日追涨买入（被套），10-22 当天炸板收 +4.5%；10-23 竞价 −8.2% 开，09:25 在 14.04~14.08 加 4 腿，09:30:15 开盘反抽到 −4.2% 附近卖 9 腿（较竞价买价 +3%），之后 10:06 在 −7% 附近、11:16 在跌停价又接，午后反抽里分批卖，收盘这只票仓位从 26% 变 30%。
- **检索到的**（格子 n=34，正 23 / 负 8，放宽 10 步）：
  - 正·**悟到空方为悟道 2026-09-04 竞业达**：昨日炸板、当天**跌停开**、手里被套 −13%，09:41 在跌停价补一腿，**36 分钟后反抽到 −3.8% 卖出 +6.9%**——和芷影这一手是同一个手法（我判 像）。

  - 格子里"实际怎么出的"：**当天就 T 掉的 15 笔平均 +2.5%（最差 −2.7%）；拖到 T+1 才卖的 16 笔平均 −2.0%（最差 −28.6%）**。

  - 原文：md 2026-10-15 账本推测"首次没在竞价买：竞价低开后等开盘第一分钟转债与正股同步急拉才追进；'低开就不进竞价'被 10-12 反例否掉"。
- **补充统计（`case_retrieval_k3.py`，因为案例库只收"做了的"，不收"那天他没做"）**：
  - 他开始做澳弘（09-16）以后，转债正股双双低开的日子 **4 天，3 天竞价买**（09-23 / 10-12 / 10-20），竞价买到首笔卖分别 +4.95% / +0.26% / +1.14%；10-15 没竞价买、开盘后追进（置信 低 · n=4）。
  - 放宽到"他在做的所有转债、前后 5 个交易日内"：双双低开 175 天，竞价买 14 天（8%），这 14 次竞价买到首笔卖平均 +1.37%、最差 −0.36%（置信 中低 · n=14；"在做"的定义很粗，175 天里很多天他其实没在盯那只债）。
  - 10-23 实际走势：开盘 235.0 → 09:31 收 244.0（较开盘 +3.8%）→ 09:34 最高 254.0（+8.1%）→ 全天最低 226.5、收 231.1。**如果照他的老套路"竞价买、开盘一两分钟卖"，这天是能赚的**；但他实际做没做、怎么做的，要等账本抓到才知道。
- **判断**：检索**找到了**最关键的先例（10-12）。同时暴露一个口径问题：**3 天标签对秒进秒出的人没意义**——10-12 那笔他 09:30 就 +0.2% 卖了，却因为转债次日涨 20% 被标成"正"。附件新加的"实际怎么出的"一行（K3：17 笔全部当天卖，平均 +1.2%，最差 −0.4%）比 3 天分布更有用（置信 中 · n=17）。

## 七、不自信点

1. **人工判是我自己判的**（75% 像）：判的人就是设计检索的人，偏宽。机械严判（46~53%）是下限参考。两者之间的真实数字，最好请用户或另一个模型盲判一部分（置信 低）。
2. **权重差异大多在噪声里**：除了"只语义 / 只拓扑 / 放宽反转"这三种明显差，其余配法 90% 区间互相重叠。推荐 0.7/0.2/0.1 是"不比别的差 + 理由好解释"，不是"显著更好"（置信 中）。
3. **机械严判和结构打分有重叠**：严判的"数值近"用的开盘、价位、浮盈，结构打分里也有，所以严判天然偏向结构权重大的配法。"行为近"那一半是独立的，结构为主的配法在那一半上也不输（67~73% vs 只语义 59~63%）。
4. **考题集中**：49 题里芷影攫心 30 题，百洋股份 13 题、太极股份 10 题、吉大正元 10 题，三只票占 33 题；"票 × 日"只有 19 簇（对照窗口 34 簇）。刘忆青 8 题、不吃土豆0 7 题、做手德融 4 题（对照窗口分别 10 / 10 / 9），结论对他们更不稳。
5. **3 天标签不适合日内型导师**（不吃土豆0 这类秒进秒出、芷影的当天 T）：正负标签说的是"之后 3 天票怎么走"，不是"他这笔做得好不好"。附件新加了"实际怎么出的"一行补这个，但标签本身没改（用户口径，我没动）。
6. **负样本账户占格子一半**（K1 的格子 34 笔里 16 笔来自护卫港 / 鳄狼King / 洋大人）：整体分布会被拉低。附件已单列"只看正样本账户"，但格子 n 和正率用的仍是全部。
7. **日卡数据口径偶有矛盾**：比如 antoo 海川智能 2026-03-27，日卡"昨收持仓"写浮 −8.9%，同一天"成交"行写卖出盈亏 +53.8%（持 11 天）——两处成本口径不同。我优先用日卡昨收浮盈，个别案例的"被套 / 浮盈"可能标反（影响面没统计）。
8. **"动作类"里的低吸 / 追涨是我定的阈值**（较开盘 ±2 点、较昨收 +5%），没有做敏感性测试。
9. **事件本体题材名漂移**会影响拓扑里的"同题材"和"阶段"，抽查只看到 3 例，实际比例不清楚。
10. **最后一次重跑验证时 `scripts/PAUSE` 已经删了**，那一轮约 50 次单句 embed（1 分钟内）没有挂暂停标记，是我流程上的疏漏；当时没有核对 GPU 上有没有别的长任务。
