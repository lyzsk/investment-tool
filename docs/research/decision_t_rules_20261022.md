## 一、5 行结论

1. **两只票"每天两边都挂"的机械 T 毛期望都 ≈ 0, 扣费后每天亏 0.2~0.46%**(1878 天日线精确回测, 5/15/30/60/120 日窗口、P50 / P75 分位全一样); 按用户"不贪、小目标、允许隔日"的 7 个场景回测, 成功率能到 70~90%, 但平均每次仍略负(没做成的那部分亏得多), 只有"低开开盘低吸 + 全档 + 拖 3 天"(纳指近一年 +0.07%/次)和"中行高开 ≥1% 先卖"(7 次)为正 → 决策 T 的价值只能来自"挑方向、挑日子、用全档", 观望是合法基准。置信度: 高。
2. **中行近一年是"银行—大盘跷跷板"结构**: 与工行相关 0.80~0.85, 与沪深 300 -0.25~-0.30、国证 2000 -0.38; 低开日只挂低吸(近 250 日唯一为正的机械方案, +0.09%/天)、小盘普涨日先卖(收 < 开 74%)、上涨趋势别反 T(均 -0.18%)都由此而来, 但**全历史不成立**, 跷跷板一消失就要重审。置信度: 中。
3. **纳指 ETF 开盘缺口 ≈ 0.68 × 隔夜 NDX(相关 0.71~0.77), 开盘后的日内走势与隔夜无关(相关 ≈ 0), 只与盘中期货弱相关(0.20~0.27)**; 冲高碰中位就卖是负期望(赚钱占比 35~40%)。置信度: 高。
4. **旧决策T 纳指 2 天 26 次观望里, 两个主要理由都站不住**: "溢价回落"有一半是 panel IOPV 白天不更新造成的假象; "已走完 30 日振幅中位、空间薄"没有统计依据(跌深后收盘相对该价位五五开), 且 30 日中位(-0.33%)远小于近 5 日(-1.33%)。中行 2 天的问题是方向对、挂价太远(7.11 恰好最低没成交、7.28 卖单高于全天最高 7.25)。置信度: 中高(样本只有 2~3 天, 但机制清楚)。
5. **事后最优 T 标签本身有坑**: 159941 分钟线 09:30~10:30 是 62 根零成交的昨收占位, 10/19 反 T 1.64%、10/21 正 T 1.05% 的"09:30"时点不可成交 → 07 复盘在修好前只能用 10:31 以后的标签。置信度: 高。

**不自信点**: ① 中行的多数正向规律(R10 / R11 / R13 / R17)只在近 250 日成立, 全历史接近 0, 可能是这一年上涨段的特征而非股性; ② 分钟线只有 9 天(中行)/ 4 天且缺首小时(纳指), R15 / R16 / R19 / R20 证据很薄; ③ 回测里"没成交的腿按收盘收口"是近似, 真实收口在 14:45 / 14:50; ④ 撮合口径(碰价即成交还是要穿价)没核对, R18 依赖它; ⑤ 溢价只有 2 天本地数据, R13 基本是推理 + 网络资料。

读法与不自信点:
- **"不贪"提高的是成功率, 不是期望**: 小目标让 70~90% 的单子做成, 但没做成的单子拖到时间止损时平均亏得更多; 这在近似随机游走的价格上是必然的(R30 / R28, ✅)。真正改变期望的只有两样: 方向判断(场景选对)和费用(全档比 1/2 档每次好 0.1~0.5 个点)。
- 用户经验和数据冲突的两处: 中行"单边下跌日先卖后买"(数据: 中行下跌段常被护盘拉回, 先卖亏)、纳指"高开低走先卖"(数据: 高开后多半继续)。按用户要求场景规则仍标 [可跟], 但规则正文写了数据给出的执行条件, 状态 ⏳, 由日卡裁决。
- 日线近似偏保守(盘中挂单当天不算回补), 当天两腿都成交的比例在真实盘中会高一些; 分钟线攒满 40 天后应重跑一次分钟级版本(待补)。
- 场景出现频率里"单边上涨 / 下跌"用的是收盘后的定义, 盘中只能用趋势 + 开盘近似认出来。

## 四、每晚 07 复盘怎么让规则自我更新(流程建议)

> 原则: 事后最优 T 是标签, 规则是假设; 每天只做"记账", 每周 distill 才改规则文字; 改规则不靠一两天的结果, 靠累计计数。

1. **先校标签(零 token, t_review 之后)**: 剔除不可成交的最优时点(159941 10:31 前、零成交 bar、涨跌停一字); 标签分三档: 可信 / 近似 / 不可信, 不可信的日子不进下面的计数。
2. **决策 → 规则归因(零 token)**: 决策 JSON 的 reason 里引用的规则编号(R4、R14 …)机械抽出; 每个时段决策和当天可信标签比对, 记"方向对 / 方向错 / 该做没做 / 不该做做了 / 价位差一档"。
3. **给规则记账(写进各 skill 的一个机器文件, 比如 persona/rule_ledger.jsonl, 不直接改 rules.md)**: 每条被引用的规则 +1 次引用, 按第 2 步结果记 支持 / 反驳; 同时用当天行情检查规则的触发条件是否成立(例如 R10: 今天低开 ≤-0.5% 吗? 成立的话只挂买单是否赚), 这样**没被引用但条件成立的规则也会积累证据**。
4. **每周 distill(LLM 一次)按账本改 rules.md**:
   - 支持 ≥ 5 且胜率 ≥ 60% → 更新"证据"行里的数字和"最后验证"日期; ⏳ 的规则同时满足 → 升 ✅(标签加"回测"); 画像满足且价差过 2 倍费用 → 升 可跟。
   - 反驳占比 ≥ 60% 且样本 ≥ 5 → 状态标"已否定"(保留不删, 进索引 ❌), 写清是哪几天否定的。
   - 失效条件被触发(例如 R12 中行—沪深 300 相关系数转正)→ 依赖它的规则(R10 / R11)统一标"待复核"。
5. **新模式进 ⏳**: 日卡里同一情景 ≥2 次出现、现有规则没覆盖的(例如"某个时段事后最优总是反 T"), 写成新规则标 `[画像 · 待验证]`; 能用日线 / 分钟线回测的, 当周就跑脚本(scripts/temp/dt1022/stats.py 可复用)回测, 回测通过才写数字证据。
6. **每月重跑一次股性统计**: 振幅五窗口表、相关系数、窗口 MAE 都是会漂的数; 漂出原证据 ±30% 时更新数字, 不改结论则只改数字。
