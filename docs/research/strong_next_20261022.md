## 1 口径

- **状态(T 日收盘已知)**: 沿用 `strong_next.py` 的 state_at, 只用 ≤T 的日线; mkt / zt_n 是 T 日收盘值。
- **(a) 封死涨停(首板 / 二板 / 三板+; 按定义收盘就在涨停价)**: T 收盘买不进 → **T+1 开盘价买**(T+1 一字涨停 = 买不进, 跳过) → T+1 不能卖(T+1 交收) → **T+2 挂 +N%(相对买价)卖**: T+2 开盘就 ≥N 按开盘价卖, 盘中摸到 N 按 N 卖, 都没有按 T+2 收盘卖。T+2 开高收用这次新加的 o2 / h2 / c2 换算成相对买价。
- **(b) 非封死(炸板 / 大涨 / 回调 1~3)**: T 收盘买 → T+1 挂 +N% 卖 / 收盘卖(就是原来的 ev 口径)。
- 扣费 0.15%(来回); 训练期 2023-01 ~ 2025-12, 样本外 2026-01 ~ 2026-10-21。
- 敏感性: 把"T+1 开盘就是涨停价但不是一字"的也算买不进(开盘排队大概率买不到)。
- **偷看未来检查**: ① 随机抽 200 条库记录, 只给行情库里 ≤T 的日线重新算 state / volr / level, 跟库内 **0 条不一致**; ② 结果字段(gap / hi / … / o2 / h2 / l2 / c2)只在算收益时用, 从不参与分组; ③ 导师对照里"买入当日(T)收盘状态"在买入时还不知道, 只用来描述(3a′ 表、3d 卖点分位); 判断"是否挑高期望"只用 T−1 状态 + 训练期期望。导师交易窗口(2025-09 ~ 2026-10)跟训练期有 3 个月重叠, 影响很小(训练期 3 年, 分组期望很稳定)。
- 导师收益 = 买 → 同代码之后第一笔卖(vwap / vwap − 1), 不扣费; 跟库内比的时候扣 0.15。"首笔卖"可能只是部分仓位。

## 5 不自信点汇总

- 现实口径假设 T+1 开盘价必成交; 没模拟 T 日盘中排板(那才是芷影的真实买法), 只用她的打板成交做了侧面对照。
- 导师数据约 1 年(刘忆青 9 个月), 打法 × 状态细格 n 多数 < 30; "首笔卖"在分批卖时会低估持有收益。
- 盘中"选股 vs 择时"拆分用的是买入当日的走势, 对打板 / 追高的买点有事后偏差(只有低吸那部分大致可信)。
- 市况两期同正的组合是从 219 组里筛出来的, 有多重比较问题, 一律当低置信。
- 涨停价是按昨收自己算的(行情库 limit_up 缺失): 本次抽查 200 条状态重算全部一致, 但除权日 pre_close 的口径没逐条核。
