## 一、结论

1. **12 条导师链中，没有一条在任何层上稳定赢过延续基线。** 延续基线就是"把导师真人昨天的样子原样当成今天的预测"。全链合并后(75 个"链×日"配对)，L1 交易、L3 标的、L4 仓位几乎全部**显著输**；L2 方向是点输，区间上沿刚好碰到 0。样本只有 4~7 个交易日，所以每条链都标了"不足以排序"。但"整体输给延续"这个方向，在合并样本上已经显著。
2. **标的层基本是零。** 12 条链 7 天里，收盘持仓与导师真人重合的只有 2 次：刘忆青链 10/09 的国轩高科、大兴链 10/16 的新华文轩。当天买入的票与真人重合 0 次。A-control 同样是 0。也就是说，在"选哪只票"这一层，skill 链和裸模型没有区别，都不像导师。
3. **skill 链唯一稳定强于对照组的是 L4 仓位层**：总仓误差、总仓分档、单票最大仓误差三项，合并后显著赢 A-control。但这很可能是驱动器机械层的功劳，不是 LLM persona 的功劳。驱动器从 10/15 晚起按导师近 5 日真实总仓设仓位下限(`run_taoge_chain.py` 的 `dynamic_position`)，而对照组用的是默认下限。
4. **几处"点赢延续"是假像，并不说明链更像导师：**
   - L4 总仓误差上赢的 3 条(刘忆青、高概率、芷影)，导师都是"满仓↔空仓"来回切的风格。延续基线每次切换都会错 100%，而链一直停在 30%~60% 的中间仓位，所以绝对误差小。拿"永远猜 50%"这个常数去比，刘忆青 0.39 对链 0.37，高概率 0.37 对链 0.35，芷影 0.49 对链 0.54。链并没有比常数好。看分档一致率这一项，这几条链都没赢。
   - L1 上赢延续的星见野、A-cb：星见野链 86% 的天数都在交易，真人只有 43%，延续基线在"买一天、拿几天"的节奏上天然吃亏。A-cb 赢，是因为真人几乎天天做转债日内 T，链也天天有成交，但链是隔夜持有，真人收盘从来不留仓，两者性质完全不同。
   - A658 链在 L1 上"一致"的 2 天，全部来自双方都没动。真人 7 天一笔没动，链却 5 天在交易。
5. **结论对用户目标(权重 = 拟人度 × 真人业绩)的含义**：按现在的数据，拟人度这一项没有可以用来排序的信号。各链之间的差异，小于各链和延续基线之间的差距。在攒够样本之前，用它来分配权重等于引入噪声。

## 二、指标定义(详见脚本 docstring)

每个交易日 d、每对"A-<导师> 链 vs 该导师真人"，算四层指标。真值是导师真人 d 日的状态和动作。

| 层 | 指标 | 计算 |
|---|---|---|
| L1 交不交易 | L1_交易 / L1_买 / L1_卖 | 当天有没有成交(买、卖分开看)，与真人是否一致，取 0 或 1 |
| L2 方向 | L2_方向 | 分三类：净加仓、净减仓、不动(含等额换股和日内 T)。净额 = 当天动过的票的"去价格漂移"权重变化之和，阈值 ±5% 资产 |
| L3 标的 | L3_买入Jaccard / L3_持仓Jaccard | 个股集合的 Jaccard。双方都空时无定义，不计入，避免把"一起空仓"算成像 |
| | L3_板块 / L3_行业 | 足迹 = 收盘持仓 ∪ 当天买入，每只票等权，算分布重合度 Σmin(p,q)。板块口径同 mentor_scope(主板/创业板/科创/北交/ETF/转债/ST)。行业取 downloads/f10 缓存里的东财二级行业，脚本不联网，覆盖率 61% |
| L4 仓位 | 总仓误差 / 总仓分档 / 只数误差 / 最大仓误差 / 换手误差 | 分档边界：5%、35%、65%、95%。换手 = 当天动过的票的去漂移权重变化绝对值之和 |

- **延续基线**：真人 d-1 的特征原样当作 d 的预测，用同一套 compare 打分。**对照基线**：A-control 当天的特征，只有 10/12 起才有。
- **lift**：链得分减基线得分；误差类指标反过来，用基线误差减链误差。lift > 0 才算比基线更像。
- **区间**：0/1 指标用 Wilson 95%；lift 用按日配对的 bootstrap 95%(2000 次，固定种子)，样本少于 3 不给区间。配对天数少于 20 一律标"不足以排序"。
- **数据**：
  - 链持仓 = 成交流水按 trade id 日期重放到当天收盘(与 similarity.mjs 同口径)，权重 = 股数 × 本地行情库收盘价 ÷ 账本当日 nav。12 本账本重放结果与账本里的 mv 偏差都是 0。
  - 真人 = day_positions 的 position_percent，剔除逆回购和低于 2% 的碎仓(碎仓只计入总仓)。当日买卖方向 = day_positions 的 op 码 ∪ 逐笔腿。op 码含义已和逐笔腿交叉验证：3/7/1 是买，4/8/2 是卖，9 是当日有买有卖(188 例全部吻合)。
- **自测**：`--selftest` 共 30 项全过，覆盖每层计算、去漂移、日内 T、换股、碎仓、逆回购、双空无定义、Wilson、bootstrap、小样本判定，以及长拿型和快轮动两种端到端的基线逻辑。

## 四、哪些"像"是真的，哪些只是不交易、空仓或中庸

- **真像(勉强)**：只有大兴链。它是唯一一条持仓 Jaccard 大于 0、L2 方向和 L3 持仓都赢对照的链。不过它唯一的重合票(新华文轩 10/16)，是真人 10/15 买入之后它才在 10/16 买的。这更像滞后跟随，形态上接近延续基线，不是独立判断出来的。刘忆青链 10/09 的国轩高科重合，反而是链提前一天买入；真人 10/08 清仓国轩、10/09 又买回来。只有 1 次，不能算信号。
- **不交易像**：A658 链 L1 的 2 天一致全部来自双方都不动。A-control 在 a658 上 L1 是 0%，看起来"链赢对照 +20%"，其实只是两边都在乱动、链乱动得少一点。
- **多交易像**：星见野链的 L1、L2 赢延续，原因是链几乎每天交易，碰上了真人买入的日子，召回率 100%；同时在真人不动的日子也在动。这是"多动多中"，不是像。
- **中庸像**：刘忆青、高概率、芷影三条链的 L4 总仓误差赢延续，原因是导师满仓、空仓来回切，链停在中间。与"恒猜 50%"相比，链没有优势(见第一节第 4 条)。
- **结构性够不着**：宣秋(两融约 2.2 倍杠杆)、antoo(融资满仓约 1.3 倍、长拿两只票并每天做 T)、不吃土豆0(收盘不留仓，全靠转债日内 T 加逆回购)。这三位的 L4 和 L3 是链的规则天然达不到的，分数低不说明 persona 写得差。

## 五、指标本身的盲点

1. **延续基线对长拿型导师极强，对快轮动导师极弱。** 比如 A658 持仓 Jaccard 的延续值是 100%，刘忆青只有 6%。所以"能否赢延续"的难度因人而异，不同导师之间的 lift 不能直接横比。权重应该按导师内部的 lift 分位来定，或者再加一个"行为统计先验"基线(导师近 N 日的交易率、总仓中位数)做归一。研究报告建议 1 里本来就有这一项，本版没有做。
2. **绝对误差奖励中庸。** L4 总仓误差会偏向停在中间仓位的链。建议以分档一致率为主，或者再加一个"常数先验"基线对照。
3. **收盘口径看不到日内 T。** 方向和换手都是按收盘对收盘的去漂移权重变化算的，antoo 和不吃土豆0 的大量日内 T 只能在 L1 里看到。链能不能做日内 T 由撮合规则决定，口径本身就不对称。
4. **L3 Jaccard 只看同一天。** 链提前 1 天或滞后 1 天买到同一只票都算 0 分。可以加 ±1~2 日窗口的宽松版，但宽松版又会把"抄昨天"算成像，需要和延续基线一起看。
5. **行业层覆盖率只有 61%**(f10 缓存只有约 270 只票，主要是导师常买的票，链买的票大多没有缓存)。行业层样本很少(合并后 20 个配对)，结论不可靠。补齐需要联网抓 F10，本脚本按约束不联网。
6. **合并 bootstrap 把"链×日"当成独立样本**，但同一天各条链共享同一份行情和 facts，同一条链的各天之间也相关，真实区间会比报告的宽。要做严格检验，应按日做聚类 bootstrap。
7. **"空仓或无数据"有歧义。** day_positions 里写着 note="空仓或无数据" 的日子，脚本按"前一日有实质持仓且当天无清仓记录就当作无数据"处理。窗口内只有 ST之狼 10/12 命中，前一日也是空仓，按空仓处理。
8. **真人数据有时差。** 宣秋、antoo 的数据停在 10/13，量化小号、边学、不吃土豆0 停在 10/15，所以各链的样本天数不一样。

## 六、我不确定的地方

- 10/08、10/09 两天的链成交来自 10/10~10/11 的账本重建和回放(tradesRestated)，不是当天实时决策。如果剔掉这两天，样本只剩 5 天。今晚整本重跑后，这段历史可能又会变。
- L4 赢对照"可能来自机械仓位下限"，我是从代码推出来的(skill 链在 10/15 晚之后按导师近 5 日总仓设下限，control 用默认值)，没有做消融验证。
- 方向阈值 5%、碎仓门槛 2%、分档边界都是我定的，没有做敏感性分析。阈值换成 3% 或 10% 时，个别链 L2 的点估计可能翻转，但"整体输延续"的结论不会变，因为差距远大于阈值带来的扰动。
- day_positions 的 position_percent 分母我理解为账户总资产(融资账户可以超过 100%)，这一点没有在 tzzb 文档里核实。
- 7 个交易日在 MILA 口径下远远不够。按研究报告第 3 条，至少要 20 天才谈得上排序，60 天才谈得上定权重。

## 七、建议怎么用

1. **接日报：可以接，但只放一行合并结论。** 比如"今日 N 条链 L1/L2/L3/L4 赢延续的条数；全链合并 lift"。逐链得分不要上日报，样本不够，会误导"谁更像"的判断。可以直接读 `mimicry/<日>.json` 的 pooled 字段。
2. **接权重：现在不接。** 等任一链的配对天数达到 20 再说，指标里已经会自动标出"不足以排序"。接的时候用"导师内 lift vs 延续"的分档(输、平、赢)乘以真人业绩，不要用原始得分；同时加上第五节第 1、2 条说的先验和常数基线。
3. **接拟人审：最有价值。** 数据已经表明，LLM 在"选哪只票"这一层对导师几乎没有命中，而仓位层的改善来自机械约束。这与研究报告建议 2 一致：把交易率、总仓、持股只数、换手做成驱动器的硬约束，LLM 只在约束内挑票。具体可以先做两件：一是导师 7 天不动(A658、边学)，链也应该基本不动，这类"不交易"闸可以零 token 实现；二是对 L1 交易率先做闸，因为现在链普遍比长拿型导师交易得多得多。
4. **今晚 books 被替换后，重跑一次**：`scripts/venv/Scripts/python.exe -X utf8 scripts/dfcf/paper/mimicry_score.py --since 2026-10-08`。逐日文件用 `--date`。
