## 三、每本最值得落地的 3~5 条
**⑥ 高频交易(奥尔德里奇)** —— 对应我们 3 秒盘口 / 竞价 / 转债 T+0
1. OFI(Cont 2011)只用一档就能算: 买一价抬高或买一量增 = 正, 卖一价下移或卖一量增 = 负; 书中与短期价格变动线性(R²≈0.09)。
2. "成交后报价回不回来"区分有信息 / 无信息: 扫单后报价慢慢回来 = 无信息, 不回来 = 知情交易。这就是 S1(急跌后拉起)的机理, 可以做确认条件。
3. 交易方向判别: tick 规则 / 报价规则 / Lee-Ready / BVC(正确率 77%~91%); 我们的 3 秒快照合并了多笔, 只能在 3 秒桶上用。
4. 大对小信息溢出: 小盘股滞后跟随大盘股; 小盘 / 价差大的股票放量 = 动量, 大盘放量 = 反转(Llorente 2002)——可以拆 KS2。
5. 分层挂单 / 幌骗的特征 = 单边异常大单 + 快速撤单 → A 股版就是"涨停封单撤单"(S4a / S4b)。

**② 经典技术分析 上册(柯克帕特里克)**
1. 突破确认五种过滤, 作者推荐 ATR 倍数过滤代替固定 3%。
2. "预期突破"三个进场位(箱内回踩 C / 刚越阻力 B / 确认后 A)的胜率与赔率此消彼长(图 13-6)。
3. 止损: 吊灯 = 最高价 − 3ATR; 时间止损也是评估进场信号的工具; 反对金额止损。
4. 假突破("专家突破")后在突破前一根低点下挂反向单。
5. 市场宽度(腾落、宽度冲力、新高新低、90% 日)是 02 市况的现成特征, 但**作者自己复测多数在 2000 年后失效 → 参数必须在 A 股重估**。

**③ 埃尔德三本**
1. 三重滤网: 长周期 = 中介 × 5; 第一层趋势(26 周 EMA 斜率)只定方向, 第二层逆势回调(强力指数 2 日 EMA < 0), 第三层挂"前一日最高 + 1 价位"买入止损单。
2. 脉冲系统: 13EMA 与 MACD 柱同时向下 = 红 bar 禁止买入(当"禁令"用)。
3. 止损放在**精确的前低上**, 不要放在前低下 1 个价位(那里止损扎堆, 一触发滑点大); 尼克止损 / 安全区止损给了可编码公式。
4. 交易评分 = 盈利 / 通道高度(≥30% = A 级), 2% / 6% 规则——给 paper 账本和 07 复盘的评价口径。
5. 新高新低(NH−NL)被作者称为最好的领先宽度指标。

**④ 概率游戏(凌波)** —— 唯一一本以 A 股 T+1 + 涨跌停为前提的书, 但**全书没有统计**
1. T+1 下大部分资金收盘前买(早盘追高下午变盘无法改错); 强势股首次回踩 MA10 尾盘低吸 ≈ 前一波追长阳的价, 但少挨几天回调。
2. 假阴线: 高开 3~5% + 小实体收阴 + 缺口不补 + 正常量 + 近均线 → 收盘前买, 缺口为止损(**与我们 KS1"上升缺口不补跑输"方向相反, 值得测**)。
3. 突破 MA10 后的最初两根长阳内追涨效用最大; 远离 MA10 的盘中长阳 = 上影线雷区; 三板不追。
4. 背离 + 长下影抄底 / 底中找底(日线与分时背离共振)。
5. 下跌缺口出现短线以退出为主, 缺口上沿是之后反弹的压力。

**⑤ 暴力K线擒大牛(王宁)** —— A 股游资形态词典, **没有统计、只有挑选的赢家**
1. "涨停基因" = 历史涨停 / 大阳多、阴线少且小(可编码成 120 日非一字涨停次数)。
2. 十种组合里最可编码的: 点头送客(涨停 + ≥2 根不破涨停上 1/3 的缩量调整 + 放量突破)、空中飞人、横盘突击(缩量窄幅横盘 + 放量涨停突破)、多方炮。
3. 5.20 法则: "有效站上 / 跌破" = 连续 2 日收盘在 MA5 / MA20 外且偏离 ≥3%。
4. 竞价猎马: 底部跳空且竞价量比 ≥ 3。
5. 高位巨量涨停 / 高位铁轨线(连续长上影)= 头部, 与我们 KS9 同向。

**⑦ 跨市场(墨菲)**
1. 跨市场是"先单独分析、再看别的市场是否印证"的第二层; 关系会变(1998、2008 两次换格局), 要看**滚动相关系数**。
2. 比率线(相对强度)判断风格 / 板块领涨; 小盘股在底部先行。
3. 对 A 股短线能直接用的只有: 隔夜外围 → 开盘, 和风格比率线。

**① 股市趋势技术分析(爱德华兹 & 迈吉)**
1. 收盘越界约 3% 才算突破; 约 3/4 对称三角形 / 箱体是整固形态; 可靠突破在三角形 1/2~3/4 处。
2. 箱体高度 / 旗杆 / 头肩高度 = 最小目标 → 给 06 止盈价一个可解释的默认值。
3. **"缺口必补"是迷信: 缺口被补的概率等于回到任何已成交价位的概率**——可以直接检验, 也能检验 KS1 的"缺口不补"是否有特殊含义。
4. 止损放在上一个短线底部(基准点)下方, 按价格与波动调间隔, 只上移不下移。

**⑧ 趋势交易(克列诺)**
1. 突破 50 日新高 + MA50 > MA100 过滤 + **3ATR 追踪止损、持有到止损** —— 正好补 KS6"只测了固定持有期"的缺口。
2. ATR 定仓(风险因子 0.2%), 按百分比设止损"非常愚蠢"。
3. 参数平原: 规则换参数结论不变才可信; 趋势跟踪胜率 ~42% 是正常的。

**④b 黑马波段操盘术(凌波, 10/25 晚补读)** —— MA10"黑马线"完整版, **全书唯一带回测表的 A 股本土系统**
1. 黑马线 = MA10: 收盘在 MA10 上 + MA10 向上 = 强势; "MA10 连续 2 天向上 = 转多、连续 2 天向下 = 转空"(过滤噪音)。
2. 黑马线交易系统(表 8-4): 入场 MA10 向上 ∧ 收阳 ∧ 收盘 > MA10 ∧ DIF > 0; 40% / 40% / 20% 分三次(盈利 ≥5% 才加, 不摊平); 出场 MA10 向下 ∧ 收阴 ∧ 收盘 < MA10, 或亏 10% 无条件; 分两次卖。
3. 书中回测: 中金岭南 2006~2009 77 笔 胜率 59.7% 盈亏比 2.30; 开滦股份 68 笔 60.3% / 4.02 —— **只 2 只自选票、收盘价成交、牛市段, 可信度很低**, 但口径完整可原样复现。
4. 共振起涨点 = 站上 MA10 且 MA10 上行 + MACD 金叉; 卖点 = 跌破 MA10 + 死叉; "买点决定胜率, 卖点决定盈亏比"。
5. MACD 柱"抽脚"(最长绿柱后变短)只在 DIF > 0 时可靠; 断头铡刀(高位均线粘合后一阴断三线)= 卖。

### P0(数据现成、直接对应实盘线、先做)
**H01 涨停封单撤单率 → 炸板**(高频 HF1)
- 定义: 封板期间(买一价 = 涨停价、卖一空), 每 3 秒: 撤单量下限 = 上一笔买一量 − 本笔买一量 − 本 3 秒成交量(Δv), 取 max(0, ·); 1 分钟封单撤单率 = Σ撤单 / 1 分钟前的封单量; 另记"封单量 / 流通盘""封单量较本轮封板最大值的回落比例"
- 数据: book_snap 5 天(只用涨停过的票), 可用 10/19~10/23 的 S4a 事件对齐

**H03 转债—正股领先滞后**(高频 HF3)

- 对应: 06 转债做 T 挂单、S1 / S3 用在转债上时是否该看正股

**H04 三重滤网 + 脉冲禁令(日线版)**(埃尔德 EL1 / EL2)
- 定义: 第一层 = 周 26 周 EMA 上行(或日线 130 日 EMA 斜率近似); 第二层 = 强力指数 2 日 EMA < 0 且未创 20 日新低; 第三层 = T+1 最高价 ≥ T 日最高 + 1 价位即成交(买入止损单); 出场 = 安全区止损(k=2)/ 第一层翻向 / 固定 5 日三种; 脉冲红 bar = 13EMA 与 MACD 柱同时下降
