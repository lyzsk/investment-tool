# k3-inv — AI 自研操盘策略

与桃哥管线（plan A = 学习桃哥操盘法）并列的 k3-inv：由 AI 基于公开操盘方法论（龙头战法、低吸、首板、缠论、量价结构等）自行构建的策略实验。

放这里的脚本应该是**可独立运行、有明确假设、能回测验证**的策略，例如：
- 板块强度选股（腾讯 pt rank 板块数据已验证可用）
- 异动/反核形态识别（复用 bilibili-taoge/downloads/kline 的 m5 数据）
- 与桃哥 skill 的对照回测（同一区间跑两套，比较收益曲线）

规则：
1. 每个策略一个子目录， 自带 README 写明假设、信号定义、回测区间与结果
2. 回测必须遵守 walk-forward（只用 T-1 及以前的信息）, 成交口径与桃哥回测一致（下一根 m5 bar 开盘价 + 万2.5 + 印花税 0.05%)
3. 行情数据复用 `bilibili-taoge/downloads/kline/` 缓存， 新标的用 `bilibili-taoge/fetch_m5.mjs` 补抓
