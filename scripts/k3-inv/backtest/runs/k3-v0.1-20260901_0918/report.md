## 五、诚实标注(数据与方法的坑)

1. **电报数据洞**: 09/10、09/16 盘中电报缺失(cls 抓取洞， stocks md 里无当日盘中条目), 按"无电报日"处理 — 若当时实际有催化报道， 09/10 澜起可能提前一天离场(少亏约1%), 结论方向不变。
2. **09/18 无电报文件**(手工 md 无 `## 加红电报` 小节), 当日决策只基于行情结构。
3. **样本极小**: 2 笔交易无任何统计意义； 且两周里上证 -1.71% 的防御环境天然利好低仓位的 k3 风格。
4. **"没买"的裁决是我(AI)做的**: miss/skip 表的事后归因存在叙事偏差风险， 缓解方法 = 所有"不买"在当日 replay 时先记录再对照， 本报告只收录当日确实触发过候选评估的票。
5. m5 无法还原盘中流动性与排队， 成交价取 bar 开盘价是乐观但一致的假设(与桃哥回测同口径， 对照有效)。

## 六、结论与 v0.2 改进方向

**可行性判断**: k3-inv v0.1 证明了"纯 AI 读电报+结构+质量筛"能稳定控制回撤(-0.71% 最大回撤， 全程最大仓位 3 成), 但收益端被自己的纪律锁死。两条策略的本质差异这两周被清晰验证：

- **桃哥**(情绪周期/反核/辨识度): 利润来自高波动票的弹性， 10万本金无高价股盲区， 换手快吃足风格红利(+6.39%)。
- **k3**(质量过滤的催化跟随): 买的都是"睡得着"的票， 跌得少但也涨不动； 电报=确认信号的定位决定了只能吃到第二段， 而这两周的行情奖励的是第一段。

**v0.2 候选改进(待用户裁决， 不自动并入)**:
1. "报道时即涨停"的强催化 → 增设**次日竞价观察窗**(隔夜单/竞价强度达标可小仓试错), 否则该类型机会永远流失；
2. 高价股盲区： 单票仓位上限对 >500元/股的票放宽到"最小1手"特殊条款， 或明确放弃(写进规格);
3. 隔夜催化(overnight 映射)是 v0.1 唯一产生交易的信号类型， 权重应提高； 盘中板块拉升报道维持"确认不追"。
4. 与桃哥管线定位： 两者标的池几乎不重叠， 适合做 6:4 或 7:3 的组合对冲， 而不是二选一。
