- **起始资金**: 100,475.40（= 你 9/19 东财真实总资产，纯现金起步，不含你现有牧原持仓，便于干净归因）

## 经验点沉淀（本轮真实收获）

1. **规则带 learned_before 是灵魂**：风华高科、云南锗业、太极 9/15 这三个"错过"不是模型蠢，是诚实的代价——他当晚才说出的规律，盘中假装知道就是未来函数。缺口等他亲口总结后入库，R9 入库次日就赚回 +6.5%。
2. **触发纪律本身就是 alpha**：9/15 金健米业"低吸关注"若无脑执行=-10%，等企稳确认躲过。信号≠触发。
3. **卖出规则与桃哥高度同构**（守利润/冲高走/低开破位走），所以连"卖飞"都同步——这说明 skill 学到的是同一个人，不是巧合。
4. **反核手法是本轮最大利润源**（新赛+12.5%、国芳+12.1%），前提条件"板块资金仍在"的确认依赖板块数据——目前是人工判断，工程上必须补板块成分/涨幅数据（腾讯 pt rank API 已验证可用）。
5. **仓位规则限制了收益也限制了回撤**：2.5 成单票上限下最大回撤仅 -0.15%，符合他"环境不好 2-3 成仓"的生存第一原则。

## 关于 cls_telegraph（诚实回答你的质疑）

你的经验是对的。本轮回测中 cls_telegraph **从未作为任何一笔交易的依据**——我只是当初假设它有用，从未验证过。真正起作用的盘中催化是**公开新闻事件**（9/03 厄尔尼诺、9/07 美股周五大涨这类所有人都能看到的），不是电报快讯。结论：cls_telegraph 降级为低优先参考，不进交易触发链；盘中催化源另找（东财/新浪快讯或干脆不用，靠板块涨幅异动本身当信号）。

## 已知局限（不粉饰）

- 13 个交易日、6 笔交易，样本极小，+6.39% 不能外推为稳定 alpha；农业/消费恰好是这两周主线，skill 吃到了风格红利。
- m5 replay 无法还原逐笔流动性，反核类买点（跌停开板瞬间）实际成交可能比模拟差。
- 3 个规则缺口（新安一进二、摩尔反核、N沈鼓）合计错过约 +15% 的潜在收益——skill 是保守版桃哥，上限低于本人，但下限也高于本人（躲过的 4 个 -10% 他也没全躲过…他躲过了，是用别的方式）。
