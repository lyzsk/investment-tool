# 大兴大兴大A当兴(daxingdaxingdadangxing) 持仓处理手法挖掘(机械, 零 token; 2026-10-24)

> 样本 = 前一交易日收盘持有的每只票 × 当日, 共 34 个持仓日(20260917~20261023)。动作按收盘仓位对比: 清仓 / 减仓(降 >8pp) / 加仓(升 >8pp) / 持有。
> 基线(全部持仓日): 清仓 14(41%) / 减仓 1(3%) / 加仓 3(9%) / 持有 16(47%)
> 验证口径(10/18 改滚动, 原 70/30 一刀切作废): 按他自己的交易日序列, 训练窗 40 日挖规律 → 紧接 10 日验证 → 整体后滑 10 日再来, 共 0 窗(验证窗覆盖 -~-); 验证窗里该情境样本 < 3 不计。每条规律给: 验证通过窗数 / 有样本的窗数、最近一次验证窗是否通过、成立区间(首个通过窗~最后通过窗)。
> 结论: **近期有效**(最近一次验证落在最后 3 窗内且通过, 通过率 ≥60%) / **曾有效·近期失效**(通过率 ≥60% 但最近一次验证没过) / **过时**(早期成立: 截至最后一次通过的通过率 ≥60%, 但最后 3 窗没再成立) / **不稳定**(其余)。只有"近期有效"能写成规则主体, 其余只能当[线索]并写明结论; 下面的 n / 占比是全样本合计(描述用)。
> 每条 = "在某情境下他明显更常做某动作"(训练窗内该动作占比 ≥55% 或是基线 1.6 倍以上, 样本 ≥ 门槛)。次日=做完动作后那只票次日收盘涨跌(卖出的看卖飞 / 逃对)。
