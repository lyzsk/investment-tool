**打分规则**: 每类事件预设互斥穷尽的假设集合(必含「其他/证据不足」), 每个假设写出它应留下的可观测后果; 基础分各 1, 命中一条证据乘对应系数(支持>1, 反驳<1), 最后归一成百分比。逐事件分布+所用证据写在 cases_auto.jsonl(side=日内事件)。

- **同日多票**: 换方向 ← 首只 2 个交易日内亏损卖出(×3) / 首只当日收盘低于买价(×1.5) / 后买票与首只题材不同(×1.5, 相同×0.4) / 两笔间隔≤10 分钟(×0.5) / 首只持有≥3 日(×0.5); 两边押 ← 两只都持有到次日收盘(×2.5) / 金额比 0.5~2(×1.5) / 题材不同(×1.5) / 间隔≤10 分钟(×0.6); 计划内多只 ← 间隔≤10 分钟(×3, >60 分钟×0.5) / 金额比 0.67~1.5(×1.5) / 两笔都在 09:35 前(×1.3); 追联动加仓 ← 同题材且后买票在涨停价/当日热点(×3) / 仅同题材(×2) / 后买票涨停价或热点且首只当日收盘高于买价(×1.5) / 题材不同(×0.3); 其他/证据不足 ← 基础分 1; 题材未知(×1.5) / 缺行情(×1.5)
- **换股**: 止损换股 ← 卖出票亏损(×3) / 题材不同(×1.3); 止盈轮动 ← 卖出票盈利(×2.5) / 新买票在涨停价或当日热点(×1.5); 同题材换股 ← 两票同题材(×3, 不同×0.3); 计划内调仓 ← 卖后 5 分钟内买(×2) / 卖在 09:35 前(×1.3); 其他/证据不足 ← 基础分 1; 题材未知(×1.5) / 卖出成本未知(×1.5)
- **同票加仓**: 右侧确认加仓 ← 加仓价≥首笔+0.5%(×2.5) / 加仓在涨停价或当日收涨停(×1.5); 左侧摊低 ← 加仓价≤首笔-0.5%(×2.5); 拆单分批执行 ← 间隔≤15 分钟(×2) / 价差<0.5%(×2); 其他/证据不足 ← 基础分 1
- **同票先买后卖**: 有底仓做T ← 买前已有持仓(×3); 试错止损 ← 买前无持仓且卖价<买价(×2.5); 日内冲高兑现 ← 卖价≥买价+1%(×2.5); 其他/证据不足 ← 基础分 1

**局限**: ①观测不到真实动机, 分布只是「哪种解释与留下的后果更相容」; ②系数是人定的先验(未用标注数据校准), 绝对百分比不可当概率, 只适合导师间横比与同一导师随时间比; ③「其他/证据不足」在题材未知/缺行情时被加权, 证据越弱它越大(同日多票证据全缺时≈36%, 加仓/先买后卖无证据命中时=25%), 不会被压成 0; ④同日多票只拿「首只」和后续每只两两比较, 3 只以上的复杂序列被拆成多对; ⑤后果用了事后信息(首只 2 日内是否亏损卖、是否持有到次日), 所以这是复盘归因, 不可在盘中实时用。

## 七、数据缺口

- 行情: 行情库 kline_day 2025-06 起; 10/09 前无成交额/换手率(成交额用 量×OHLC 均价近似, 换手/流通市值用 10/09 后换手率反推流通股本套历史, 有增发/解禁的票会偏), 10/09 前无北交所; 退市/到期转债无行情(不吃土豆0 的转债大面积「数据缺失」)。
- 题材: 只有 md「## 涨停分析」(2026-01-15 起), 名称→代码匹配 12930 条 / 未匹配 1011 条(OCR 错字/改名); 只认识上过涨停分析的股, 没有完整行业/概念成分库与板块涨幅排名 → 「当日涨幅前列板块」用「当日涨停数前三题材」代替; 2026-01-15 前的买入题材特征为缺失。
- 龙虎榜: lhb_stock 2025-01 起, 有。涨跌家数/涨停家数: 从全市场日线自算(不依赖 md)。
- 分钟线: 只有 10/09 起约 800 只, 本版未用(买点低吸/冲高只用日线区间, 已标降级)。
- 港股(量化小号/星见野少量)无行情 → 「数据缺失」。

## 八、建议怎么接入

1. **事实包加「本导师自选股池」**: 盘前跑 `mentor_fingerprint.py --pool --date <今天>` → `scripts/tzzb/pools/<日>.json`, 每位导师 Top30(含打分理由/题材), 作为 01/04 步的候选来源之一; 只用前一日收盘数据, 无后见。
2. **04 候选约束**: 候选票须(a)落在本导师池内, 或(b)占用「池外预算」(=该导师时间外池外比例, 见第六节), 并且(c)候选的打法主标签须在导师打法分布里占比≥5%(用 classify_play 对挂单价预判)。指纹「不清晰」的导师只用(c), 不用(a)。
3. **拟人度选股层主口径改为打法分布 JS**: 用第五节的方法每日/滚动算链 vs 真人, 以「对照组 JS」和「真人近期 vs 全史 JS」为上下界。
4. **LLM 深蒸馏输入包**: `cases_auto.jsonl` 逐笔(买入前状态+打法+结果), 按打法分组抽样(每类 ≤10 笔, 正负结果各半)喂给蒸馏, 让 LLM 只做「为什么在这些情形下买/不买」的归纳, 统计数字以 fingerprint.md 为准不许改写。

## 九、不自信点

1. 题材特征覆盖窄且有 OCR 噪声; 热点=当日涨停数前三题材, 题材名跨日不统一(如「AI应用」vs「AI智能体」)会低估「同题材」。
2. 流通市值/换手/历史成交额是近似值, 分箱边界附近的票会错箱。2026-07-06 前主板 ST 档位用当日区间推断(当时已摘帽、现名不带 ST 又不在导师成交名单里的票会被当 10% 档, 漏判其 5% 涨停); 07-06 起按新规一律 10%。
3. 朴素贝叶斯假设特征独立, 实际高度相关(昨涨停/连板/近10日涨停/量比), 分数只用于排序, 倍数不可当概率。
4. 时间外样本小的导师(大兴/边学/宣秋/冲5000w)命中率置信区间很宽; 冲5000w 数据止于 07/06, 其测试段是 2026 上半年, 与当前行情不同期。
5. 「新开仓」靠腿推算持仓 ∪ day_positions, 数据窗口之前的老仓若没出现在 day_positions 里会被当新开仓。antoo 拆单极碎, 日×票聚合后同日多次进出被合并。
6. 卖出 FIFO 成本按本人数据窗口内的腿算, 窗口前买入的筹码=「成本未知」; 两融/做T 账户的 FIFO 与真实成本(券商摊薄)不同。
7. paper 链只有 10/08 起 7 个交易日, 每条链几笔到十几笔买入, JS 波动大; books 今晚可能被整日重跑替换。
8. 指纹池命中只算新开仓(选股层); 加仓/做T 不进池评估。基线「昨涨停按成交额」与打板型导师天然接近, 这些人的「倍数」偏低不代表指纹差。
