# 大师案例 #1：沧海自流 2026-06-02（风云杯 +683.87% 选手）

> 学习方法论：不看回放式结论，模拟当日从竞价到收盘的信息流，推演每笔操作"当时为什么"。

## 当日信息流时间线
- **前情**：光模块主升段首次分歧——5/29、6/1 两连阴（旭创 1198→1130）
- **隔夜明牌**：英伟达 +6.26% 收 224.36 美元（市值 5.45 万亿，杀入 PC 处理器+订单超预期）
- **竞价甄别**：旭创 +2.1% / 新易盛 +2.4%（认催化=真核心）；生益 -1.8%（不认=蹭分支）
- **盘中**：旭创走强至 +4% 时他加仓（1199.94），新易盛同加；生益低开高走（-1.8%→+6.4%）他只做 T
- **次日**：旭创 +7%，加仓 24h 内兑现；6/3 天孚创历史新高

## 原理（可执行规则化）
1. 催化提名 + 竞价当选，两个信号缺一不可（隔夜催化 × 竞价高开）
2. 竞价=强弱甄别器：同催化下高开=真核心，低开=蹭概念
3. 右侧加仓：买在盘中走强确认后（他的加仓价比开盘高 4%），不在竞价赌
4. **强弱分流铁律：强票加仓，弱票只 T 不加仓不隔夜重仓**
5. 仓位结构：主线龙头可重仓（他 131% 融资仓是极端版，k3-inv 不碰杠杆）

## 对 k3-inv 的映射（牧原 9/23-24 反例）
牧原 9/23 的 42.0/42.1 三笔补仓：无催化+竞价平开+走势单边弱 → 三条件全不满足，
属于"给弱票补仓"——沧海模型的反面教材。对应规则：R-ADD-CONFIRM 加仓三条件。
