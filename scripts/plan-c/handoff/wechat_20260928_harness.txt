一、harness 是什么
就是"调度器"：一段确定性 python 代码，负责组织多个 agent 调用的顺序、传参、断点续跑。agent（拟人判断）只干判断评分表态；harness（代码）干流程编排、状态记账、失败重试。我们已上线的 results→md→taoge-skill 串行链就是一个活 harness。

二、核心三件套（全部有自家样例，直接抄）
1. 调 agent = 调子进程:
   subprocess.run(["cmd","/c","claude","-p","--dangerously-skip-permissions", prompt],
                  timeout=900, capture_output=True, text=True, encoding="utf-8")
   样例: scripts/backfill_taoge.py 的 maybe_distill()。
   坑①: 必须 --dangerously-skip-permissions，否则 headless 卡授权。
   坑②: 中文 prompt 不能走 bash 内联/heredoc（GBK 会吃掉），先 Write 落盘再用 python 读文件传入。

2. 环节间只传文件，不传内存:
   每个环节的输入输出都是磁盘文件（results/、stocks md、rules.md），这样任何环节崩溃都能从文件现场恢复，且上下文天然隔离（每个 claude -p 是新会话，互相不污染）。

3. 哨兵 + 账本 = 断点续跑:
   要求 agent stdout 末行打印哨兵（如 DISTILL_OK 2025-08-29），harness 检查到才把该日记进 distill_state.json；没哨兵=没完成，下次重跑。超限额/崩溃后重跑脚本，账本自动跳过已完成的。
   样例: distill_state.json + maybe_distill 的哨兵校验。

三、最小骨架（30 行能跑）
```python
import json, subprocess, sys
from pathlib import Path

STATE = Path("state.json")          # 账本: {"done": [...]}
done = set(json.loads(STATE.read_text())["done"]) if STATE.exists() else set()

def run_agent(prompt_file, sentinel):
    prompt = Path(prompt_file).read_text(encoding="utf-8")   # 中文必须读文件
    r = subprocess.run(["cmd","/c","claude","-p","--dangerously-skip-permissions",prompt],
                       timeout=900, capture_output=True, text=True, encoding="utf-8")
    tail = (r.stdout or "").strip().splitlines()
    return r.returncode == 0 and tail and tail[-1].strip() == sentinel

for task in TASKS:                   # 串行, 一个agent烧token
    if task in done: continue        # 幂等: 跳过已完成
    ok = run_agent(f"prompts/{task}.txt", f"OK {task}")
    if ok:
        done.add(task)
        STATE.write_text(json.dumps({"done": sorted(done)}))   # 先记账再下一个
    else:
        print(f"失败 {task}, 下轮再来")  # 失败不阻断
```

四、进阶两件套（我们 9/28 刚立法的）
- 单实例锁: 启动写 pid 文件，已活则退出（防 nohup 双开）。样例: ensure_single_instance()。
- 随叫随停: 循环里检查 PAUSE 文件，在就待命。你说"暂停"我建文件，"继续"我删。

五、你要学什么（按优先级）
1. Anthropic 官方博客《Building effective agents》——harness 模式的圣经，我们只用到其中两种: prompt chaining（串行链，md→distill 就是）和 orchestrator-workers（七环节回测: 1个编排+6个工种agent）。搜 anthropic.com/engineering/building-effective-agents
2.  Claude Agent SDK（旧名 Claude Code SDK）——如果想在 python 里直接 import 调 agent 而不是 subprocess。我们暂时不需要，subprocess 够用且更透明。
3. 不用学框架（LangGraph 等）——奥卡姆剃刀: 我们的需求 30 行骨架+账本+锁就覆盖，框架只会引入幻觉面。
