# taoge-skill · distill 工作流（每日核销+沉淀）

> 路由来源: SKILL.md。
> 建立: 2026-09-28 (用户拍板: 单 agent 串行链 results→md→skill沉淀; 无候选池, 全量回顾自行核销; 误判一等公民入库)
> 触发: 由 scripts/backfill_taoge/backfill_taoge.py 的 `--llm-batch` 清账段批量调用——**5 天/会话**批量 sum+distill(非逐日单跑); 单日期 distill 钩子仍兼容, 核销/提取逻辑按目标日期逐日执行不变。

## 定位

读某一天的 md `### 桃哥` 小节(新格式五大 bullet), 把可复用的东西沉淀进 `skills/taoge-skill/persona/`。
**信息截止铁律**: 只允许使用 ≤ 目标日期的素材(md 文件、rules.md 现有内容); 禁止用任何晚于目标日期的市场知识修饰规则——这是回填, 不是马后炮。

## 流程(两步, 顺序不可换)

### 第零步: 读素材包(10/17 A14②, 零 token)

会话开头一次 Bash 生成本批全部目标日的素材包: `scripts/venv/Scripts/python.exe -X utf8 scripts/md/build_distill_pack.py --skill taoge --date <日1>,<日2>,...`, 每天开工先 Read `downloads/distill_pack/<目标日>/taoge.md`: ①当天本人小节全文 ②收评 + 涨停分析/龙虎榜同票行 ③近 5 个交易日本人同票记录 ④同票规则全文(带 rules.md 行号, 长规则只给前 3000 字) + 待验证规则索引 ⑤画像目录。包里有的不再自己 grep/cat md 与 rules.md; 包里标"未展开/截断"的、或核销还需要的其他规则, 按 [L行号] 只读那几条。非交易日顺延块(挂在下一交易日 md)不在包里, 照旧读挂载日 md; 脚本失败=照旧读原件。

### 第一步: 核销(先算账, 再进新货)

1. 读 `skills/taoge-skill/persona/rules.md` 的 `[待验证]` 规则(素材包 ④ 的待验证索引 + 按行号补读, 禁整文件读)。
2. 对每条, 用**目标日期的 md**(以及该日 md 内的收评/涨停/电报区)检查是否出现验证条件:
   - 兑现 → 状态改 `[md 验证 YYYY-MM-DD]`, 样本数 +1, 在规则末尾追加一行验证记录: `- 验证: YYYY-MM-DD 兑现/部分兑现, 一句话经过 + 证据引文`。
   - 打脸 → 状态改 `[已证伪 YYYY-MM-DD]` 但不删除(准则: 反例优先), 同时在 cases.md 立误判案(见下)。
   - 未出现验证条件 → 不动, 留给后面的日子。
3. 时间锚点推断纪律: 规则文本内的时间词为准("尾盘"=当日 15:00 前, "明天"=下一交易日, "这周"=本周); 无时间词 = 长期纪律, 永不核销只靠样本积累。**不在规则里写死具体验证日期**(日期可从规则出生日+交易日历机械推出)。

### 第二步: 提取(从本日小节进新货)

按五个 bullet 分流:

| md bullet | 沉淀去向 |
|---|---|
| 大盘 / 桃哥今日操作 | profile.md 行为统计(操作频率/仓位口径), 有新模式才写 |
| 提及个股(带态度: 观察/避开/低吸) | rules.md 对应区(A市场/B买/C卖/D仓); 已有规则则样本数+1 并补证据日期 |
| 画面增量 | 一般不沉淀(是事实不是人格); 除非揭示他的**看盘习惯**(如"先看人气排名再看换手") → profile.md |
| 规则沉淀 | rules.md 主战场, 新规则初始状态 `[待验证]`(除非当日 md 已可自证, 如"尾盘守60"→收评已出结果, 直接 `[md 验证]` 同日) |
| 任何 bullet 里的**误判/踏空/检讨** | cases.md 立案(一等公民, 见格式) |

语言指纹: 小节引用块里出现新口头禅/比喻 → language.md 追加(原声照录, ASR 错字首次注音释)。

## cases.md 条目格式(误判与神操作同构)

```

### [误判|神操作|学费] YYYY-MM-DD · 一句话标题

- 背景因素: 当时市况/消息/情绪(为什么会做这个判断)
- 他的判断: 原话锚点 + 出处日期
- 结果: 何时、以什么方式得知对错(当日收评/次日走势/他后来自己承认)
- 他有没有自己总结: 有=引原话; 无=写"未见自我归因"
- 教训/人格增量: 这条让画像哪里更准了
```

## 纪律(继承 taoge-skill 更新纪律, 加三条)

1. 每条新增/修改必须带证据锚点(日期+原话短句); 引不出原文的规则不许入库。
2. 冲突不删: 新证据与旧规则打架时, 旧规则标 `[已失效-市况变迁 YYYY-MM-DD]` 而非删除——旧规则有历史参考价值(用户立法: 市场是动态的, 规则动态更新, 旧记忆保留)。
3. 修改 rules.md/cases.md/profile.md/language.md 任一文件, 必须在该文件修订记录追加一行(日期/改了什么/依据日期)。
4. 单次出现的怪操作不升格为规则, 只进 cases.md; 样本≥2 才进 rules.md。
5. 本日小节无任何可沉淀内容(纯记录日/无操作日)是正常结果, 不硬凑。
6. 结束时**必须**在 stdout 最后一行打印哨兵: `DISTILL_OK {日期}`(回写脚本据此记账, 打了才认)。
7. **输出纪律(10/17 A14③)**: persona 文件只写变更/新增条目(新规则、样本数+1、验证记录行、状态改动、修订记录行), 不整段重写没变的内容, 不把 md 原文复述进 persona(锚点=日期+≤30 字原话); 改文件用 Edit 局部替换/追加, 不用 Write 整文件重写; 最终回复每天只列改动清单(规则编号+动作) + 哨兵, 不复述小节内容。
