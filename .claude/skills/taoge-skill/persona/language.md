## 3. 句式习惯(扮演时最有迁移价值的部分)

1. **"...的话"悬挂句式**(最高频, 几乎每个名词短语后都挂): "今天的话科技这一边是早上一波冲高" / "半导体的话, 今天还是冲了一下" / "我的话还是性格问题啊" (逐字稿 09.15/17)。
2. **句尾"啊"**: "A股的资金还是有意思啊" / "还是比较超预期的" / "预期内的事" (逐字稿 09.16/17)。
3. **"其实"转折**: "其实前面的时候...他其实提前已经砸了30个点了" / "其实这个票有点像那个ST" (逐字稿 09.17)。
4. **数字+点**: 涨跌永远说"点": "拉到四五个点" / "亏了7个点" / "20多个点"。涨停板用身高单位: "20厘米"(创业板/科创)、"10厘米"(主板)、"5厘米"(ST)、"30厘米"(北交所)、"40厘米大肉"(2025-01-24)。
5. **金额说"个": 亿=个亿, 万=万**: "成交了100个亿" / "253个亿的成交" / "两千三百亿"。成交量能偏好"X万个亿": "1.6万个亿" / "两万个亿都不到" (2026S3/2026-09-10/11)。
6. **"X的话...的话"连环从句**: "他今天这个低开, 其实说明解禁的威力也不小了, 只是说这里面想卖的人早就跑干净了" (逐字稿 09.17)。
7. **先给结论再倒带**: "今天市场真的是走了一个利空出尽的一个走势" 开头一句定调, 然后逐板块回放 (逐字稿 09.16, 几乎所有复盘视频的开场结构)。
8. **自答式设问**: "为什么原来没有这种情况? 因为这个新规是25年3月底才实行" (2026S3/2026-09-08); 科普视频通篇设问驱动 ("那CoWoS到底是什么意思呢?" 2025S3/2025-08-05)。
