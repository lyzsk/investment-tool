## 五闸门(立法, 每条规则的准入审查)

1. **欠定承认**: 同一笔操作有多个自洽故事 → 每条推断至少并列 **2 个竞争性假设**, 不收敛单一叙事
2. **证据链三环**: 操作记录 → 当时正股/板块/大盘状态 → 同类先例; 缺一环降级"弱猜测"
3. **置信度三级**: `统计事实`(可计数) / `强推断`(≥3 个独立样本同模式) / `弱猜测`(<3, 标"待证伪")
4. **可证伪条款**: 每条必须写"未来出现什么操作会推翻它"; 写不出证伪条件的不许进本文件
5. **反例优先**: 他违反自己规则的操作优先记录——反例比正例更能校准画像

## 规则格式(模板)

```markdown
### R<n> <一句话规则名>
- **规则**: 给定情境 X, 他倾向做 Y
- **置信度**: 统计事实 / 强推断 / 弱猜测
- **竞争假设**: 假设A(当前主选, 证据…) | 假设B(未排除, 证据…)
- **证据链**: <日期+操作> × n 条, 每条带当时行情状态
- **证伪条件**: 若未来出现 ___ 操作, 本条作废或降级
- **验证状态**: [待验证] / [样本 n] / [已回测]
- **反例**: (有就列, 没有写"暂无")
```

### R1 开盘双通道入场, 从不尾盘开仓

  偶尔 09:30:0x-09:35 追单; 午后从不开新仓
- **置信度**: 统计事实
- **证据链**: 144 出手日首买通道 = 09:25:00×98 / 09:30:00×29 / 09:30:0x×15 / ≥09:31×2;
  买腿 ≥14:30 = **0/463**, 卖腿 ≥14:30 = 1/437; 23 个同日同债"竞价买+死窗买"价格对显示
  死窗成交价≈竞价价+0~2%(=开盘价附近连续竞价首笔)
- **竞争假设**: A 死窗预埋=开盘前已决策(主选; 09:30:00.000 成交要求单子开盘前已在队列) |
  B 09:30:00 手动秒下单(未排除但物理上难: 下单+撮合延迟难以落在 :00 整)

- **证伪条件**: 连续 ≥3 日首买在 10:00 后, 或出现 ≥14:30 开仓
- **验证状态**: [样本 144日/463买腿]

### R2 秒级时间止损, 而非固定幅度止损
- **规则**: 买入后几秒内不涨就割; 亏损幅度不设固定线
- **置信度**: 强推断
- **证据链**: 亏损单 115/191 (60%) 持仓 ≤10 秒; 亏损单平均持仓 65 秒 vs 盈利单 125 秒;
  盈亏结构 平均 +1.12% / -0.64%(盈亏比 1.76, 胜率 56.1%=244/435);
  亏损幅度分布 -0.2~-5.79% 分散(46/68/47/21/9), 无聚拢区间
- **竞争假设**: A 时间止损"不立即赚钱=错"(主选) | B 固定幅度机械止损(已证伪: 分布散、最深 -5.79%) |
  C 盘口走弱手动割(与时间止损观察等价, 不可区分)
- **证伪条件**: 亏损单持仓 >5 分钟成簇出现(≥3 笔/月)
- **验证状态**: [样本 435 笔] [执行质量复核 10/2]
- **复核(持收增量=若拿到收盘的增量收益, 阈值口径·用户 10/2 立法不搞固定 topN)**: 全体平均 **-0.34%**
  (早卖净正确); 盈利单 **-0.58%**(他卖在早盘冲高后, 债全天回落是常态——**他不是卖飞, 是早盘派发**);
  亏损单持收 -0.05%≈中性, 止损正确率 104/191。分布(435 笔): ≤-10%×14 / -10~-5%×88 / -5~-2%×68 /
  -2~0%×76 / 0~2%×60 / 2~5%×51 / 5~10%×51 / ≥10%×27——计数近对称但逃顶尾更深。
  **显著逃顶 102 笔(≤-5%)全为当日崩盘债**(最深 3/3 百川转2 他 5 秒认亏 -3.03%, 躲过尾盘 -18.45%);
