| 发布时刻 | 挂载点 | 节不存在时 |

| 09:15-11:30 | 新建 `## 早盘` 节(插在 `## 午评` 前)+`### bilibili`+`#### 卢本圆复盘复盘` | 当天他早盘发稿才建节(append 模式, 模板不预置) |

- 边界: 挂载判据=视频 publishTime(B站 API 值), 不用合成时刻
- 周末/节假日发布: 挂载到**下一个交易日**的 md(对齐 Java 交易日Markdown 生成/加红电报的瞬移语义, 10/7 立法); 若视频标题明确所指交易日与瞬移结果冲突, 按标题所属日, 拿不准标 (待核)
- 同日多稿(他日均可能 1-2 稿): 同一 `#### 卢本圆复盘复盘` 节内按发布时间序追加多个视频块(视频标题行天然分隔), 不建第二同名节
- 深夜稿: 实测不存在(UTC 时区假象), 若未来真出现按标题所指交易日归属, 拿不准标 `(待核)`
