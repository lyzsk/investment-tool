# 桃哥视频产物合成(状态机最后一棒)

上游 `bilibiliVideoHandler`(quartz, cron 0 30 15-23 * * ?)已完成:
发现(INSERT step=NEW) → 下载(mp4+m4a+json → source_files, step=DOWNLOADED)
→ 直链 process_video.py(ASR→纠错→视觉→聚合 → results/, step=VISION_DONE)。

本 skill = 把 VISION_DONE 的产物消化进 stocks md, 然后推进 SUMMARIZED。
**这是状态机最后一棒: 不推进, 30 天物理删除永不触发, downloads/ 会膨胀。**

## 纪律(不可违反)

1. **AI 写库必须走 controller**: 推进只准 curl `POST /api/bilibili/video/markSummarized`,
   禁止手写 SQL 改 DB; curl 不通(spring 没跑)就报告用户, 不许绕过
2. **幻觉防控**: 只写产物文件里有的信息; 产物缺就标注缺失, 绝不脑补内容
3. **股票代码以 OCR/多帧投票为准**(VLM 会编代码: 金健米业→600193, 真 600127),
   对不上的代码标 `[?]`, 不猜
4. 不改 downloads/ 任何文件, 不删任何文件; results/ 是永久档案只读
5. `### 桃哥` 小节内容只可能是本 skill 的产出, 合成即整小节覆盖(幂等), 无需任何标记

## 步骤

### 1. 发现待合成列表

```bash
curl -s localhost:8888/api/bilibili/video/pendingSummary
# Result.data = VISION_DONE 且 retry_count<3 的行: bvid/title/authorMid/publishTime
```

空列表 = 没活, 直接结束(先确认上游 job 跑过: sys_job_log 看 bilibiliVideoHandler 回执)。

### 2. 逐视频定位产物 + 三态判定

产物目录: `results/bilibili/<authorMid>/<发布日 yyyy.MM.dd>/`(发布日=publishTime 的日期部分)

| 文件 | 角色 |
|---|---|
| `<bvid>.txt` | 纠错后口述全文, **主原料** |
| `<bvid>.vision.json` | 画面产物, 含 pages 段(页面时间轴/注意力榜/BS买卖点/持仓快照/自选股清单/紫色持仓) |
| `<bvid>.raw.txt` / `.tsv` | 原始转写/时间戳, 仅参考不直接引用 |

三态(幻觉防控核心):
- **态1 全齐**(txt + vision.json 含 pages): 正常合成, 口述+画面两段都写
- **态2 仅 txt**(仅 CPU 机器跑过 asr,correct, 视觉留待): 只整合口述, md 小节开头标注
  `> ⚠️ 画面产物缺失(仅CPU管线), 本节无视觉信息` — 可以合成, 信息缺口显式化
- **态3 连 txt 都没有**: **不合成不脑补**, 把缺失清单报给用户(查 sys_job_log 失败原因), 结束

### 3. 合成写 md

挂载点: `stocks/<year>S<quarter>/<发布日 yyyy-MM-dd>.md` 的 `## 复盘` → `### 桃哥` 小节
(桃哥只在交易日盘后发稿, 挂发布日当天; quarter=(月-1)/3+1, 9月=S3)

小节结构(2026-09-24 用户定稿格式, 五大 bullet 全收在 ### 桃哥 下, 不用 #### 子小节):
```markdown
### 桃哥

**[视频标题](https://www.bilibili.com/video/<bvid>)** · HH:MM 发布 · N 分钟 ·（语音转写）

> 逐字稿第 1 段(txt 原文按自然段拆引用块, 保留原声不转述——他是语感样本,
> 错字/口误照留, 纠错层已在 txt 里做过)

> 逐字稿第 2 段 ...

- **大盘**: 指数/量能/情绪一句话 + 他的定调(画面确认的数据标"(画面确认)")
- **桃哥今日操作**(持仓高亮:紫色高亮票清单): ①买/卖/埋伏 逐条带价位,
  价位命中口述或多帧一致的标"(画面确认)"; 单帧孤证标"(待核)"
- **提及个股**: 名称(代码) · 看多/看空/观察 — 依据一句话 + T3 轻量快照(见 3.5);
  代码以 OCR/多帧投票为准, 对不上标 [?]
- **画面增量(口述未提)**: 沉默持仓/ASR 零提及但注意力榜靠前的票/板块指数
  异动——这是视觉管线存在的意义, 没增量就写"无"不许省略小节。
  **紫色高亮=持仓(2026-09-28 用户确认, 不是"疑似")**; 口述说"已走"但画面仍有
  紫高亮的, 如实并列两说标"待核", 不许擅自二选一
- **持仓逆向**(有持仓时必写, 无持仓写"无"): 对每只持仓(紫高亮+口述自认)做
  技术面快照+持有动机推断, 见 3.5; 推断必须标注证据与置信度, 不许写成断言
- **规则沉淀**: 1) 2) 3) 从当天操作/剧本提炼的可迁移规则, 每条带当天
  证据; 马后炮嫌疑的标"(样本1, 待验证)"
```

### 3.5 个股技术快照与持仓逆向(2026-09-28 用户立法, 分层)

快照存在的根本理由=**锚定当时**: 复看 md 要的是"桃哥当天看到的技术面",
事后爬数据锚点全变——内嵌事实数据是 md 作为学习语料的不可再生部分。
事实层(快照)=确定性代码, 推断层(动机)=LLM 并标"推断", 两层分开。

**分层(高内聚低耦合, 避免全量快照撑爆 md):**
- **T1 持仓**(紫高亮+口述自认): 完整快照 + 持仓逆向(动机推断+触发点)
- **T2 聚焦**(注意力榜前列/BS 买卖点): 完整快照, **无动机推断**(他没说就别编)
- **T3 口述提及**: 轻量快照一行(现价/涨跌幅/近120日区间位置%/均线多空一句话)

**完整快照字段(全部机械可算, 禁 LLM 估算)**: 日线≥120 交易日(腾讯粒度允许
另拉当日 m5 分时, 周报由日线聚合); MA5/10/20/60/**120/144**(注: 桃哥本人用
哪几条均线语料无证据, 120/144 为 9/28 用户指定扩展=观察字段, 不进推断链)、
MACD(12,26,9)、RSI(6,12,24)、KDJ(9,3,3)、CCI14(指标参数=9/28 用户推荐口径)、
近30日振幅、近120日区间高低+现价位置%、前高前低(近20日)、未回补缺口(近60日)、
均线粘合/多空排列状态。**不做**: 威科夫相位/缠论中枢等主观体系 overlay——另一套
方法论套在桃哥票上=学偏且不可机械化, 违背事实/推断分层(9/28 定, 用户疑虑确认)。
快照计算脚本待建(2026 国庆, 与市场扫描脚本同批); 建成前允许手工示范版(标
"手工示范, 管线复核"字样)。

**语料验证结论(2026-09-28, 180 个 vision.json 统计 + ASR 检索)**:
- 盯盘页面驻留: 分时 128 段/1181s 第一 > 资讯 > 持仓 > 盘口 188s > K线仅
  22 段/134s——**他是分时选手, 日K看得少**; 快照以日线为主是因为日线可机械
  复现, 不代表他看日线决策
- "跌透了"实锤(2026-05-07/08 逐字稿: "提前跌透了…早上开的强再去抄基本不会
  亏钱""跌透了以后反而就不跌了"), **但语境=提前爆雷/ST 预警股跌半年, 不是
  普通技术性回调**——推导链"超跌"环按此口径: 别把 -10% 回调当"跌透"

**持仓逆向(T1 专属, LLM 推断)**: 结合 a) 历史口述该票买入逻辑(查既往 md
桃哥小节) b) 首次出现持仓日期区间=inferred 成本区 c) 当前技术位(均线多空/
MACD 柱/RSI 超买超卖/KDJ 金叉死叉/CCI 极值/振幅带) → 回答"他为什么还拿着"
(格局等催化/被套装死/做 T 摊本/板块贝塔配置...), 给出该持仓的**下个触发点**
猜测(止损线/兑现线)。写入 **持仓逆向** bullet, 每只 2-4 句: 技术快照(数值)
+ 动机推断(带"推断"字样, 多动机并列不许擅自二选一) + 触发点; 数据缺(转债
不索引/粒度超限)如实标注。


态2(仅 txt)标注位置: 在视频引用行下一行加
`> ⚠️ 画面产物缺失(仅CPU管线), 本节无视觉信息`, bullet 只写 大盘/操作/提及/规则 四条。

- `### 桃哥` 小节只可能是 AI 产出 → 已存在就直接整小节覆盖(幂等重合成)
- md 文件不存在(非交易日/没预建) → 报告, 不新建(挂载归口是 cls 域的职责)

### 4. 推进状态机(只推合成成功的)

```bash
curl -X POST localhost:8888/api/bilibili/video/markSummarized \
  -H "Content-Type: application/json" -d '["<bvid1>","<bvid2>"]'
# 回执: "推进SUMMARIZED x/跳过 y(非VISION_DONE)/未找到 z"
# 跳过=已推进过(幂等), 不是错误; 推进时刻的 update_time = 30 天物理删除倒计时起点
```

**批量改写分支(历史回填日期)**: backfill_taoge.py 回填的日期**不写 DB**(用户定:
文件驱动), 这些日期没有表行 → 跳过本步, 不 curl。判别: pendingSummary 列表里
没有的 bvid 但 results/ 产物齐 = 回填日期, 合成完直接结束。

### 5. 批量改写(2026-09-27 用户定: 旧 md 全部统一为 9/24 定稿格式)

旧 md(~219 天, 2025-10 起)的 `### 桃哥` 是旧格式(纯逐字稿 或 #### 解读/
#### 画面 子小节), 全部按上方定稿模板整小节覆盖重写。驱动方式:
- **原料 = results/ 四件套齐备的日期**, 回填(backfill_taoge.py)出一天的产物
  就改写一天, 与回填节奏自然咬合; 不用等全部回填完
- 已有产物的日期(results/bilibili/625315686/ 下现有目录)可立即先行
- 2026-09-18 是用户手工精修稿, **跳过不改**; 2026-09-24 是定稿样板本身, 不动
- 逐字稿引用块: 旧 md 里已有人工/纠错稿的, 以 results txt 为准重建(同源)
