## 要点
1. 五项原则: 做好功课 / 寻找强大竞争优势(经济护城河) / 拥有安全边际 / 长期持有 / 知道何时卖出。
2. 七个错误: 虚幻目标、相信"这次不同"、偏爱公司产品、下跌时恐慌、**试图择时**、忽视估值、只看盈利数据。
3. 对短线的直接表态: "单看股票, **股价运动传达的是无用信息, 尤其是短期**"; 择时风险: 市场收益集中在少数几天(收益不对称), 错过几天就差很多。
4. 何时卖: 买时犯了错 / 基本面恶化 / 股价远超内在价值 / 有更好去处 / 仓位过重。不能仅因涨跌卖。
5. 交易成本与税: 频繁交易者在佣金+短期资本利得税下长期显著落后(美国税制)。

## 对项目的意义(我的判断)
