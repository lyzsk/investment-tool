## 一、核心概念
1. **K 线位置决定性质**: 判断一根 K 线先看位置、再看量、再看时间; 同一根长阴墓碑, 长期下跌后**缩量**出现 = 洗盘骗线(见底), 高位放量 = 出货。
2. **暴力 K 线** = 大阳线和涨停板。选股两条件: ①**历史走势涨停板和大阳线多、阴线少且实体小**("涨停基因 / 贵族基因");②近期出现第一根放量大阳线或涨停板 → 随时准备进场。回避阴多阳少、阳线不占优的弱势股。
3. **5.20 法则**: 平衡市里短线行情以"有效站上 MA5"开始、"有效跌破 MA5"结束; 中线以 MA20 为界。**有效 = 收盘连续 2 天在均线上(下)且偏离 ≥ 3%**。大牛市里跌破 MA20 不空仓(看 55 / 144 / 233 日线); 大熊市倒过来用: 偏离 MA5 过大时买, 反弹到 MA5 不过就减半、到 MA20 受阻就清。
4. **黄金均线**: 5、10、20、55、89、144、233、377、450、610(斐波那契); 短线回避黄金均线空头排列、回避大黄金均线(55 以上)压制; 暴力 K 线**突破大黄金均线束缚**是最佳买点。
5. **缺口猎马**(第 3 章): 突破缺口 + 暴力 K 线 = 真突破; 判断真假: 有涨停基因的票更可能、整理期量价配合好、**位置越低越可能**; **竞价猎马: 09:25 量比排行, 相对底部跳空且竞价量比 ≥ 3, 09:30 前准备介入**; 开盘后分时不补缺口继续放量 → 回调低点介入。
6. **一字板放弃**(3.3 节): 重组 / 突发利好的连续一字板"用技术根本抓不到", 一秒翻过去。
7. **十种暴力 K 线组合**(第 4 章):
   - 否极泰来: 底部 / 充分调整末期, 阴线后接大阳(右侧实体越大越好, 涨停最佳);
   - **大阳接力**: 连续两根中大阳线, 第二根开盘略低于第一根收盘(无缺口), 启动初期、第二根实体和量都大于第一根更好;
   - **多方炮**: 大阳(涨停)+ 阴线(洗盘)+ 大阳(涨停)突破, 右侧放量;
   - 星火燎原: 涨停 / 大阳 + 在其上方的星线(小阴小阳十字)+ 涨停 / 大阳;
   - **点头送客**: 涨停 + **2 根以上强势调整 K 线, 不跌破涨停 K 线上 1/3**、一般缩量 + 放量大阳或涨停突破(买点), 位置不高才有效;
   - **空中飞人**: 3~4 根涨停 / 大阳接力且至少 1 个跳空缺口(一字板可无量), 之后缩量浅调, 再出涨停 / 大阳介入;
   - 夹心炮: 多方炮的中间阴线换成 2 根以上的调整组(时间越长越弱);
   - 大阳旗形 / 涨停旗形: 大阳(涨停)后在其头部附近收敛整理、缩量, 放量突破旗形买;
   - **横盘突击**: 连续缩量横盘(K 线极度收敛、"芝麻量"、不随指数波动 = 高度控盘), 放量涨停 / 大阳突破即买。
   - 分时买点共性: 分时线在均价线上方"通气"、回调不破均价线、"横盘突击"式突破分时震荡区间、涨停开板在低位 = 诱空吃货。
8. **十种头部 K 线**(5.2 节): 射击之星、长阴墓碑、乌云盖顶、颠倒乾坤(吞没)、黄昏之星、高位品字形、空方炮、三只乌鸦、**高位巨量涨停板**(要等次日确认阴线再走)、**高位铁轨线**(盘头时连续多根长上影, 之后放量阴线破位就走)。前提: 涨幅过大、上涨斜率变缓开始盘头、放量标志 K 线确认。

## 二、可机械化的定义(日线; 10cm / 20cm 分别按涨停价判定)
| 编号 | 名称 | 口径 |
|---|---|---|
| WND1 | 暴力 K 线 | 涨停收盘(非一字)或 涨幅 ≥ 7%(10cm)/ 12%(20cm)且实体 ≥ 0.7 × 振幅 |
| WND2 | 涨停基因 | 过去 120 个交易日非一字涨停次数 N_zt(只用 T−1 及以前); 再加 阳线实体和 / 阴线实体和 |
| WND3 | 5.20 有效站上 | 连续 2 日收盘 > MA(5 或 20) 且 第 2 日 收盘 ≥ MA × 1.03; 有效跌破对称 |
| WND4 | 大阳接力 | 连续 2 根 WND1(或中阳 ≥ 4%), 第 2 根 开 ≤ 第 1 根 收 且 开 ≥ 第 1 根 收 × 0.98; 第 2 根 实体 > 第 1 根、量 > 第 1 根 |
| WND5 | 多方炮 | WND1 + 阴线(收 < 开, 跌幅 ≤ 5%)+ WND1(且 收 > 前两根最高, 量 > 中间阴线量) |
| WND6 | 点头送客 | Z = 非一字涨停 bar; 之后 k ≥ 2 根: 每根 最低 ≥ Z_low + (2/3)·(Z_high − Z_low), 每根量 < Z 量; 然后一根 WND1 且 收 > 调整段最高, 量 > 调整段均量 × 1.5; 前提 收盘距 60 日最低 ≤ 50%("位置不高") |
| WND7 | 空中飞人 | 连续 3~4 根 WND1(允许一字), 其中 ≥1 个向上缺口(低 > 昨高); 之后 1~3 根 调整(最低 > 最后一个缺口的下沿, 量递减); 再出 WND1 |
| WND8 | 横盘突击 | 前 ≥ 10 根: (最高 − 最低)/收盘 ≤ 2.5 × ATR%(或箱体宽 ≤ 3 ATR)、平均实体 ≤ 0.5 × 60 日平均实体、量 ≤ 0.6 × 60 日均量; 当日 WND1 且 收 > 横盘区最高, 量 ≥ 2.5 × 横盘区均量 |
| WND9 | 竞价猎马 | 09:25 开盘价 > 昨日最高(跳空)、竞价量比(竞价成交量 / 近 5 日同时段平均)≥ 3、收盘距 60 日最低 ≤ 30% |
| WND10 | 高位铁轨线 | 近 20 日涨幅 ≥ 40%; 连续 ≥ 3 根 上影 ≥ 0.5 × 振幅; 之后一根 放量阴线 收 < 这几根的最低 |

## 四、和 A 股的差异与适用性
- 这本书是 **A 股游资 / 题材股的形态语言**, 和桃哥 / 天哥 / 刘忆青等导师的说法高度重合("多方炮""旗形""横盘突破""涨停基因"), 价值在于**把导师口中的形态写成了可编码的结构**, 让我们能把导师的买点标注成"哪种暴力 K 线", 再统计导师在哪种形态上赚钱(与 kline_study 报告 §五 3 的"复盘标注事件"思路一致)。
- 和我们已有证据的关系:
  - KS2(非涨停长阳 + 放量 5 日跑输)、KS6(突破跑输)、strong_next(强势股次日现实口径溢价为负)——**"暴力 K 线就买"在全样本上大概率是负期望**; 书中所有形态都要求"位置不高 + 缩量调整 + 再次放量突破", 我们要检验的是**这些前置条件能不能把负号翻过来**;
  - KS9(高位连板大分歧回封次日两极、3 日偏弱)与"高位巨量涨停板 = 出货"一致;
  - KD3(一字板不识别)与"一字板放弃"一致。
- 2013 年小盘题材牛市的案例, 换到 2024~2026(注册制、20cm、量化增多)可能完全不同。

## 五、可以给本项目做的回测候选
- **WN1 涨停基因持续性**(WND2): N_zt 分档(0 / 1~2 / 3~5 / ≥6)→ 之后 20 / 60 日出现涨停的概率、最大涨幅 P50 / P90、收益全分布; 检验"股性"是否可持续。对应 04 选股(候选池排序 / 能力圈)。
- **WN2 横盘突击 vs 普通突破**(WND8 vs KS6 海龟突破): 前置"缩量窄幅横盘"能否把突破的负超额翻正; 对应 04 / KS6 修订。
- **WN3 点头送客 / 空中飞人**(WND6 / WND7): 买点当日收盘(或次日开盘)→ 1 / 3 / 5 日; 对照 strong_next 同状态(首板 / 二板 / 回调n)基准。对应 04(打板 / 接力型导师)、S4。
- **WN4 竞价猎马**(WND9): 用 `call_auction_open.jsonl`(10/09 起)和日线(竞价量比用分钟路径 09:25 那一笔近似)看当日开盘→收盘、次日; 样本 11 天, 先算 n 再决定。对应 S6 竞价抢筹 / 02 盘前首跑。
- WN5 5.20 有效跌破 MA20(WND3)当作持仓离场规则, 与 KP3 / EL3 的止损对比合并做。
- WN6 多方炮 / 大阳接力(WND4 / WND5)全样本表现(预期为负或零, 当作 KS2 的细分)。
