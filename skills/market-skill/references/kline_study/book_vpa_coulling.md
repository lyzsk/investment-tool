# 《量价分析》(安娜·库林)学习笔记 —— 与威科夫互证

- 原书: Anna Coulling, *A Complete Guide to Volume Price Analysis*(2013), 肖凤娟译, 中国青年出版社 2016
- 本地: `C:\Users\admin\dev\6530-量价分析\量价分析.epub`。第 4~6 章精读; 第 7~9、11 章按要点读(关键段落全读); 第 1~3 章(历史/成交量/价格概述)、第 10 章(案例)、第 12 章略读。看图约 10 张, 代表图存 `skills/market-skill/references/kline_study/img/vpa_*.jpg`
- 定位: 威科夫思想的**通俗化+K 线化**版本, 外汇/指数期货背景为主。对我们最有用的是: ①"确认 vs 异常"二分法; ②三根 K 线"孤立支点"定义箱体上下沿; ③突破的量能要求

## 一、核心框架
1. **只问一个问题: 成交量是"确认"价格, 还是"异常"**(第四章第六条原则)。依据威科夫第三定律(投入产出 = 努力与结果)。
   - 确认: 长阳+高量、短阳+低量(单根); 多根上涨实体递增且量递增(趋势级)。
   - 异常: **长阳+低量**(陷阱, 常见于开盘测试/新闻冲高) / **短实体+高量**(弱势: 牛市顶或熊市底的典型) / 上涨中实体变大而量变小(连续异常=买压枯竭)。图 4.16/4.17: 第 2 根出现"小实体高量"是第一个信号, 第 3、4 根"大实体低量"确认。
2. **成交量永远是相对的**: 只和同一数据源的历史比(第三条原则); 作者明说"不在乎数据 70% 还是 90% 准确, 只要一致"。→ 我们用个股自身 N 日均量/分位数, 完全符合。
3. **作者自称"艺术不是科学, 无法自动化"**(第一条原则)——这是对我们机械化工作的直接反证, 必须写进 open_questions。
4. 三步分析: 微观(单根) → 宏观(相邻几根) → 全局(在趋势/区间中的位置)。多周期: 5/15/30 分钟"三车道", 快周期的变化传导到慢周期 = 更大的趋势(因果定律)。
5. **耐心**: "信号出现后市场常沿原方向再走一段才反转", 像油轮刹车。

## 二、K 线 + 成交量(第六章)
| 形态 | 价格含义 | 成交量分级解读 |
|---|---|---|
| 射击之星(长上影, 小实体靠下) | 永远是弱势, "不会是异常" | 低量=小弱, 平均=较强回调, 高/极高=专业人士卖出; **同一价位连续 2~3 根且量递增**=抛售高潮的一部分(图 6.10) |
| 锤子线 | 永远是强势 | 同上反向; 下跌中 2~3 根高量锤子 = 买入高潮; 之后可能出现低量测试锤子(影线较短) |
| 长腿十字 | 不明确 | **低量长腿十字=异常**(局内人在新闻时制造波动洗盘, 自己没参与); 至少平均量才可信 |
| 高实体 | 情绪强 | 低量 = 警钟 |
| 低实体 | 情绪弱 | **高量 = 异常**: 阳线高量=顶部吃力; 阴线高量=下方有买盘承接 |
| 吊颈线 | 上涨顶部 | 高于平均量才是弱势, 需后续射击之星(高量)确认 |
| **放量止跌**(图 6.17, `img/vpa_fig6-17_stopping_volume.jpg`) | 暴跌中连续 3~4 根: 实体越来越短、**长下影线、收在 K 线上半部分**, 最后一根近锤子 | **成交量远高于平均且逐根增长** |
| **放量止涨** | 上涨中连续几根: 长上影、实体变短、"弧线", 最后一根射击之星 | 量大幅高于平均 |

## 三、全局: 吸筹/派筹/测试/高潮(第五章)
- 与孟洪涛书一致的部分: 吸筹=局内人以批发价填仓, 用利空/恐慌震出; 派筹=以零售价出货, 用利好/FOMO 吸引; **供给测试**=吸筹后回到前期卖压区, **低实体+长下影+低量**=卖盘已被吸收, 高量=失败需重来; **需求测试**=派筹后回测, 低量冲高回落=买盘已耗尽。
- 图 5.18 完整周期: 吸筹 → 买入高潮 → 供给测试 → 上涨 → 派筹 → 抛售高潮 → 需求测试 → 下跌。
- ⚠️ **术语反转(重要冲突)**: 库林把"抛售高潮 Selling Climax"放在**上涨顶部**(局内人卖), 把"买入高潮 Buying Climax"放在**下跌底部**(局内人买), 并说明"很多人理解正好相反"。经典威科夫(孟洪涛书、Pruden、WyckoffPro 代码)是 **SC 在底、BC 在顶**。项目统一采用经典口径, 本书的"抛售高潮/买入高潮"在笔记中按经典口径对调理解。

## 四、箱体 / 支撑阻力 / 突破(第七~九章) —— 箱体定义的主要来源
1. **孤立支点**(图 7.13/7.14, `img/vpa_fig7-14_pivot_box_start.jpg`): 三根 K 线;
   - 孤立高位支点: 中间 K 线最高价高于两侧最高价, **且**最低价也高于两侧最低价;
   - 孤立低位支点: 中间 K 线最低价低于两侧最低价, 且最高价也低于两侧最高价。
   - 上涨后先出现高位支点、再出现低位支点 → **震荡区(箱体)开始**, 高支点=天花板, 低支点=地板; 下跌后顺序相反。后续更多支点用于修正边界。
2. 边界是"**橡皮筋**"不是直线: 价格只滑出几个点不算突破, 要看到天花板上方的"**清晰水流**"(明确收在区间外)。
3. **有效突破**(图 7.16, `img/vpa_fig7-16_breakout_volume.jpg`): 突破时成交量**高于平均且逐渐放大**; 之后回踩时量萎缩、回踩不跌回区间; 原天花板变地板(极性转换, "楼层"比喻)。无放量 = 局内人陷阱。
4. 区间形成原因: 等待重大消息 / 高潮后吸筹派筹 / 回到前期套牢区。区间越久、后续行情越大(因果)。
5. 动态趋势线(第八章): 突破后用连续的高/低支点逐级画边界, 不画事后趋势线; 新的高支点不再创新高 → 可能进入下一个箱体。
6. **VAP 价量分布**(第九章): 按价位统计成交量, 密集区=强支撑阻力; 短时间窄区间却出现高 VAP = 警示。

## 五、对项目的启示
- 箱体机械定义可直接采用"孤立支点"(= 3 根 K 线分形)确定上下沿, 再用 ATR 容差做"橡皮筋", 用收盘越界+量能做有效突破判定; 在分钟级同样适用(作者本人主做 5/15/30 分钟)。
- "确认/异常"可编码为: 实体(或振幅)分位 vs 成交量分位的二维格子, 对角线外=异常。
- VAP 可用分钟数据按价位聚合成交量实现(本库有分钟线, 可做)。

## 六、不确定点
- 作者明确反对自动化; 书中所有图例为示意图或挑选案例, 无统计。
- 外汇 tick volume 与 A 股真实成交量性质不同; A 股涨停一字板的"低量长阳"在本书框架里是"异常/陷阱", 但在 A 股恰恰是最强(无人卖) → **必须把涨跌停单独处理**。
