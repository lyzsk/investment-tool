## 一、核心概念
1. **订单流 = 主动买量 − 主动卖量**(式 11-1)。学术结论: 订单流解释价格中至少 50% 的信息(Love & Payne 2008, 外汇)。市价单不可撤 = 承诺最强 = 信息最多。
2. **交易方向判别(第 4 章)**: 没有买卖标识时 4 种方法——
   - tick 规则: 比上一笔价高 = 买, 低 = 卖, 平价沿用上一次非零变动方向(纳斯达克正确率 77.7%, 期货 86.4%);
   - 报价规则: 成交价 > 买卖中间价 = 买, < 中间价 = 卖, 等于中间价不分(76.4%);
   - Lee-Ready: 先报价规则, 中间价那笔再用 tick 规则(81.1%);
   - 整体量分类 BVC: 每个时间桶 / 量桶里, 买量占比 = Φ(ΔP / σΔP)(正态分布函数), 按量桶 90.7%、按时间桶 86.6%。
3. **OFI(Cont-Kukanov-Stoikov 2011, 式 11-5/11-6)**——只用一档就能算:
   `e_n = 1[Pb_n ≥ Pb_{n-1}]·qb_n − 1[Pb_n ≤ Pb_{n-1}]·qb_{n-1} − 1[Pa_n ≤ Pa_{n-1}]·qa_n + 1[Pa_n ≥ Pa_{n-1}]·qa_{n-1}`, OFI = 区间内 e_n 之和。买一价抬高或买一量增加 → 正; 卖一价下移或卖一量增加 → 负。图 11-7: 价格变动 ≈ 0.005·OFI(R²≈0.09)。
4. **一笔成交后的报价反应四种情形(图 11-1~11-4)**: ①报价不动 = 小单无信息; ②报价被打下去又慢慢回来 = 大单扫了一档但无信息; ③报价被打下去不回来 = **有信息**(知情交易); ④成交后价差变宽 = 不确定性上升(重大消息前), 做市商"宽报价"。
5. **激进程度**: 市价单 / 吃单占比越高 = 下单者越确信方向; 激进程度有自相关("对角线效应": 同等激进的单后面跟同等激进的单), 来源 = 大单拆小单 + 动量。机构限价单优于散户, 大单优于小单(Anand 等 2005)。
6. **订单簿形态(Cao 等 2004)**: 紧靠现价的流动性峰**把价格推离**该峰; 远离现价的流动性峰**把价格吸过去**("报价的万有引力"); 订单簿深度低 → 未来波动低(Foucault 等); 远离现价的集中挂单可能含有事后公告的信息。
7. **流动性测度**: 价差、一档深度、订单簿形态、Kyle λ(ΔP 对净主动量回归的斜率)、Amihud 非流动性(|收益|/成交额)、市场弹性(被扫单后恢复原形状的速度)。
8. **久期**: 卖空受限的市场里, 成交间隔越短 → 越可能有利好(Diamond-Verrecchia、Easley-O'Hara); 收盘前 1 小时成交间隔最短。可以用"量钟"(每 N 股一根 bar)代替时间钟抽样。
9. **市场冲击**: 永久冲击 ∝ 单量(线性), 临时冲击随时间指数衰减(图 5-6); 拉高出货可行的条件是"买的永久冲击 ≠ 卖的永久冲击"(f(V) ≠ −f(−V)), 可用回归检验。
10. **事件交易三步(第 9 章)**: ①收集事件时刻与"超预期"量; ②算事件前后各窗口收益; ③回归 R = α + β·超预期。书中 CPI → 美元 / 加元的例子: **抽样间隔越短, 显著的交易窗口越多**(5 分钟只 1 个, 15 秒有多个), 机会集中在公告后几分钟。
11. **大对小的信息溢出(第 8 章)**: 小盘股对信息反应慢于大盘股, 小盘股收益滞后跟随大盘股(Lo-MacKinlay 1990); **小盘股 / 价差大的股票放量时呈动量, 大盘股 / 价差小的股票放量时没有动量甚至反转**(Llorente 等 2002)。
12. **分层挂单与幌骗(第 12 章)**: 分层挂单多数是合法的"占队列"; 幌骗 = 单边大单只挂不成交、反复撤; 可检测特征 = "某一边出现异常单边峰值 + 快速撤单"。

## 二、可机械化的定义(落到我们 3 秒五档 `book_snap` 字段: s / t / p / v(累计量) / a(累计额) / b[[价,量]×5] / k[[价,量]×5])
| 编号 | 名称 | 口径 |
|---|---|---|
| HD1 | 中间价 | mid = (b[0][0] + k[0][0]) / 2; 涨停封板时 k[0] 为空 → mid 不定义, 单独分组 |
| HD2 | 价差(价位数) | spread_tick = (k[0][0] − b[0][0]) / 最小价位(股票 0.01, 转债 0.001); 低价股常年 1 个价位 → 用 HD3 |
| HD3 | 一档失衡 QI | (b[0][1] − k[0][1]) / (b[0][1] + k[0][1]); 五档版 QI5 = Σ买量 − Σ卖量 / 总量(可按距离加权) |
| HD4 | OFI | 相邻两笔快照按上面 e_n 公式累加; 按 1 / 5 分钟汇总, 除以当日平均一档深度标准化 |
| HD5 | 3 秒主动量 | Δv = v_n − v_{n−1}; 方向用 tick 规则(p 对上一笔 p)或报价规则(p 对上一笔 mid); 也可直接用 `tick_flow.jsonl` 已分好的 buyVol / sellVol(分钟级) |
| HD6 | 成交后报价反应 | 一个 3 秒内 Δv ≥ 当日 Δv 的 P95 且 p ≤ 上一笔 b[0][0](主动卖扫单): 看之后 60 / 180 秒 mid 是否回到扫单前 mid 的 50% 以上 → "可恢复"(情形②) vs "不恢复"(情形③) |
| HD7 | 撤单量估计 | 同一价位前后两笔快照挂单量减少 − 该价位期间成交量(用 Δv 且 p 在该价位) = 撤单量下限; 涨停价买一上用它算"封单撤单率" |
| HD8 | 流动性峰 | 五档里挂量 ≥ 该边平均档量 × 3 的档位; 距现价 1 档 = 近峰, 3~5 档 = 远峰 |
| HD9 | Kyle λ / Amihud | 每票每天: 1 分钟 Δmid 对 1 分钟净主动量回归斜率; Amihud = mean(|r_1m|) / mean(额_1m) |

## 四、和 A 股 / 我们的差异与适用性
- **集合竞价**: 书里没有。我们的 09:15~09:25 未匹配量(`call_auction_open.jsonl` / `cb_auction_features` 的 unm_buy / unm_sell)是比连续竞价 OFI 更"干净"的订单流——09:20 后不可撤, 相当于书里"不可撤的市价单承诺"。S6(竞价抢筹)就是这个思路。
- **涨跌停**: 封板时一侧空档, OFI / mid 都失效; 但涨停价上的买一挂量和撤单(HD7)是 A 股特有的、信息量最大的盘口变量(对应 S4a / S4b)。
- **快照不是逐笔**: 新浪五档约 3 秒一刷, 中间多笔成交被合并 → tick 规则只能在"3 秒桶"层面用, 正确率会比书里低; 撤单量只能估下限(HD7)。
- **T+1**: 书里的做市 / 剥头皮在 A 股股票上做不了; **转债 T+0** 和"已有底仓做 T"才是能用的场景。
- **大单拆小单 + 游资对倒**: A 股游资会刻意制造主动买(对倒), 订单流的"信息含量"可能低于美股; 要用"成交后报价是否回来"(HD6)判断是不是真买。
- **样本**: 3 秒五档实际只有 10/19~10/23 共 5 个交易日(`downloads/market/<日>/book_snap.jsonl.gz`), 约 200 只; `tick_flow.jsonl`(分钟主动买卖量)10/09 起 11 天。任何结论都只能先给"低"置信。

## 六、不自信点
1. 只有 5 天 3 秒盘口, 且是"我们盯的票"(持仓 / 候选池 / 连板梯队), 不是随机样本; 涨停票占比偏高。
2. 3 秒快照合并了多笔成交, OFI / tick 规则的噪声比书中逐笔数据大很多, 结论可能被"刷新时点"污染(新浪刷新不是严格 3 秒)。
3. 书中 OFI 的 R² 只有 0.09 且是同期关系; 同期解释 ≠ 能预测, 我们要的是领先关系, 可能很弱。
4. 第 5、13~16 章(交易成本细节、执行算法 TWAP / VWAP、风控)没细读; 第 8 章配对交易只读了思路。
