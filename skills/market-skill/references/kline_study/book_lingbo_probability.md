## 一、核心概念(A 股本土短线 / 波段)
1. **看大盘做个股**: 上证分时**白线 = 加权(大盘股)、黄线 = 不加权(中小盘)**; 黄线在上 = 中小盘强。约八成个股与大盘波动形态相似、只是幅度不同 → 大盘打开上涨窗口(日线 DIF > 0)才是做股时机; 作者统计上证日线 DIF 在零轴上方每年约 4~6 个月(做多时间占 1/3~1/2)。
2. **趋势 / 震荡**: 上升趋势 = 波峰波谷逐个抬高; 箱体 = 碰上沿回、碰下沿弹; "横有多长竖有多高"; 建议只做趋势系统, 过滤震荡。高手买点 = 大涨后回调再**突破前高**时(不是回调中、不是前高)。
3. **起涨点**: 2 浪结束后 3 浪突破 1 浪高点处买, 止损放在 2 浪低点。
4. **关键 K 线(撑起 / 压倒一波行情)**: 判断 6 条——涨幅 / 位置(背离后或上穿主要均线)/ 成交量 / 时间周期 / 形态 / **下跌中出现的大阳线且站上 MA10(黑马线)**; 顶部对称: 阶段高位放量大阴线跌破 MA10。
5. **追涨停 6 问题**: 选股池、T+1 当天无法改错、佣金、大盘好时涨停多胜率高、封板可能性、次日冲高长阴只有一次卖点; **"三板不追"**(第三个涨停再追风险大); 涨幅过 8% 准备追、放量要封板时出手; 在上涨末端(MACD 第 32 根红柱、远离均线金叉)追涨停空间有限。**作者自己试验后"否定了天天追强势股拼曲线"的做法**, 主张波段。
6. **追势不追价**: 日线确认突破位(前高)后到分时找买点——分时均价线上方、放量突破分时前高 = 买点; 挂单直接高挂几档。
7. **假阴线(作者称"一种赚钱形态")**: ①跳空高开(3%~5% 合适);②小实体;③收阴;④缺口不补;⑤正常放量(不能巨量, 参考历史换手);⑥在均线附近(低位突破最佳, 高位只做短线)。买点: 开盘 5 分钟后 / 均价线上方 / **收盘前(重要)**; 止损: 缺口上沿或下沿; 后两日回补缺口 = 失效。前提: 大盘或板块多头背景。
8. **123 法则 / 2B / 背离**: 分时 123 = 突破下降趋势线 → 回落不创新低 → 突破前高; 背离 = 价格新低而 DIF 不新低, 等 MACD 绿柱明显收缩或出红柱才算完成; 上证 DIF < −50 是下跌动能最大区; 日线背离与分时背离**共振**最好。
9. **下跌缺口**: 出现向下跳空缺口 → 短线以退出为主; 缺口上沿在之后反弹中构成压力; 站上缺口再考虑买。
10. **锤头线 + 黑马线**: 下跌低位出锤头, **等 MA10 首次拐头向上**那天买, MA10 拐头向下卖。
11. **抄底在背离下影时**: 放量下跌释放过、DIF 低位绿柱收敛、确认背离、当天长下影 → 收盘前试探买, 止损放当天最低; 买入后不迅速脱离成本就走。
12. **底中找底**: 高一级别背离的第 5 浪里再找次一级别背离的 5-5 浪(两周期共振); 或者等"第一个抬高的波谷"(右侧)。
13. **T+1 下的低吸**: 一波上涨里 2 浪、3-2 浪、3-4 浪、4 浪是低吸位; 均线 MA10 → MA20 → MA60 依次各支撑一次后被跌破; **大部分资金在收盘前买**(早盘买如果下午变盘没有改错机会); 回踩 MA10 的低吸价 ≈ 前一波追长阳的价格, 但少受好几天回调。
14. **上影线多发区**: 远离 MA10 的长阳(盘中)= 收盘后的长上影, 是短线雷区; 突破 MA10 之后的**最初两根长阳内**追涨效用最大, 之后通常还有约 3 个涨停的空间(作者经验)。
15. **价托**: MA5、MA10、MA20 构成的封闭三角(MA5 上穿 MA10、MA10 还没上穿 MA20)= 波段起点; 强势股回调 MA10 是加仓位。
16. **过滤条件**: MACD 系统里"DIF > 5(上证)"过滤零轴附近反复交叉; 个股阈值 = 近 4 天 DIF 日变动绝对值的平均(万科 0.013 → 取 0.02)。中长线系统: 买 = DIF > 阈值 ∧ MACD 红柱放大 ∧ 收阳; 卖 = DIF < −阈值 或 跌破买价 5% 或 总亏 10%。
17. **系统测试**: 30 笔以上说明基本问题, 100 笔以上基本可信; 不要找最优参数; 指数上的波段机会一年约 10 次。

## 二、可机械化的定义(日线, 全部只用 T 及以前数据)
| 编号 | 名称 | 口径 |
|---|---|---|
| LBD1 | 黑马线方向 | MA10_t > MA10_{t−1} |
| LBD2 | 价托 | MA5 上穿 MA10 后 ≤ 5 日内, MA10 ≤ MA20 且 MA10 上行(即将上穿) |
| LBD3 | 强势股首次回踩 MA10 | 近 10 日内出现过 MA5 > MA10 > MA20 且 收盘较 MA10 高 ≥ 8%; 当日 最低 ≤ MA10 × 1.01 且 收盘 ≥ MA10; 自该轮金叉后第一次; **14:55 买(用分钟路径取 14:55 价; 日线回测用收盘价)** |
| LBD4 | 假阴线 | 开盘 / 昨收 − 1 ∈ [3%, 5%](创业板 / 科创板按 ×2 换算或单列)、\|收−开\| ≤ 0.3 × (高−低)、收 < 开、低 > 昨高(缺口不补)、量 / 20 日均量 ∈ [0.8, 2.5]、收盘与 MA10 或 MA20 距离 ≤ 1.5 ATR; 买 = 当日收盘(作者"收盘前")或次日开盘; 失效 = 后 2 日最低 ≤ 昨高(补缺) |
| LBD5 | 背离下影抄底 | 收盘创 20 日新低 或 最低创 20 日新低; DIF 高于前一次 20 日新低时的 DIF(底背离); 下影 ≥ 2 × 实体; MACD 柱较前 3 日收敛; 收盘买, 止损 = 当日最低 |
| LBD6 | 下跌缺口压力 | 向下缺口(高 < 昨低)3 日未补; 之后反弹最高价与缺口上沿(昨低)的距离分布 |
| LBD7 | 突破 MA10 的第 n 根长阳 | 长阳 = 涨幅 ≥ 5%(10cm)且实体 ≥ 1.5 × 10 日平均实体; 收盘上穿 MA10 后第 1 / 2 / 3+ 根长阳 |
| LBD8 | DIF 过滤 | θ = mean(\|DIF_t − DIF_{t−1}\|, 近 4 日); 有效多头 = DIF > θ |
| LBD9 | 黄白线差(日内) | 上证等权(或中证 1000 / 中证 2000)日内涨幅 − 上证加权日内涨幅; 10:00 / 11:30 两个时点 |

## 四、和 A 股的差异与适用性
- 这是**唯一一本以 A 股 T+1 + 涨跌停为前提写的书**, 很多观点和我们导师语料一致(收盘前买、回踩 MA10 低吸、三板不追、下跌缺口退出)——**正因为它就是 A 股短线圈的常识, 才更需要用数据检验**, 不能因为"大家都这么说"就进规则。
- 和我们已有结论的冲突点:
  - **假阴线"缺口不补 = 支撑"** vs **KS1"上升缺口 3 日不补之后 5 日跑输(n=11,149, t −4.6)"** —— 方向相反, 假阴线是 KS1 的一个子集(高开 3~5% + 小阴 + 近均线 + 正常量), 要看子集是否翻号;
  - **"突破 MA10 最初两根长阳内追"** vs **KS2"非涨停长阳 + 放量 5 日跑输"**、**KS6"突破类跑输"**;
  - "三板不追"与 strong_next(三板+ 现实口径 −1.61% / −0.33%)方向一致, 已有证据。
- "收盘前买"是 A 股 T+1 的合理执行建议, 可以用分钟路径直接量化"同一个日线信号, 早盘买 vs 尾盘买"的次日盈亏差——这是本书最容易落地、最有价值的一条。

## 五、可以给本项目做的回测候选
- **LB1 早盘追 vs 尾盘买(T+1 执行时段)**: 对同一批日线信号日(KS7 样本、LBD3 样本、导师买点), 比较 10:00 / 10:30 / 14:50 三个买入价到次日开盘 / 次日收盘 / 次日最高的收益全分布; 分"当日收阳 / 收阴"。数据: 股票分钟路径 100 天。对应 06 挂单时段(以及计划模式的下单时间)。
- **LB2 强势股首次回踩 MA10 尾盘买(LBD3)**: 之后 1 / 3 / 5 日; 对照 "同期突破 MA10 的第 1 / 2 / 3 根长阳追入"(LBD7)。日线 2019~。对应 04 选股(低吸型)/ 06。
- **LB3 假阴线(LBD4)**: 当日收盘买 / 次日开盘买, 之后 1 / 3 / 5 日; 与 KS1 全体做差。对应 04 / KS1 修订。
- **LB4 背离下影抄底(LBD5)**: 与 KS5(锤子 / 吞没无优势)对照, 看"背离"这个条件是否带来增量。
- LB5 下跌缺口压力(LBD6): 反弹止于缺口上沿 ±0.5 ATR 的比例 vs 同距离随机价位(对应 06 止盈 / 减仓价)。
- LB6 MA10 方向过滤(LBD1)对所有低吸类信号的增益(和埃尔德脉冲 EL2 合并做, 作为"禁令"候选)。
