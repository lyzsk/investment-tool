## 一、核心概念
1. **四类资产互相联系**: 股票、债券、商品、外汇; 分析任何一个都要看另外三个。跨市场分析不是替代单市场技术分析, 而是**"先单独分析每个市场 → 再看别的市场是否印证"**的第二层。
2. **经典关系(书中原则汇总, 第 16 章)**:
   - 美元与商品反向(最持久); 债券价格与商品反向;
   - 1998 年后 债券与股票反向(通缩恐慌时代), 2008 年后 股票与商品高度正相关;
   - 顺序: **债券先转向 → 股票 → 商品**; 债券收益率先见顶, 股票其次, 商品最后;
   - 市场**顶部**的板块轮动比**底部**更可靠;
   - 全球股市高度联动; 美元弱利好海外股票, 美元强利好美国股票; 新兴市场与商品同向。
3. **板块轮动与经济周期**(第 9 章): 牛市启动时经济敏感型(可选消费、科技、运输)和**小盘股率先见底**并领涨; 见顶前防守型(必需消费、医药、公用事业)走强; 金融股领涨常在衰退末期 / 扩张初期。
4. **相关系数是核心工具**(第 11、16 章): 两条序列画在一起 + 下方画**滚动相关系数线**; 相关系数 > 0.5 才算强; 关系会变(1998、2008 两次换"格局"), 所以要看相关系数**何时增强、何时减弱、何时反常**(例: 2011 年黄金与金矿股短暂负相关, 很快回正并伴随一波上攻)。
5. **比率(相对强度)线**: 一个市场 / 板块除以另一个(如 纳指 / 标普、地区银行 ETF / 标普、股票 / 债券), 比率线突破趋势线或前高 = 领涨 / 风格切换信号。
6. **领先指标**: 市场领先经济(股市先于经济 3~6 个月转向), 债市又领先股市; 图表分析是"看基本面的快捷方式"。

## 三、书中统计
- 2011 年大部分时间 美元 vs 商品 相关系数约 −0.75
- 2002~2012: 商品 +64%、债券 +23%、美国股票 +9%、美元 −32%
- 2007 年见顶前拖后腿的 4 类: 小盘股、金融、零售、运输(没创新高 = 宽度退化)
- 2002-10~2003-06: 纳指 +37%、罗素 2000 领涨; 2009 纳指 +30% 且跑赢标普 50%, 罗素 2000 +40%
- 书中**没有交易规则级别的回测**(没有胜率 / 期望), 全部是事后图表复盘 → 只能当"假设来源"

## 四、和 A 股的差异与适用性
- **时间尺度不同**: 墨菲讲的是月度~年度的资产配置 / 经济周期, 我们是 1~5 天短线。直接能用的只有两类: ①**隔夜外围 → A 股开盘**(时差决定了这是"已知信息", 不是同期相关); ②**风格 / 板块相对强度**(比率线)做市况与能力圈切换。
- **A 股的"四类资产"**更像: 美股科技(NQ / 中概 KWEB)、港股(HSI / 恒生科技)、离岸人民币(USDCNH)、A50 期货、商品(铜 / 油 / 金)→ 对应板块(有色 / 石油 / 黄金)。
- **数据缺口**: `history/global/` 有 NQ / ES / A50 / HSI / NKD / ndx / spx / kweb / fxi / ashr / ewy / ewj(2004~2018 起不等), **没有 USDCNH、黄金、原油、铜的历史日线**(`global_kline.jsonl` 每天只采当天一行, 10/09 起); MU3 要先补商品历史(用户批了才补, 遵守 B 站 / 行情源防封规矩)。
- **"关系会变"**是本书最重要的方法论教训, 和我们 market-skill 的"截至日 / 失效条件"一致: 联动系数要滚动算, 不能拿全历史均值。
- 债券(10 年国债收益率)对 A 股 1~5 天几乎没有可用信息, 不做。

## 五、可以给本项目做的回测候选
- **MU1 隔夜外围 → A 股开盘与日内**: 按 NQ / A50 / HSI 隔夜收益分档(5 档), 看 上证 / 创业板 / 中证 1000 次日 开盘跳空、开盘→收盘 的全分布; 重点问"外围大跌后的低开是被回补还是延续"。对应 02 市况(盘前首跑)。先查 `similar_days.py` / `window_similar.py` 是否已经把外盘当特征用了, 已有则只补"开盘→收盘"那段。
- **MU2 风格比率线**: 中证 1000 / 沪深 300 的 20 日相对强度分 3 档 → 各导师线(打板型 / 低吸型 / 转债)次日胜率与收益; 对应 02 市况 + 导师权重(对照 `docs/research/mentor_regime_20261022.md` 已有的市况分层, 避免重复)。
- **MU3 商品 → 板块开盘**(需补数据): 隔夜铜 / 油 / 金涨跌幅 ≥ 1σ 时, 有色 / 石油 / 黄金板块次日开盘与全天超额; 只在 20 日滚动相关 > 0.5 的"联动态"里看。对应 04 选股(题材联动)。
- MU4 小盘先见底: 上证 60 日新低后反弹 ≥8% 的样本里, 中证 1000 / 沪深 300 比率是否先于上证见底(样本少, 低优先)。

## 六、不自信点
1. 书是 2012 年前的美国宏观复盘, 对 A 股 1~5 日持有能贡献的只是"假设清单"; 我没找到任何可以照搬的阈值。
2. A 股受政策 / 国家队影响, 外围传导在大跌日可能被托底打断, 关系可能非对称(外围跌传导强、涨传导弱), 要分方向检验。
3. 第 2~7、14~15 章只读了小结, 1997 / 2000 / 2007 的事件复盘细节没看。
