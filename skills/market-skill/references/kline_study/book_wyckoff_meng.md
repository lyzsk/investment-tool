## 一、方法论骨架(第一章)
1. **只用三要素**: 价格、成交量、走势速度(趋势线角度)。作者明确反对与技术指标混用(后记: "千万别把本书方法和指标系统组合")。
2. **看盘顺序**: 背景 → 价量形态(蜡烛长度、成交量高度、变化速度) → 性质(强弱/原因/后果) → 结论 → 行动。"背景"永远第一。
3. **三大原则**: 供求(不平衡产生趋势) / 因果(趋势前必须有准备过程=震荡区; "没有吸筹就没有牛市, 不要抄底") / 努力与结果(量是努力, 价格进展是结果; 放量不涨/放量不跌=停止行为)。
4. **支撑/阻力的定义是供求不是画线**: 支撑=该价位需求吸收全部供应; 判断支撑有效看**从支撑起来的反弹力度**, 回测支撑时要"小蜡烛+小量"(供应枯竭)。图 1-6: 到支撑后无力反弹(小涨幅收中部)+ 再出现放量上影 → 支撑无效。
5. **垂直需求柱/垂直供应柱(VSB)**: 放量长阳(长阴)。其底部(顶部)自然成为支撑(阻力), 价格常回测。
6. **冰线**: 上升趋势最后一道防线 = "新高前反弹波段的低点"; 派发区间的下沿也叫冰线。破冰后大跌。
7. **超买线/超卖线**: 趋势通道的平行线(连接 2 个以上波峰/波谷再平行), 价格触及/突破=超买/超卖。**死角**: 趋势线与水平支撑阻力交叉、K 线高点降低低点抬高越走越窄 → 即将大幅波动。
8. **50% 原则**: 上涨波回调不破 50% = 强; 回调多次超过 50% = 警告。反弹不过前一下跌波 50% = 熊市延续。
9. **SOT(突破幅度缩短)**: 相邻波峰(或 K 线)之间新高突破距离递减 = 停止行为(图 3-1 用 2015 上证)。
10. **"右手边"**: 震荡区后段(二次测试之后)才找进场; 左手边(熊市第一次反弹)不抄底。

## 二、吸筹(第二章) —— 事件定义与图上特征
图 2-1(`img/wyckoff_fig2-1_bear_end_4steps.jpg`): 熊市终止 4 步 = 初次支撑 → 恐慌抛售 → 自动反弹 → 二次测试; 自动反弹高点与二次测试低点围成"吸筹区间"。

| 事件 | 原书定义/图上特征 | 原书确认/失效 |
|---|---|---|
| **PS 初次支撑** | 持续无反抗下跌后, 出现**扩大的成交量**使下跌暂停; 常是"下影线+放量"(图 2-2 蜡烛 1) | 需要后续 SC 确认; 有时与 SC 重合, 不易辨认 |
| **SC 恐慌抛售(超卖高潮)** | 下跌持续一段时间后, **超长阴线+超高成交量**, 振幅极宽, 可持续 1 天或几天(注[3]); 也可用"跌破超卖线"判超卖 | **没有上述价量特征就不是 SC**; 不是所有熊市都有 SC(第七节: A 股底部"很少出现恐慌抛售", 2008-2014 上证即无 SC, 靠长时间拖+JOC) |
| **AR 自动反弹** | SC 后的自然反弹, 多为空头回补, 不必在意, **不能在这里抄底** | 其高点=区间上沿; "空头回补的上涨之后会迅速带量回落"(第五章图一) |
| **ST 二次测试** | 回到 SC 附近, **价格波动和成交量都比 SC 明显缩小** = 成功; "成交量依然大但低于 SC"=也算 ST 但需再测 | 测试中**成交量继续扩大** → 浮动供应还在 → 跌破支撑熊市恢复; 图 2-2 蜡烛 4 (ST 但量巨大=失败), 蜡烛 5 (再测, 量减=接近停止) |
| 停止行为(两种) | ①下跌中"较大下影线+放量"(上涨中为"较大上影线+放量"); ②**"蜡烛大幅缩小但成交量大幅增加"**(努力无结果, 较隐蔽) | 停止≠反转, 只是提醒; 发生在震荡区右手边时可能导致大涨 |
| 疲劳战术(Phase B) | 区间内每次反弹到上沿就被打压, 缓慢枯燥下滑, 成交量低迷(图 2-6) | 区间早期波动大、后期波动和量都缩小 = 正常吸筹; **上涨波的振幅和量 > 下跌波** 才是吸筹 |
| **Spring 弹簧** | 价格**小幅**跌破区间支撑后 **1~3 根内收回**支撑上方(第四章) | 见第四节专表 |
| **终极震仓 Shakeout** | 吸筹末期**急速大幅深跌, 冲破所有支撑**, 随后快速反弹回区间(图 2-28 `img/wyckoff_fig2-28_terminal_shakeout.jpg`)。预警: 区间内反弹高点呈台阶式下降、到不了前高 | 需快速反弹确认(更高高点/低点/收盘+稳定递增的量); 再做缩量二次测试 = **风险最低的抄底点** |
| **SOS 强势出现** | 震荡区内"长阳+明显增高的成交量"; 也可是**连续 2~3 根阳线, 更高的最低价/收盘价/最高价, 成交量递增**(图 2-11) | **必须经随后的回调确认, 确认过程一定是小蜡烛+小成交量**; 测试出现放量长阴 → SOS 失效 |
| **JOC 跳离震荡区(越过小溪)** | SOS 的一种: **放量长阳突破震荡区顶部**, 宽振幅; 必须在区间右手边; 突破后量要有跟随 | 回测突破点时**缩量小蜡烛** = 最佳进场(LPS); 回测出现放量阴线 → JOC 失效, 回区间 |
| **LPS 最后支撑点** | SOS/JOC 后的缩量回测或"支撑上漂亮的反弹", 低点抬高(图 2-19 蜡烛 7) | — |
| 吸收 | 强势出现之后, 在供应区(前高套牢区)附近形成小震荡, **成交量放大但收盘都在高位** → 需求吸收了解套盘 | "吸收现象只发生在强势出现之后" |
| 低点抬高 | 再次测试的低点高于前低 = "CM 的最低收购价提高, 下方已买不到筹码"(图 2-7、2-19) | 反复出现=吸筹的有力证据 |

**吸筹三个进场位置**(图 2-4, `img/wyckoff_fig2-4_accum_entry_points.jpg`): ①SOS/JOC 后缩量回测(最安全); ②成功 ST 后且"上涨的阳线和量比下跌的长"时, 区间底部的 Spring(小幅跌破直接进; 放量大幅跌破等二次测试); ③终极震仓本身或其二次测试。**进场后必须看到价格和成交量递增, 若出现放量阴线立刻离场**(第五章反复强调 1~3 或 3~5 根内甄别)。

## 三、派发(第三章)
| 事件 | 原书定义/图上特征 | 确认/失效 |
|---|---|---|
| 顶部预警 | ①上涨波突破幅度递减(SOT); ②回调**超过**前一上涨波 50% 且量价扩大; ③上涨速度骤然加快、趋势线角度变陡(超过 45° 走向垂直); ④牛市中出现超长阳线+天量 | 预警≠顶; "在牛市中没看到供应扩大, 不能轻易猜顶" |
| **PSY 初始供应** | 牛市中首次大量供应上市: 放量下跌, 或先急涨后放量下跌; 也可是"放量但涨幅缩小"(图 3-9 X) | 只是临时阻止 |
| **BC 抢购高潮** | **天量新高长阳**, 上涨速度骤增(图 1-13、3-5); 可用"一波的累积成交量是上涨以来天量"判断; 区分技巧: **急涨若是突破重要阻力=正常上涨; 在空中无阻力处急涨=抢购高潮**(第四章图 4-11 后) | 有时没有 BC, 以圆顶/量价递减结束(第四节四) |
| AR 自然回落 | BC 后回落, 其低点 = CM 设立的派发支撑(冰线) | — |
| ST 二次测试(顶) | 再探顶, **成交量明显小于 BC**、无力创新高 = 成功, 确认牛市终止 | 测试量仍大 → 需要再测 |
| **UT 上冲回落** | 突破区间顶部(阻力)后**1~3 根内跌回**区间, 常是放量上影线; 本质=努力无结果 | **必须有阴线跟随+成交量递增**才发挥反转作用; 在上升趋势中、量不扩大的上冲回落只是"探索行为"(图 2-13 蜡烛 2、5), 不能做空 |
| **SOW 弱势出现** | 区间右手边**放量长阴**; 或直接放量跌破冰线(破冰)。宽松版定义(图 1-19 蜡烛 5): **①当日高、低都低于昨日; ②收盘低于昨收; ③成交量 ≥ 昨日** | 必须由随后的**无量(缩量小蜡烛)反弹**确认; 若反弹是放量阳线 → SOW 失效 |
| **LPSY 最后派发点** | SOW 后缩量小蜡烛反弹的顶部, 做空/出逃最后一班车 | — |
| 低位派发 | SOW 后形成的区间不一定是吸筹: 回升量递减+上沿出现 UT = 再派发(图 3-13~3-15, 作者说 2015 年后 A 股出现过) | 判吸筹还是派发的唯一标准是**右手边的测试行为**: SOS/终极震仓/Spring → 吸筹; SOW/带量 UT → 派发 |

图 3-8(`img/wyckoff_fig3-8_000006_distribution.jpg`)是 A 股实例: 深振业A(000006)2015-09~2016-02 日线, 1 初始供应、2 BC(放量)、3 AR、4/5/6 扩量高抛、7/8 建派发支撑、9 UT(量递增)、10 破冰 SOW。图 3-16/3-17 是 2015 年 6 月上证: 7 个交易日涨 800 点(BC), 十字星放量滞涨, 二次测试、UT、SOW 破冰。

## 四、Spring 交易法(第四章)
定义: 价格**迅速突破支撑, 然后迅速返回支撑上方**(1~3 根 K 线内), 是下跌的停止行为。
**三种 Spring**(图 4-2, `img/wyckoff_fig4-2_spring_3types.jpg`, 读图特征):
| 类型 | 图上 | 结论 |
|---|---|---|
| 左 | 跌破时**长阴实体+大成交量**, 深度跌破 | 支撑附近大量卖单, 不是要的 Spring; 在吸筹右手边出现叫"震仓", 需等二次测试 |
| 中 | 跌破时**小实体、短下影刺破、成交量大幅缩小** | **最好的 Spring, 可直接进场** |
| 右 | 跌破时略放量、**长下影线收回支撑上**、后续小阳线回升且量缩 | 等低量二次测试; 例外: 量大但**收在 K 线 50% 以上的下影线**, 在牛市中可直接进 |
另: Spring 失败 = 反弹没有出现持续上涨+量递增。

**Spring 的位置**: 牛市中的震荡区底部 / JOC 后回测突破点 / 回测垂直需求柱底部 / 吸筹末期; **熊市中的 Spring 是陷阱, 不能进场**("卖盘控制的背景下 Spring 是做空信号"); 牛市中连续失败的 Spring = 预警。
**Spring 前提**: 支撑必须是前面已建立的强支撑(需求强劲处)。

## 五、可机械化的要点汇总(→ definitions.md)
1. 背景判定: 趋势通道/50% 原则/SOT → 我们用"N 日涨跌幅 + 均线斜率 + 前一波回撤比例"近似。
2. "放量""缩量"全部是**相对**的(相对前一天、相对 SC、相对上涨波), 书中从未给绝对倍数 → 用个股自身近 N 日成交量的倍数/分位数实现, 符合用户"动态阈值"要求。
3. "长阴/长阳""小蜡烛" 同样相对 → 用 振幅/ATR 或 实体/近 N 日平均实体。
4. 停止行为②(量增、振幅缩)可直接写成: `vol_t > vol_{t-1}` 且 `range_t < k·range_{t-1}`。
5. SOW 宽松版三条件书中直接给出, 可原样编码。
6. 确认链: 事件本身不交易, **事件 + 随后 1~3 根的确认(缩量回测/放量跟随)** 才是信号 → 回测时信号日应取确认日, 不能用事件日(避免未来函数)。

## 六、我对本书的批判性看法
- 全书是**事后标注**的案例, 没有一个统计数字; 作者也承认"理想状态不是很多, 需要掌握的是原则不是形态"。
- 大量"CM(主力)意图"解释不可证伪(同一放量阴线, 在吸筹里是 SC/震仓, 在派发里是 SOW), **只能靠后续走势倒推**——这正是机械化最难的地方。
- 期货/外汇案例多(欧元、黄金、铜、标普期货), A 股案例约 6 个(上证 2008-2015、深振业、2015 股灾); 未讨论涨跌停对"放量长阴/SC"的影响(跌停板往往缩量)。
- 书中多处引流视频课程, 商业性强; 但术语定义与 Wyckoff 原典/Pruden/Weis 体系一致(UT、SOS、LPS、JOC、Creek、Ice 都是标准术语), 可信度中上。
