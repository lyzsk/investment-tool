## 一、回测口径(与我们对照)
| 项目 | zwQuant(书中) | 本项目 scripts/kline_study |
|---|---|---|
| 信号价 priceWrk | 复权开盘价或复权收盘价 | 后复权 OHLC(信号日收盘后计算) |
| 成交价 priceBuy | 第 5 章说"一般采用**次日的复权开盘价**"; **但第 8~9 章的海龟、MACD、KDJ、RSI 策略全部改成"信号日收盘价成交"**(作者: "为简化策略设计…统一采用 close, 对回测影响不大") | **T+1 开盘价**(主口径) + 信号日收盘(对照口径, 涨停收盘剔除) |
| 结算价 priceCalc | 复权收盘价 | T+h 复权收盘 ✓ |
| 持有 | 持有到反向信号(海龟: 收盘跌破前 15 日最低; RSI: <30) | 固定持有 1/3/5/20 日 |
| 股票池 | **单只股票**(海龟案例用 600401 ST海润, 2014~2016) | 全 A(主板/创业板/科创板, 非 ST, 日均额 ≥3000 万) |
| 手续费/印花税/滑点 | 不扣; 作者称"长期看可忽略, 吻合度超过 99%" | 未扣, 报告显式标注往返约 0.2% |
| 涨跌停/一字板 | 未处理 | T+1 一字涨停剔除; 涨停收盘不计收盘入场 |
| 参数优化 | 第 8.10 节**手工改参数逐次记录**("30,15 = 43.40%"); 作者自己注意到"从 2014 起回测大部分是正收益, 不利于优化, 改从 2015 起" | 不做参数搜索; 只用书中原参数 |
| 大盘 | 第 10 章把大盘指数读进内存库做对比 | 超额 = 减同日全池均值 |
| 绩效 | 累计回报、平均日收益、日收益标准差、夏普(rf=0.05 或 0, ×√252)、最大回撤、最长回撤时间、交易次数、盈亏交易明细 | 均值/中位/P10/P90/胜率/超额/按日聚类 t/两段对照 |
→ **我的判断**: ①"信号日收盘成交"在信号用的就是当日收盘价时, 实盘只能在 14:57 尾盘集合竞价近似实现, 回测会偏乐观; ②单股单段(含 2015 牛市)的收益数字(海龟 43%/95%、KDJ1 222%)没有参考价值; ③成本可忽略的说法对 A 股短线不成立。

## 三、可复用的指标代码对照
| 书/zwQuant | 本项目 | 差异 |
|---|---|---|
| zwta.MACD(12,26,9), 柱 = DIF−DEA | KChartView 口径: 柱 = (DIF−DEA)×2(同花顺/通达信) | 书没有 ×2, 只影响数值不影响符号 |
| STOD/STOK(TA-Lib 随机指标) | 国内 KDJ(9,3,3): K = SMA(RSV,3,1) | TA-Lib 的 slowk 用简单均线, 与国内 SMA(1/3 平滑)数值不同; 本次回测按国内口径 |
| RSI(n), Wilder | backtest_zwquant 用 Wilder 平滑(alpha=1/14); KChartView 用 SMA(N,1) | 一致(两者同为 1/N 平滑) |
| rolling_max/min 后 **shift(1)**(海龟 xhigh/xlow) | kline_defs 所有窗口统计 shift(1) | ✓ 一致, 作者也注意了不用当日最高价 |
| sharpe_rate(rets, rf, ntim=252) | 未使用(事件研究不需要) | — |
| 第 5 章 pandas 指标库(MOM/ROC/ATR/BBANDS/TRIX/ADX/CCI/OBV/MFI/DONCH…) | kline_defs 自带 ATR; 其余未移植 | 需要时可从书中抄式子, 注意 pandas 旧 API(pd.rolling_max)已废弃 |
可复用价值: zwQuant 的"策略 = 数据预处理函数 + 策略分析函数"(1+1 模式)和我们 `kline_defs.signals()` + `backtest_daily.process()` 的分层基本相同; 我们多了全市场、涨跌停、超额基准和两段检验。

## 四、方法论
- "数据分析 I2O 流程"; "KISS 法则"; "量化交易不是高频、不是自动交易"。
- 1.2 "一月效应": 统计思路与事件研究一致, 但无样本外与显著性。
- 第 8.10 节作者自己意识到"回测起点挑在牛市前会让结果好看"——这正是施瓦格说的"后见之明"。

## 五、不确定点
- zwQuant 未在本地运行; 书中策略在我们框架里是按原文规则重写的, 可能与作者代码细节(如 RSI 用 TA-Lib 默认参数、KDJ 用 TA-Lib STOCH)不完全一致。
- 我们用"首次成立日 + 固定持有", 与书中"持有到反向信号"不同; 持有到反向信号的版本未测。
