## 口径
| 项 | 设定 |
|---|---|
| 股票池 | 主板/创业板/科创板, `security_master.is_st=0`(只有当前 ST 标记, 历史 ST 会混入/漏掉), 上市满 130 根, 收盘 ≥2 元, 近 20 日日均成交额 ≥3000 万; 北交所未纳入 |
| 样本 | 信号日 2024-10-24 ~ 2026-10-15(约 2 年, 2,240,635 个股票日); **P1** = 2024-10-24~2025-10-23(偏牛), **P2** = 2025-10-24~2026-10-15(偏弱, 无条件 h5 中位 −0.39%) |
| 入场/出场 | 信号日 t 收盘后可知 → **T+1 开盘买**, T+h 收盘卖(h=1/3/5); T+1 一字涨停(买不到)剔除; 窗口内有涨跌幅超限的坏数据剔除。对照口径"信号日收盘买"(涨停收盘剔除)见表内 |
| 成本 | **未扣**(往返约 0.2%; 多数超额小于此) |
| 基准 | ①无条件: 同日全股票池均值 → "超额"; ②条件基准: 同背景但不要求形态核心条件(例: 锤子线 vs 所有"下跌背景+触及 20 日低点"的日子) |
| 显著性 | 同一天多只股票不是独立样本 → 主看**按日超额**(先按日期平均再平均)和其 t 值; |t|<2 视为不显著 |

## 三、补充检验(analysis_extra.py)
**A. 背景依赖**(上升背景 = 收盘 > MA60 且 MA60 比 10 日前高):
- UT · 上升背景 n=2,652: h3 按日 +0.72(t 3.6), h5 +0.63(t 2.3), P1 +0.56 / P2 +0.71 → **上升趋势里的"上冲回落"后 3~5 天反而跑赢**, 正是孟书说的"上升趋势中的上冲回落是探索行为, 不能做空"。
- Spring: 上升背景样本只有 114/189, 结论不稳; 非上升背景下放量 Spring h5 −0.40(t −2.2)。孟书"熊市中 Spring 是陷阱"方向一致, 但"牛市 Spring 好用"样本不足以证实。
- JOC · 上升背景 h5 −0.61(t −2.2), 两段 −0.57 / −0.65 → 突破追进在 A 股 5 日内是负超额。
**B. 收盘位置**(非涨跌停收盘, 振幅 ≥0.8ATR):
- 收在最高 10%(clpos ≥ 0.9) n=121,503: h5 按日 −0.43(t −4.8), P1 −0.55 / P2 −0.31; 收盘位置越高, 3~5 日超额越差, 单调。
- 上涨背景 + 收最低 10%(长上影类)h1 +0.35(t 4.6) 但 h5 −0.39 → 次日反弹, 一周转弱。
**C. 库林"确认/异常"**:
- **长阳(实体 ≥1.5 倍平均)+放量(≥1.5 倍均量), 非涨停收盘** n=108,267: 原始 h5 均值 0.12 / 中位 −0.61 / P10 −8.41 / P90 8.98 / 胜率 45.0%; 按日超额 h1 +0.12(t 3.3) → h5 **−0.40(t −5.6)**, P1 −0.56 / P2 −0.24。最好: 志特新材(sz300986) 2025-12-31 +126.0%; 最差: 捷邦科技(sz301326) 2026-07-10 −38.0%。→ 库林说的"确认"在 A 股 5 日维度是**均值回归**, 更接近威科夫"牛市里的超长阳+天量 = 抢购高潮/供应入场"。
- 小阳+放量(库林"异常") h1 +0.27(t 6.0), h5 ≈0。

## 六、局限(必须一起读)
1. 只有 2 年、两段行情; 2025-04-07/08 这类单日集中事件会主导小样本信号(W2、K2 最好案例都在那几天)。
2. 未扣成本; 超额 ±0.3% 级别的结论扣 0.2% 往返后基本归零。
3. ST 用的是当前标记; 名称含"退"的已退市股出现在样本里(SC 最差案例 退市国化、萃华退)。
4. 定义参数有 3 处在小样本上为凑样本数放宽过(见 definitions.md §5)。
5. 统计的是"单独使用形态", 书中所有作者都强调形态要放在位置/背景/确认里用——本次只做了"上升背景"一个维度。
