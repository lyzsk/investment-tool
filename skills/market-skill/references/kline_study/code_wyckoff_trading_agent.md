## 一、箱体识别 `identify_trading_range`(最值得借鉴)
- 窗口: 近 90 根, **排除当天**(`exclude_last=1`, 避免用当天收盘定箱体再判当天突破 = 未来函数)。
- 上下沿: 摆动高/低点(`swing_window=3`, 即左右各 3 根的分形)的**最近 5 个的中位数**; 摆动点 <2 个时退化为高 90 分位/低 10 分位。
- 合格条件: 宽度 4% ≤ (上−下)/下 ≤ min(max(30%×1.5, 24%), 55%); 首尾收盘漂移 ≤ max(12%×1.5, 18%); **上下沿各被测试 ≥ 2 次**(低点 ≤ 下沿×1.035 / 高点 ≥ 上沿×0.965)。
- 质量分 = 0.45·测试次数分(满 6 次) + 0.35·宽度分(理想宽度 = **4×ATR%**, 夹在 6%~40%) + 0.20·漂移分。
- 注释里写: "区间最大允许振幅为 ATR_pct 的 N 倍(替代固定的 30%)" → 作者也在把固定阈值改成 ATR 相对值。

## 二、触发器与阈值(FunnelConfig 默认)
| 触发 | 条件 |
|---|---|
| SOS | 收盘 ≥ 箱顶×(1−1%) **且** 当日涨幅 ≥ 6% **且** 量 ≥ 前 20 日均量×2.0(另有 3.0、95 分位的版本); 注释: "原 4.5% 追高触发止损率极高" |
| Spring | min(昨低,今低) ≤ 箱底×0.995 且 收盘 > 箱底×1.005 且 收盘 < 箱中+0.25 宽 且 量 ≥ 5日均量×1.1~1.3 |
| LPS | 近 3 日最低点在箱底+0.35 宽以内、收盘 > 箱底、近 3 日最大量 / 前 60 日最大量 ≤ 0.65(缩量) |
| EVR(放量不涨) | 量 ≥ 20 日均量×1.8、收盘 ≤ 箱中、当日涨跌幅在 ±2% 内、收盘 ≥ 箱底×0.98 |
| 派发 UT | 近 60 日、突破 1%、收回 0.3%、上影占比 ≥ 0.35、量 ≥ 1.5×、需离 MA200 ≥ 15% |
| 吸筹通道 | 现价 ≤ 年内低点+45%、60 日振幅 ≤ 40%、近 20 日均量/120 日均量 < 0.75、MA50 与 MA200 差 < 8% |
| 地量通道 | 近 10 日内出现 250 日成交量 20 分位以下的地量, 且现价 ≤ 年内低点+35% |

## 三、A 股涨跌停处理 `limit_move.py`(必须借鉴)
- 文件头原话: "A 股涨跌停制度会截断价格发现: **一字跌停当天几乎没有真实换手, '跌停'本身不代表出货或走弱确认, 也不能被当作有效的 Spring 支撑测试**。"
- 涨跌幅: 北交所 30%, 创业板/科创板 20%(**ST 也仍 20%**), 沪深主板 10%, 主板 ST 5%; 触板容差 0.15%。
- 分类: 触及/封住涨(跌)停、一字板、开板未封(炸板/烂板)。

## 四、实证结论(作者跑过的, 有成本)
`pattern_forward_eval.py` 头部记录(2026-08-22, 498 交易日, 2.3 万只次, 扣 0.202% 往返成本):
"前一日平淡(涨幅<3%)、当日大涨(≥7%)、次日开盘缺口 ≤4%" → T+1 开盘买, **T+5 净超额全为负, 且当日涨幅门槛越高越差**(7%: −0.71; 8%: −0.82; 10%: −0.98); 同期全市场 T+5 +0.44%。并指出"开盘买收盘卖 +10%"是**未来函数**。
→ 对我们: ①"放量大阳突破"类信号在 A 股次日接力上很可能是负 alpha, 我们的 SOS/JOC 回测要重点看; ②回测必须用 T+1 开盘价入场。

## 五、日内路径分类 `intraday_shakeout.py`
同样收盘价的大阴线, 用分钟线区分: 收盘位置 ≥0.62(强)/≤0.38(弱)、尾段成交占比 >0.55 视为尾盘抛压、盘中破支撑但收回=洗盘(washout), 放量下跌尾盘走弱=出货(distribution)。→ 可直接作为 Spring/震仓 的分钟级确认。

## 六、批判
- 阈值仍大量是百分比常数(6%、2 倍、0.995、1.005), 只在部分地方换成 ATR/分位。
- 它的结论是"形态在它自己的漏斗口径下"得出的, 混入了 RPS/市值/成交额等过滤, 不能直接等同于"纯形态"效果。
