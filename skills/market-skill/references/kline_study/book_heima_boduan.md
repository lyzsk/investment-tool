## 一、核心概念
1. **黑马线 = MA10**(股票生命线)。强势股两条标准: ①收盘在 MA10 之上; ②MA10 向上。买入后违反①= 体质减弱, 减部分仓; 再违反②= 生命终结, 清仓。
2. **一线乾坤**: 用 MA10 划分多空——(a) 位置法: 站上 MA10(突破后若回落, 再次站上视为确认)买, 收盘跌破且次日仍未收回卖; (b) **方向法: MA10 连续 2 天向上 = 由空转多(买), 连续 2 天向下 = 由多转空(卖)**(过滤噪音)。结论: MA10 向上且价在上 = 黄金机会; MA10 向上但价在下 = 较好; MA10 向下且价在下 = 不宜做多。
3. **双线交叉**: 短线 MA5 / MA10、中线 MA10 / MA20、长线 MA20 / MA60, **MA60 / MA120 判大势**; 作者偏向中线(经验上中线效果更好, 短线手续费吃利润)。
4. **三线开花**: MA5、MA10、MA20 同向且按短→长依次排列(= 多头排列); 大势版 MA20 / MA60 / MA120; **短周期与长周期同时开花 = 共振, 最佳**; 找法: 从长周期均线方向找起(最后转向的是长均线)。卖点 = 向下开花。
5. **多线穿越**: 一根 K 线同时穿过 3~4 条均线(均线粘合 = 多周期成本一致 = "时间超越平衡点")→ 变盘窗口; 向上穿越买、向下穿越卖。**断头铡刀**: 高位 MA5 / MA10 / MA20 黏合后一根阴线同时跌破三线 = 卖出。
6. **MACD**: DIF 上穿零轴 = 由空转多首个买点(零下震荡越久越有效, 首次上穿常有回踩, 分批); DIF 下穿零轴 = 卖; 背离要等 DIF 拐头才算完成; **绿柱"抽脚"(最长绿柱后第一根变短)= 买, 红柱"缩头" = 卖**; 抽脚只在 DIF > 0(多头市场)里可靠, 空头市场的抽脚"只是止跌"; 绿柱变红柱比抽脚更稳。
7. **共振起涨点**: 黑马线(站上且向上)+ MACD 金叉 同时成立 = 起涨点; 再加"量突破前高"更稳但买点更靠后(空间换胜率)。**多空临界点**(卖点)= 跌破黑马线 + MACD 死叉(+ 顶部 K 线 / 放量下跌)共振。
8. **买点决定胜率, 卖点决定盈亏比**; 成功投资者胜率多在 40%~70%、盈亏比 3~8。
9. **分时**: 健康上涨 = 白线(价)大部分时间在黄线(均价)之上、白线带动黄线上行; T+1 下在日线买点时间窗口内再到分时找买点。
10. **黑马线交易系统**(第八章, 表 8-4): 入场 = MA10 向上 ∧ 收阳 ∧ 收盘 > MA10 ∧ DIF > 0; 开仓 40%, 盈利 ≥5% 且再次满足条件加仓 40%、再加 20%(永不摊平亏损); 离场 = MA10 向下 ∧ 收阴 ∧ 收盘 < MA10(亏损未到 10% 时不因此离场), 或 亏损达 10% 无条件; 每次卖一半, 连续第二次清仓; 止损后再满足条件先补回止损量。手续费按单边约 0.2% 设。

## 二、可机械化的定义(日线, 只用 T 及以前)
| 编号 | 名称 | 口径 |
|---|---|---|
| HMD1 | 黑马线方向转多 | MA10_t > MA10_{t−1} 且 MA10_{t−1} > MA10_{t−2}, 且 MA10_{t−2} ≤ MA10_{t−3}(连续 2 天向上的第一天) |
| HMD2 | 位置法站上确认 | 收盘上穿 MA10 后 ≤5 日内回到 MA10 下, 再次收盘 > MA10 的那天 |
| HMD3 | 三线开花(双周期共振) | MA5 > MA10 > MA20 且三者都较昨日上升; 同时 MA20 / MA60 / MA120 三者都上升(大势版) |
| HMD4 | 多线穿越 | 当日 开 < min(MA5, MA10, MA20[, MA60]) 且 收 > max(同); 粘合条件: 前一日这几条均线极差 ≤ 1 ATR14 |
| HMD5 | 断头铡刀 | 近 20 日涨幅 ≥ 15%; 前一日 MA5 / MA10 / MA20 极差 ≤ 0.8 ATR; 当日阴线 开 > max(三线) 且 收 < min(三线) |
| HMD6 | 共振起涨点 | 收盘 > MA10 ∧ MA10 上行 ∧ 当日 DIF 上穿 DEA(或 5 日内发生过) |
| HMD7 | 绿柱抽脚(多头版) | DIF > 0 ∧ MACD 柱 < 0 ∧ 柱_t > 柱_{t−1} ∧ 柱_{t−1} 是近 10 日最小 |
| HMD8 | 黑马线交易系统 | 按表 8-4 原样(见上文第 10 条): 收盘信号, 次日开盘执行(书中按收盘价成交, 有前视) |

## 四、和 A 股 / 我们已有结论的关系
- 本书是**我们读到的唯一一个完整、可原样编码、带资金管理和出场规则的 A 股本土系统**——这正好补我们回测的两个缺口: KS6"只测了固定 1~20 日持有, 没测持有到反向信号"; kline_study 报告"没扣成本、没做敏感性"。
- 呼应 / 冲突:
  - **KS6(突破 / 超买追高跑输, h5 −0.71% t −6.1)**: 黑马线系统入场"站上 MA10 + 收阳 + DIF > 0"本质也是追涨型入场, 预期在固定 5 日持有下同样为负; 差别在"**持有到 MA10 转向**"——如果全市场回测仍为负, KS6 进一步加强; 如果翻正, 说明 A 股短线的问题是"出得太早"而不是"进错了"。
  - **KS2(非涨停长阳放量跑输)**: 入场条件"收阳"包含了长阳放量, 需要分组看。
  - **KS5(经典底部 K 线单独无优势)**: 本书锤子 / 背离都要求"等 MA10 拐头 / DIF 拐头"确认, 正好是 KS5 失效条件里"加上确认后尚未检验"的那一项。
  - 与埃尔德脉冲系统(13EMA × MACD 柱)、克列诺 CL1(突破 + 均线过滤 + 持有到止损)是同一类趋势跟踪, 三者可以同一个脚本跑、并排比较。
- 局限: 10cm / 20cm 涨停会让"收盘 > MA10"在连板股上一直成立, 回撤到 MA10 往往已经亏很多, 10% 硬止损在 20cm 票上一天就触发; 要按板块分开报。

## 五、可以给本项目做的回测候选(编号接总报告 H24 起)
- **HM1(→H24)黑马线交易系统全市场复现**: 表 8-4 原样(次日开盘执行、扣 0.2% 单边费), 全 A 2019~ 非 ST、日均额 ≥3000 万, 主板 / 创业板 / 科创板分开; 报 每笔收益全分布、胜率、盈亏比、平均持仓、最大回撤; 对照: ①同入场固定持有 5 / 10 / 20 日; ②同入场 + 克列诺 3ATR 追踪; ③随机入场 + 同出场(检验出场规则本身的贡献)。对应 KS6 修订、04(趋势型导师)、paper 账本的机械执行口径。
- **HM2(→H25)MA10 方向转多(HMD1)vs 位置法(HMD2)vs 共振起涨点(HMD6)**: 三种入场到"MA10 连续 2 天向下"出场; 比较哪个入场在 A 股最好、是否都劣于随机入场。
- **HM3(→H26)多空零轴过滤的增益**: 所有已有买入样本(KS1~KS9、导师 cases_auto 买点)按买入日 DIF > 0 / < 0 分组, 看 5 日收益差; 并与埃尔德脉冲红 bar(H04)比较谁是更好的"禁令"。对应 06 风控 / market-skill。
- **HM4(→H27)断头铡刀 / 多线穿越(HMD4 / HMD5)**: 向下穿越后 5 日收益 vs 同期近 20 日涨幅相近的样本; 向上穿越(均线粘合后一阳穿多线)后 5 / 10 日。对应持仓离场提醒 / 04。
- HM5(→H28)MA60 / MA120 金叉区间作为大势开关: 上证 / 中证 1000 处于金叉区间时, 全市场各类买入信号的 5 日收益是否显著更好(对应 02 市况; 先对照 regime 相关已有研究避免重复)。
