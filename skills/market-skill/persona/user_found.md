# market-skill · 用户发现(U 系列; 状态 = 假设, 每晚零 token 核销, 够样本升 M / KS 要用户点头; 10/25 建)

> 来源: 用户盘中 / 复盘时说出的盘面规律。只写规律本身, 不写用户持仓和成交。每条: 规则 + 适用对象 + 发现人 / 日期 + 机械口径 + 核销状态(样本 n / 命中率 / 截至)。
> **读法(用户 10/25)**: U 系列描述的是"妖债的一种走法模式", 不是全市场规律; 数字(+6% / −3% / 1.5%)是用户估算的量级, 振幅随这只票当下的波动走, 不是死线 ——
> 像桃哥挂低吸单"差一点点没成交"一样, 模式对了、细节差一点是常态; 本项目相对人工盯盘的优势是**快速认出模式 + 没成交马上改价**, 所以用的时候把阈值换成"这只票当下振幅"的比例(信号动态参数同口径)。

## 适用对象: 当下的妖债(活跃高波动转债)
- 机械口径(10/25 暂定, 待用户点头): 近 20 个交易日日均振幅 ≥ 8%(且成交额靠前); 每天收盘重算 —— 妖债是"某段时间"的状态, 会进会出
- 10/23 收盘按此口径: 澳弘转债 111024(近 20 日日均振幅 12.9%、日均成交 32 亿)、111012(8.5% / 15 亿)
- 澳弘 9 月中之前日均振幅只有 2% 左右, 不算妖债; 9/16 起 3.5% → 10/20 13.9%

### U1 妖债竞价低开后, 开盘几分钟内冲高 ≈6 个点 [假设 · 澳弘核销通过 · 全市场不通过]
- **时间状态**: 建立 2026-10-25 · 来源 用户(10/21~10/23 澳弘转债实盘观察; 10/25 澄清口径) · 状态 假设
- 规则: 妖债竞价低开(开盘价 < 昨收), 从竞价开盘价到开盘后几分钟内的最高点能有约 6 个点(低点到高点的收益率); 6% 是量级估算, 按这只票当下振幅浮动
- 机械口径: 开盘价(竞价) → 开盘后 30 分钟内最高价的涨幅(分钟路径 downloads/quotes/cb/minute_path); 分组 = 近 20 日日均振幅
- 核销(截至 10/22, 分钟数据; 脚本 scripts/market/user_found_check.py, 10/25 口径待按本条改):
  - 澳弘处在妖债期(近 20 日振幅 ≥ 3.5%, 9/16 起)的低开日: 9/16 +13.4% · 9/23 +12.4% · 9/30 −2.3% · 10/12 −0.1% · 10/15 +11.6% · 10/20 +8.7% → **6 次里 4 次 ≥ 6%**(另 9/11 振幅还只有 1.8% 时也冲了 +8.9%)
  - 全部活跃债(近 20 日振幅 ≥ 8%): 低开日 431 次, 开盘 30 分钟最高相对开盘 中位 +1.86%、P75 +3.55%, ≥6% 只有 10%、≥3% 33% → 作为"妖债普遍规律"不通过
  - 振幅 < 5% 的普通转债: 11585 次, 中位 +0.35%, ≥6% 约 0% → 不适用
  - 结论: **澳弘这只当下的妖债验证通过(n=6, 置信低)**, 其他妖债验证不通过; 失效条件 = 澳弘近 20 日振幅掉回 < 5%

### U2 妖债高开 +2~3% 后回落到 −3% 附近接 [假设 · 澳弘只有 1 次 · 全市场不通过]
- **时间状态**: 建立 2026-10-25 · 来源 用户(澳弘转债) · 状态 假设
- 规则: 妖债高开 +2%~+3%, 盘中回落到相对昨收 −3% 附近接, 之后能反弹(幅度按当下振幅浮动)
- 核销(日线, 截至 10/23):
  - 澳弘: 只出现 1 次(10/22): −3% 接 → 当天收盘 −0.71%, 次日最高 +3.34%, 次日收盘 −6.18% —— 次日冲高卖才赚, 拿着亏
  - 全市场转债 63 次: 当天收盘中位 −0.53%, 次日最高中位 +2.71%, 次日收盘中位 −1.35% → 不通过(只有"次日冲高卖"的版本有空间)
  - 结论: 样本不够, 保持假设; 要按"接了以后在哪卖"拆开核销

## 适用对象: 主板股票(沪 60 / 深 00)

### U4 昨日跌停失败(逼近跌停没封住、被拉回)= 有资金在维护; 次日冲高是资金出逃的卖点, 不是拿着的理由 [假设 · 全市场日线初核支持 · 待分钟级核销]
- **时间状态**: 建立 2026-10-25 · 来源 用户(10/23 百洋股份: 10-22 最低 9.63 逼近跌停 9.47 没封住、收 9.81; 10-23 开 10.09 → 09:33 冲到 10.61 → 收 10.25) · 状态 假设
- 规则: T−1 盘中逼近 / 触及跌停但没封住、被拉回 → T 日开盘后的第一波冲高(按术语表「反抽」口径: 1 分钟 MACD 红柱连续 ≥3 根 + RSI6 > 80 + 价 ≥ 分时均价)是卖点; 持仓不在开盘第一跳按挂单价砸, 也不拿到收盘
- 机械口径(10/25 暂定): T−1 最低 ≤ 跌停价 × 1.02 且 T−1 收盘 ≥ 跌停价 × 1.03; 主板 60 / 00, 非 ST
- 核销(日线, 2025-10-01 ~ 2026-10-22, n=324; 主会话 10/25 零 token 初核):
  - T 日开盘相对 T−1 收盘: 均 −0.74% · 中 −0.55% · P10 −2.47% · P90 +1.12% —— 多数平开略低
  - T 日最高相对 T 日开盘: 均 +3.40% · 中 +2.47% · P10 +0.26% · P90 +7.88% —— **开盘后普遍有冲高空间**
  - T 日收盘相对 T 日最高: 均 −4.13% · 中 −3.93% · P10 −7.12% · 最差 −13.92% —— **冲高后普遍回落**
  - T 日收盘相对 T−1 收盘: 均 −1.61% · 中 −2.07% · P10 −6.30% · P90 +3.52% —— 拿到收盘偏亏
  - T 日最高 ≥ T−1 收盘 +3% 的占 35%
  - 结论: "次日有冲高、冲高后回落、拿着偏亏"三项都支持(置信 中, n=324); **没验证的**: 冲高发生在几点(要分钟线)、按「反抽」口径卖能卖到冲高的几成、和"昨日跌停封死"组对比、分题材 / 市况
- 待做核销: 分钟级(downloads/quotes/stock/minute_path + kline_minute)算 反抽口径卖点 vs 当天最高 vs 开盘价; 每晚 user_found_check.py 滚动加样本

### U5 跌停打开后: 拉得快(几分钟拉起 ≥5%)= 资金先让恐慌盘出清再低吸, 有资金但有分歧; 不二封跌停 = 在走强 [假设 · 待核销]
- **时间状态**: 建立 2026-10-25 · 来源 用户(10/23 吉大正元 003029: 开盘一字跌停 21.33 → 09:36 一分钟拉到 22.37(约 +5%)、成交 953 万股 → 09:42 回落到 21.51 没再封跌停 → 10:40 冲到 24.63(相对跌停 +15%)→ 收 23.05) · 状态 假设
- 规则: 跌停打开后 ①拉起速度: 几分钟内拉起 ≥5% 且放巨量 = 资金主动撬板, 先让恐慌盘出清、再在回落里低吸 → 资金在, 但内部有分歧 / 分化(会有回落); 慢慢磨起来 = 被动修复 ②之后**没有二封跌停**(回落不回到跌停价)= 在走强; 二封跌停 = 弱
- 机械口径(10/25 暂定, 待核): 当天开盘或盘中封跌停 → 首次开板后 N 分钟(N≤5)内最高相对跌停价 ≥ +5% 且该段成交量 ≥ 当日前 30 分钟均量 × k → "急拉"; 开板后到 10:30(或开板后 60 分钟)最低 > 跌停价 = "没二封"
- 用法: 持仓 / 观察票出现"急拉 + 没二封" → 不在第一波回落里恐慌卖, 回落企稳(不破急拉起点)是低吸点; 出现"二封跌停" → 弱, 反抽就走
- 核销计划: 分钟数据(kline_minute 关注集 10/09 起 + stock minute_path 100 日涨跌停票)统计 急拉 vs 慢拉、二封 vs 没二封 四组的当日收盘 / 次日开盘 / 次日最高全分布; 结论写回本条
- 对照(同日反例): 天威视讯 002238 10/23 开盘一字跌停 6.57, 09:36 短暂打开到 6.70(+2%)马上回封、10:00 前反复回到跌停 → "慢 + 二封"; 收 6.65

### U7 自己的票涨停后挂"涨停价回落 1.5% 清仓"; 炸板回封成功的(尤其二板)次日有溢价高点, 拿过夜次日冲高卖 [假设 · 全市场初核支持 · 待分票质量核销]
- **时间状态**: 建立 2026-10-25 · 来源 用户实盘经验(1% 容易误杀炸板回封; 二板炸板回封成功次日容易出溢价高点) · 状态 假设
- 核销(事件本体 open 事件, 主会话 10/25 零 token):
  - 开板深度 → 之后回封: ≤2% n=2115 回封 97% / 收盘封住 73% · 2~4% n=1093 66% / 53% · 4~7% n=877 26% / 21% · >7% n=412 12% / 9% —— 浅开板多数会回封, 1% 触发会卖掉大量之后回封的
  - 当天回封成功(第 1 次开板后又封到收盘)→ 次日(相对当日收盘): 首板 n=1824 最高中位 +5.92%(P25 +2.77) 收盘中位 +1.17% · 二板 n=320 最高中位 +6.80%(P25 +3.41) 收盘 +1.26% · 三板+ n=170 最高中位 +7.63% 收盘 +1.27%
  - 和 10/26 离线测试"二封那一刻就卖好 0.51%"冲突的原因: 那个测试拿过夜按**次日开盘**估值, 没按次日冲高卖 —— 对"次日冲高卖"的打法不适用
- **10/25 晚用户补充(经验, 假设)**:
  - 回落幅度看票强弱: 涨停价回落 **1.5% ~ 1.75%** 清仓 —— 票越强、市场短线情绪越和这只票共振(同题材在发酵 / 梯队完整 / 情绪周期在上升段), 越往 1.75% 放(给回封留空间); 弱票 / 情绪退潮 / 孤板, 用 1.5%
  - 低位二封次日溢价: **低位**的票当天炸板回封成功(二封), 次日容易出冲高溢价, 计划次日冲高卖; "低位"是相对概念 = 相对当天市场最高连板, 用户暂定 最高连板 10 板时 4 板及以下算低位(用户自述不自信)
- 机械口径(10/25 暂定, 待核): 强弱共振 = 本票题材在近 5 日最活跃题材里 + 情绪周期(涨停家数 / 晋级率)不在退潮 + 梯队位置非孤板; 低位 = 本票连板高度 ≤ 当天最高连板 × 0.4
- 待做核销: ①1.5% vs 1.75% 按"强弱共振"分组, 比较误杀回封率和崩板时多亏多少(要分钟级 + 题材 / 情绪数据) ②低位 vs 高位(按相对最高连板)回封成功次日最高 / 收盘全分布 ③"低位"阈值 0.4 是否合理(试 0.3 / 0.4 / 0.5)
- 没验证的: 1% vs 1.5% 在 ≤2% 那档里的细分(本体深度只分到 ≤2%)、分票质量(题材阶段 / 梯队位置 / 龙虎榜资金)后的差异、次日冲高能卖到最高的几成(要分钟级)
