## D 类 · 定义

### KD1 箱体上沿 / 下沿(日线)[定义 · ✅ 用户 10/24 认可, 已进术语表]
- **时间状态**: 建立 2026-10-24 · 状态 已定(用户看了牧原股份 002714 示意图: "你对箱体的理解没问题, 就是这样")
- 规则(段式箱体): 横盘 ≥8 根起箱; 上沿 = 箱内实体顶的 90% 分位、下沿 = 实体底的 10% 分位(去单根长影线); 宽度 1.5~8 ATR; 收盘越出边界 0.5 ATR 连续 >2 根才算离箱, 1~2 根就收回 = 假突破(UT)/ 假跌破(Spring), 箱体不断; 每延伸一根重算上下沿
- 引用必须写级别: `日线箱体上沿 43.22`
- 代码: `scripts/kline_study/draw_box.py seg_boxes`; 图例 `skills/market-skill/references/kline_study/img/box_002714_2026-10-23.png`(三个箱体: 06-22~07-13 / 07-14~08-26 / 08-27~10-23)
- 旧口径(摆动点中位数 + 60 根包含率 ≥80%)作废: 趋势段和横盘段混在 60 根里包含率过不了, 牧原 3 个月只认出 4 天
- 失效 / 不足: 起箱段如果其实是缓涨趋势也会被框进来(牧原箱体 1 偏斜); 宽度 1.5~8 ATR 是拍的, 待参数敏感性

### KD4 威科夫事件(SC / ST / Spring / JOC / LPS / UT / SOW) [定义]
- **时间状态**: 建立 2026-10-25 · 最后验证 2026-04-02 · 状态 待复核
- 规则: 见 `skills/market-skill/references/kline_study/definitions.md §4` 表(W1~W9)。核心: SC = 20 日跌势 + 60 日新低 + 量 ≥ 自身 95 分位 + 振幅 ≥ 自身 80 分位; ST = SC 后 5~40 根、出现过 AR、回到 SC 低点附近、量 ≤ 0.6×SC 量; Spring = 刺破箱底 0.1~1.5ATR 收回(缩量最好、放量等二次测试); JOC = 收盘越箱顶 0.3ATR + 量 ≥ 85 分位 + 收在上 1/4; LPS = JOC 后 10 根内首次缩量回踩不破; UT = 冲过箱顶收回 + 放量 + 长上影; SOW = 放量长阴跌破箱底 0.3ATR
- 来源: 孟洪涛《威科夫操盘法》第 1~4 章(图 2-1、2-4、2-28、3-7、4-2) · WyckoffPro 阈值
- 失效: 书中所有事件都要后续确认; 单独事件日不是信号

### KD7 箱体五阶段(市况位置层, 20 日收盘箱体) [定义 · 10/20 市况改造 R 系列; 10/25 从 docs/knowledge/box.md 并入]
- **时间状态**: 建立 2026-10-20 · 最后验证 2026-10-25 · 状态 活跃(事实包「多指数箱体位置」在用)
- 口径(和 KD1 段式箱体不是一回事, 引用要写清): `scripts/quotes/indicators_db.py` 的 box_hi / box_lo = 近 20 日**收盘价**最高 / 最低(不用影线, 单日长影不撑大箱子); box_pos = (收盘 − box_lo)/(box_hi − box_lo); regime = er20 低 + 箱宽小 + 上下沿各触碰够次数 → 交易区间 / er20 高 + 均线排列 → 上涨 / 下跌趋势 / 其余无规则
- 五阶段: 向下破位(收盘 < 前一日 box_lo 且 er20 走高 → 不接刀, 等 3 日不创新低的新箱底)· 下沿超跌反弹(box_pos ≤ 0.2 + 止跌迹象: SC/ST、长下影、量能衰竭 → 左侧轻仓, 失效 = 箱底 − 0.5 ATR)· 中部震荡(0.2~0.8 → 高抛低吸 / 做 T, 不追)· 上沿超涨回踩(≥ 0.8 未突破, 或突破后 ≤ 2 日回箱 → 减仓 / 高抛, 突破失败按 UTAD)· 向上突破(收盘 > box_hi 且量 ≥ 20 日均量 × 1.5、次日不回箱 → 右侧跟进, 止损 = 原箱顶下方)
- 达瓦斯原版: 新高后连续 3 天不再创新高 = 箱顶; 回落低点连续 3 天不再创新低 = 箱底; 放量破箱顶买, 止损在新箱底下
- A 股坑: 突破日常直接涨停 → "放量"改看换手 / 封单额; 20 日窗口对游资连板票太大、对宽基 / 银行偏短(按近 60 日振幅分位调); 个股突破但指数在"向下破位" → 失败率高; indicators 是前复权, 原始价挂单要换回
- 失效 / 证伪: 窗口 / 收盘 vs 影线改了结论就变 → 固定口径; 3 年全 A 回测五阶段之后 5 / 10 日收益, 阶段间差异不显著就退回"描述语言"(未做)
### KD8 威科夫区间阶段(吸筹 A~E / 派发) [定义 · 10/25 从 docs/knowledge/wyckoff.md 并入; 事件口径见 KD4]
- **时间状态**: 建立 2026-10-20 · 最后验证 2026-10-25 · 状态 活跃(只作描述语言)
- 三定律: 供求(量价是供求唯一可观测投影)· 因果(横盘时间 × 宽度 = 突破后能走多远)· 努力与结果(量 = 努力、价格位移 = 结果, 放巨量价格不走 = 对面有人接 / 派)
- 吸筹: A 止跌(PS → SC → AR → ST, SC 低点 + AR 高点框出区间)→ B 筑因(区间内反复 ST, 量收敛)→ C 测试(Spring / Shakeout + 低量 Test)→ D 走强(SOS 放量大阳穿区间 → LPS 缩量回踩不破, 经典买点)→ E 趋势(JAC 跳过小溪 → BU 回踩确认); 派发镜像: PSY → BC → AR → ST → UTAD → SOW → LPSY
- 机械初稿(待回测定阈值): 努力与结果背离 = 量 ≥ 均量 × 2 但 |涨跌| ≤ 0.3 ATR; LPS = SOS 后回踩 box_pos ≥ 0.5 且量 ≤ SOS × 0.5; UTAD = 站上 box_hi 后 ≤ 2 日跌回且放量
- A 股坑: SC / BC 常以跌停打开、涨停炸板出现, "一日 Spring"常被涨跌停截成两天(用 2 日窗口); 游资票"吸筹"只有 3~5 天, 威科夫更适合指数 / 权重 / 中军 / ETF 和持有 ≥ 5 天的导师; 节前缩量 / 成分调整放量先剔除; 政策底巨量形似 SC 但不一定走完 B~E
- 用法: 箱体(KD7)给"在哪", 威科夫给"区间性质"; 06 失效位: Spring 买点 = Spring 低点、LPS 买点 = 区间中轴; 07 把"买在派发区(BC / UTAD 后)"当可统计的错误类型
### KD9 缠论(分型 / 笔 / 线段 / 中枢 / 背驰 / 三类买卖点) [定义 · 只做辅助, 不做主信号 · 10/25 从 docs/knowledge/chan.md 并入]
- **时间状态**: 建立 2026-10-20 · 最后验证 2026-10-25 · 状态 活跃(只作结构描述, 未机械实现)
- 包含处理: 相邻两根一根高低点完全包含另一根 → 按当前方向合并(向上取高高、向下取低低), 处理完才找分型
- 分型: 顶 = 处理后连续三根中间那根高点最高、低点也最高; 底镜像。笔 = 相邻顶底分型相连, 新笔要求分型之间不共用 K 线且至少一根独立 K 线(老笔 ≥ 5 根)。线段 = 至少三笔且前三笔有重叠, 结束用特征序列分型判
- 中枢: 被至少三个连续次级别走势重叠的部分, ZG = 三段高点最低者、ZD = 三段低点最高者, 区间 [ZD, ZG](要 ZG > ZD); 盘整 = 一个中枢, 趋势 = 两个以上依次同向不重叠的中枢
- 背驰: 同向后一段力度 < 前一段(MACD 柱面积 / 黄白线高度; 参数必须固定); 趋势背驰 = 最后中枢之后那段 vs 前一中枢之后那段
- 三类买点(卖点镜像): 一买 = 下跌趋势背驰低点(左侧, 最容易错)· 二买 = 一买后首次次级别回调不破一买低点 · 三买 = 次级别向上离开中枢后回抽低点 > ZG(右侧, ≈ 箱体"突破后回踩不回箱", 可和 KD7 交叉验证); 区间套 = 大级别买点区内逐级找小级别背驰定时点
- A 股坑: 一字板让分型 / 笔失真, 连板票基本不适用; **结论必须带级别**(日线一买、5 分钟可能是三卖); T+1 股票小级别买点只能用来定"今天在哪买 / 明天在哪卖", 日内来回只限转债 / ETF; 网上口径不统一, 实现时固定一个开源口径(参考 czsc)并注明
- 可机械化: 包含处理 / 分型 / 笔 / 笔中枢 / MACD 面积背驰; 难: 有缺口时的线段特征序列
- 证伪: 机械实现后 3 年数据统计三买 / 三卖后 5 / 10 日收益, 不显著优于箱体就不引入(能用箱体解释的不用缠论)
### KD10 波浪理论(5 浪推动 + 3 浪调整) [定义 · 权重最低, 只当情景生成器 · 10/25 从 docs/knowledge/elliott.md 并入; 书笔记见 references/kline_study/book_elliott_wave.md]
- **时间状态**: 建立 2026-10-20 · 最后验证 2026-10-25 · 状态 活跃(只用于指数 / 宽基)
- 结构: 推动 1~5(内部 5-3-5-3-5)+ 调整 A-B-C; 分形, 每浪由低一级浪构成
- 三铁律(违反即数错): 2 浪不回撤超过 1 浪起点 · 3 浪不是 1/3/5 中最短 · 4 浪不与 1 浪价格区间重叠(倾斜三角形例外)
- 指引(非铁律): 2/4 浪形态交替; 2 浪常回撤 1 浪 50%~61.8%、3 浪 ≈ 1 浪 × 1.618、4 浪回撤 3 浪 38.2%、5 浪 ≈ 1 浪等长; A 股多为 3 浪延长; 调整浪: 锯齿 5-3-5(C ≈ A)/ 平台 3-3-5 / 三角形 3-3-3-3-3 / 复合 W-X-Y
- A 股坑: 政策冲击让浪形断档(按政策节点重置起点); **个股(题材股)浪形基本无意义, 只用于指数和大市值 / 宽基 ETF**; 多种合规数法时必须同时写首选 + 备选 + 各自失效价位
- 可机械化: 给定摆动高低点(缠论笔 / ZigZag)检查三铁律 + 算斐波那契参考位; 数浪本身不机械化
- 纪律 / 证伪: 每次用必须写失效价位, 失效即切备选、不许事后改数; 统计 02 里波浪情景 1~3 日命中率, 对比不带波浪的 02, 无增益就移除

### KS1 上升窗口(跳空)后 3 天没补, 之后 5 天统计上跑输 [风控 · 统计 · ✅ 用户 10/25 点头]

### KS2 非涨停的长阳 + 放量, 之后 5 天统计上跑输 [风控 · 统计 · ✅ 用户 10/25 点头]
- **时间状态**: 建立 2026-10-25 · 最后验证 2026-07-10 · 状态 待复核
- 规则: 阳线实体 ≥1.5 倍近 10 日平均实体、量 ≥1.5 倍 20 日均量、收盘未涨停 → 次日可能还有惯性, 但 3~5 天统计上回吐; 追这类 K 线要有更强理由
- 证据: n=108,267; h5 原始均值 0.12% / 中位 −0.61% / P10 −8.41% / P90 8.98% / 胜率 45.0%; 按日超额 h1 +0.12%(t 3.3)、h5 −0.40%(t −5.6); P1 −0.56% / P2 −0.24%; 最好 志特新材 2025-12-31 +126.0%, 最差 捷邦科技 2026-07-10 −38.0%
- 来源对照: 与孟洪涛"牛市中超长阳+天量是抢购高潮/供应入场"一致; 与库林"长阳+放量=确认"相反; 与 WyckoffTradingAgent"当日大涨次日接力负 alpha"、market-skill M1 同向
- 置信: 中高 · 失效: 未区分题材主线/连板梯队(高辨识度龙头可能相反)
