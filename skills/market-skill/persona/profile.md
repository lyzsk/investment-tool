# market-skill 画像（盘面共性知识）

- 管什么: 全市场统计意义上"这种状态下第二天大概率怎么走"——强势股（首板 / 二板 / 三板+ / 炸板 / 大涨 / 涨停回调 1~3 天）× 市况（上证 / 创业板涨跌档 × 当天涨停家数）的次日表现
- 不管什么: 选哪只票、导师的打法和节奏（那是导师 skill 的事）
- 口径: **现实可成交**——封死涨停当天收盘买不进，按次日开盘买（一字跳过）、再下一天卖；非封死按当天收盘买、次日卖；扣来回费 0.15%
- 数据: `downloads/market/similar/stock_strong.jsonl`（2023-01 起全 A，约 23.5 万个强势股日，每晚重建）；研究报告 `docs/research/strong_next_20261022.md`
- 必查里对应的查询: 「强势股次日」（本票昨收状态的历史同类次日开盘 / 冲高 / 最低 / 振幅 / 收盘分布）
