# 桃哥规则库 · 可执行化规格 v0.1

> 来源: 2026-09-14 ~ 09-18 五天视频提取 (downloads/analysis/*.json)
> 目的: 把"他说的话"分成 [可执行信号 / 可复用规则 / 马后炮 / 噪音], 并把可执行部分写成"触发→入场→失效→出场"的机器可判定形式, 供 T+1 盘中提醒和回测使用

## 0. 四分类框架(每条提取内容必须打标)

| 类别 | 定义 | 例子 | 处理 |
|---|---|---|---|
| **F 预测/计划** | 对未来说的, 带明确标的+条件 | "明天沐曦解禁, 参照今天-17拉回的剧本" | 进信号表, T+1 盘中监听触发 |
| **R 可复用规则** | "如果...就..."的战法 | "利空落地日不看跌幅看时间, 3-4分钟看承接" | 进规则库, 作为盘中判定逻辑 |
| **H 马后炮/复盘解释** | 解释今天为什么涨/跌, 无明日指向 | "今天科技跳水所以资金回流防御" | 只作次日 context, **不能直接产生交易信号** |
| **N 情绪/噪音** | 心碎/哇靠/载入史册 | "我非常心碎" | 丢弃(仅用于风格画像) |

**马后炮陷阱示例**: 9/15"固态电池一日游, 跑得慢亏钱"——这是 H(总结当天), 但它同时也是 R(下次遇到同类消息行情的操作纪律)。**判别标准: 把句子改写成"如果明天出现 X, 应该 Y"能成立的才算 R/F; 只能描述过去的, 标 H。**

## 1. 已提炼规则 → 可执行规格

### R1 利空落地反转 (证据强度 ★★★, 本周连续 2 次兑现: 沐曦预告→+18.8%, 科创解禁票-17拉回)

- **原文**: "利空大家提前都知道了, 提前砸; 落地的时候一波大涨" / "不看跌幅看时间, 开盘3-4分钟看成交"
- **前置条件**: 标的有已知的、日期确定的利空(解禁/处罚/业绩暴雷), 且利空前已提前下跌(跌透)
- **T+1 触发**(盘中可判定):
  1. 利空日低开或开盘后下杀
  2. 开盘 3~5 分钟内放出巨量(对照: 近5日同时段均量的 3 倍以上)
  3. 价格不再创新低 = "跌不下去"
- **入场**: 满足 1+2+3 后追入(他说"34分3.56还是可以追的")
- **失效/不买**: 低开后缩量阴跌(没承接), 或利空未被市场提前消化(没提前跌)
- **出场**: 未明确说; 暂定: 当日冲高回落破分时均线走, 或次日不延续就走
- **盘中监听**: 信号池里带"已知利空日"的股票, 09:30-09:35 重点看量价
- **回测近似**(历史无分时数据时): 利空日 OPEN < 前收×0.97 且 CLOSE > OPEN×1.05 且 VOL > 5日均量×2 → 视为触发, 入场价≈OPEN×1.02

### R2 重大利空前拿先手 (★★★, 9/16"最后一天是买点"→9/17创业板大涨兑现)

- **前置**: 市场级确定日期事件(美联储加息/重磅会议), 预期已打满(概率>90%)
- **触发**: 事件前最后一个交易日, 市场已提前下跌后的企稳/反弹日 → 买(科技等弹性方向)
- **出场**: 事件落地后冲高兑现
- **监听**: 事件日历(手动维护) + 大盘指数分时

### R3 天地板/巨量高标=出货, 次日跌停还是卖 (★★★, 9/14瑞尔特→9/15跌停兑现)

- **触发(复盘识别)**: 高位票当日天地板(触及涨停后收跌)且放巨量(>5日均量3倍)
- **执行**: 持仓者次日开盘立即卖; 未持仓者加入避开名单(至少3天)
- **识别特征**: 该票是被"软件标签"误归类蹭板块的高标(瑞尔特标消费实为家具) → 需要人工/LLM 核实主营

### R4 一日游消息行情: 跑得慢亏钱 (★★☆)

- **触发**: 前日突发消息刺激的板块(固态电池/网络安全), 次日冲高
- **执行**: 持有者冲高就走, 不格局; 未持有者不追; "太一致的一字板不追"(R4b)
- **马后炮警示**: 只有持仓时此规则有意义 → 需要东财持仓数据匹配板块

### R5 缩量市场只拉辨识度龙头 (★★☆)

- **环境判定**: 两市成交额连续萎缩(如<1.7万亿)
- **执行**: 同概念里只买辨识度最高的(连板数/成交额/市场讨论度), 不买同概念低位"杂毛"(他粤桂股份不赚钱的教训)
- **数据**: 每日成交额(腾讯指数行情) + 板块内连板/成交额排名

### R6 低吸前期高标的时机 (★★★, 9/17国芳→9/18涨停兑现)

- **前置**: 前期高标(近期有连板记录), 回调到支撑位, 当日主线(如科技)跳水→资金切防御
- **触发**: 主线指数/板块盘中跌幅>1.5% 且 目标票下杀不破前低/关键均线
- **入场**: 下杀企稳时低吸(他9/17"掏了一把")
- **出场**: 未说; 暂定次日冲高或破板走

### R7 利空链传导蹭消息 (★★☆, SK海力士→太极实业)

- **触发**: 加红电报出现海外大厂利好(SK海力士/英伟达) → 立即检索 A股"与其有合作/合资"的标的
- **执行**: 午后/盘中消息出来后追辨识度最高的关联票(炸板风险自负)
- **数据**: 需要预建"海外大厂→A股关联公司"映射表(LLM 生成+人工校对)

### R8 他不做的(负面规则, 同等重要)

- 不玩新股/次新股(C燧原、沈鼓只记录不参与)
- 不追"每天杀一个大票"环境里的大白马
- 抱团核心集体跌停时(亏钱效应), 回避同类高标
