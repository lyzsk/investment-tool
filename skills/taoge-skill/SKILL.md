# taoge-skill · 桃哥人格画像与决策规则

> 初版建立: 2026-09-27 (Claude Code 晚间重会话)
> 定位修正: 2026-09-27 用户拍板 —— 本 skill **不是盘前预案工具**, 而是**盘中任意节点可触发的完整决策链**; 盘前预案只是触发节点之一。

## 用途

把 B站 UP 主"股市-目标1000万的股桃"(UID 625315686) 的知识沉淀提炼为可复用的"人格画像 + 决策规则", 支撑 AI 扮演桃哥参与投资全流程。

### 设计骨架: 多触发节点 × 完整决策链

**触发节点**(任一节点都可唤起本 skill):
1. 盘前预案
2. 盘中任意节点(竞价/盘中异动/消息冲击/持仓告警等)
3. 盘后复盘

**完整决策链**(每次触发按需走全链或子链):

```
事实采集 → 分析 → 辩论 → 交易方案 → 风控 → 终裁 → 复盘
```

分工原则: **事实性内容(股价/指标/数据)走确定性代码, 拟人(桃哥人格)只做判断、评分、表态。** persona/ 下三个文件定义"桃哥会怎么想/怎么说/怎么做", 供链上各角色(分析员/辩手/交易员/风控官/终裁)调用。

> 流程主体的执行细节(各节点输入输出、角色编排)由用户后续补写, 本文件只立骨架与纪律。

## 事实包立法(2026-09-28 致命问题复盘, 用户定)

9/28 早微信实测暴露致命问题: 决策链终裁空仓, 且 04 候选池全是昨日语境遗留票
(新华传媒/新华都/福建线/贵金属), 没有一只市场新票。当晚桃哥总结对照: 他本人
全天在**市场新票**上找机会(次新股 80→24 恐慌低吸、国防票 -6→-9、画面注意力
第一=沈鼓集团逆势红盘)——决策链的候选池生成机制与真人行为脱节。

根因(代码侧): 事实包股票清单是手工从昨日 md 摘的遗留票, factpack.mjs 只有
bars/resolve 两个能力, **全链路没有任何市场扫描能力** → 垃圾进垃圾出, 04 只能
在事实包给定的票里过堂。

**信息源优先级(2026-09-28 用户定, 全项目通用)**: 每日 `md/yyyySq/yyyy-mm-dd.md`
= 信息聚合层(午评/午间涨停分析/收评/涨停分析/桃哥小节), 任何 skill 需要"那天
早上怎样/下午怎样/全天态势/涨停个股/板数"等信息时**先查 md, 查不到再爬外部**——
md 是已清洗的一手语料, 重复爬取既慢又丢"当时锚点"。

立法(2026-09-28 用户三轮修正):
1. **事实包必须含"市场扫描"段**(确定性代码生成, 不许只喂遗留票), 三层**并列采集**:
   板块层(竞价涨跌幅榜/异动)、资金惯性层(妖股辨识度/资金惯性思考方向——此层
   数据源有二: ①distill 沉淀的规则/persona ②**md 的涨停分析小节=惯性
   妖股速查库**(9/28 用户确认设计意图: 每笔记板数/题材/时间就是在积累妖股履历,
   同一题材每年的 top 妖股会换, 但"题材→历史妖股→辨识度排序"总能推导), 不靠
   脚本现算)、惯性个股层(惯性方向下
   的特殊品种/惯性炒作个股); 辅以竞价异动榜(高/低开 Top N)、当日"竞价看龙头"
   类电报全文、昨日跌停/大跌榜、近端次新区间跌幅榜。扫描脚本 2026 国庆假期做
   (走东财 push2/腾讯排行, 防封铁律同 quote.mjs: 多源+抖动+失败闭环)。
   **→ 已落地=`scripts/scan.mjs`(2026-10-01; 10/2 从 plan-a 抢救回根目录)**: 六榜(涨跌幅/跌幅/连板梯队/跌停/
   次新区间跌幅/板块), 东财 push2 clist(主)+新浪 getHQNodeData(备, 涨跌榜双源);
   腾讯排行已死(302→空 data, 实测勿再试); 连板/跌停池/次新/板块=东财单源+失败闭环;
   已接入 run_taoge_chain.py facts 组装。
   **权重不硬编码进采集层**(高内聚低耦合, 9/28 用户"再考虑下"后修正): 采集层只
   负责采全, 哪层先行归 02 分析环节的市况三态判定——有主线市: 板块层先行(板块
   指明方向); 无主线/退潮/普跌市: 资金惯性层先行(老妖/辨识度/错杀低吸), 板块层
   降级为回避清单+防御确认。(9/28 实证: 竞价板块榜全是血制品/银行/物业纯防御,
   桃哥实际注意力全在惯性层——沈鼓/次新/津药; 固定"板块权重最高"在退潮日失效)
2. **04 候选池两组**: 遗留票组(昨日语境) + **桃哥选股方向组**(persona/rules
   拟人生成)。方向组输出=**必填推导链, 不许整组暂缺**(9/28 用户定: 基于已有
   沉淀至少总能推导得到):
   `方向 → 板块 → 细分概念 → 大票/小票 → 个股`, 每一环带三件套——**证据锚**
   (沉淀 md/persona 出处)、**失效条件**(什么信号证伪此环)、**置信度**;
   推不出个股也要推出方向+板块, "暂缺"只允许挂在具体断链步骤上并写明缺什么。
   无证据硬凑的个股 = 学偏, 禁止; 单样本推导不进 rules.md, 标"样本1, 待验证"。
   两组列齐才允许空仓终裁; 候选池只有遗留票就判空仓 = 违规输出。
   (9/28 实证: 方向=弱市防御+老妖抱团(distill 9月缩量定调) → 板块=医药(防御
   +题材寿命) → 大小票=缩量只拉得动小票 → 个股=津药药业(4月13天8板总龙头=
   医药最高辨识度 + 9/14 三天2板资金记忆再激活 + 缩量回踩 MA20/60 粘合 8 天)
   ——盘前可推导入池, 涨停与否是资金选择, 候选池不赌单票)
3. **盘中信号触发重跑**: 终裁写的动手信号若被盘中行情命中(9/28 案例: 终裁信号一
   =沪指破 -1.5%, 当日实际 -1.67% 命中, 但无人重跑), 必须在盘中节点重跑决策链。
   本 skill 定位就是"盘中任意节点可触发", 盘前一跑定全天 = 用法错误

**多空辩论纪律(2026-09-28 用户定, 防"每天空仓")**: 03 辩论必须分出高下并给出
决定性理由, **禁止 TradingAgents 式多空各说各话、和稀泥收场**; 证据确实平衡时,
裁决跟随当日市态下的先行层方向(有主线=板块层, 无主线=资金惯性层)给最小试错仓,
不许把"分不出高下"当空仓通行证——风控可以压仓位, 不能习惯性清零决策。

## 更新纪律(立法)

1. **画像从沉淀持续更新**: 每次读取新语料(results/bilibili 逐字稿、md 桃哥小节)后, 若发现与画像冲突或画像缺失的证据, 更新对应文件。
2. **每条结论必须带证据**: 引原文短句+出处(文件名/日期/BV号)。禁止无出处的"正确的废话"。
3. **更新时带日期和出处**: 在条目上标注出处; 修改已有结论时在文件头部"修订记录"追加一行: 日期/改了什么/依据。
4. **置信度显式标注**: 样本不足的维度(如熊市情绪反应)必须写"样本为零/不足, 待补", 不得用震荡市样本外推。
5. **对抗式维护**: 发现反例(桃哥自己打自己脸的操作)优先记录, 反例比正例更能校准画像。
6. **语言指纹只信原声**: language.md 的例句优先取 results/bilibili 逐字稿(ASR 原声), md 二手解读只作补充; 注意 ASR 同音错字(利空出境=利空出尽、载油实测=载入史册), 引用时按原样保留并在首次出现处注音释。
