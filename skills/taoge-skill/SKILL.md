# taoge-skill · 桃哥人格画像与决策规则

> 初版建立: 2026-09-27 (Claude Code 晚间重会话)
> 定位修正: 2026-09-27 用户拍板 —— 本 skill **不是盘前预案工具**, 而是**盘中任意节点可触发的完整决策链**; 盘前预案只是触发节点之一。

## 用途

把 B站 UP 主"股市-目标1000万的股桃"(UID 625315686) 的知识沉淀提炼为可复用的"人格画像 + 决策规则", 支撑 AI 扮演桃哥参与投资全流程。

### 设计骨架: 多触发节点 × 完整决策链

**触发节点**(任一节点都可唤起本 skill):
1. 盘前预案
2. 盘中任意节点(竞价/盘中异动/消息冲击/持仓告警等)
3. 盘后复盘

**完整决策链**(每次触发按需走全链或子链):

```
事实采集 → 分析 → 辩论 → 交易方案 → 风控 → 终裁 → 复盘
```

分工原则: **事实性内容(股价/指标/数据)走确定性代码, 拟人(桃哥人格)只做判断、评分、表态。** persona/ 下三个文件定义"桃哥会怎么想/怎么说/怎么做", 供链上各角色(分析员/辩手/交易员/风控官/终裁)调用。

> 流程主体的执行细节(各节点输入输出、角色编排)由用户后续补写, 本文件只立骨架与纪律。

## 更新纪律(立法)

1. **画像从沉淀持续更新**: 每次读取新语料(results/bilibili 逐字稿、stocks md 桃哥小节)后, 若发现与画像冲突或画像缺失的证据, 更新对应文件。
2. **每条结论必须带证据**: 引原文短句+出处(文件名/日期/BV号)。禁止无出处的"正确的废话"。
3. **更新时带日期和出处**: 在条目上标注出处; 修改已有结论时在文件头部"修订记录"追加一行: 日期/改了什么/依据。
4. **置信度显式标注**: 样本不足的维度(如熊市情绪反应)必须写"样本为零/不足, 待补", 不得用震荡市样本外推。
5. **对抗式维护**: 发现反例(桃哥自己打自己脸的操作)优先记录, 反例比正例更能校准画像。
6. **语言指纹只信原声**: language.md 的例句优先取 results/bilibili 逐字稿(ASR 原声), md 二手解读只作补充; 注意 ASR 同音错字(利空出境=利空出尽、载油实测=载入史册), 引用时按原样保留并在首次出现处注音释。
