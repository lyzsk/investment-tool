## 五闸门(立法, 每条规则的准入审查)

1. **欠定承认**: 同一笔操作有多个自洽故事 → 每条推断至少并列 **2 个竞争性假设**, 不收敛单一叙事
2. **证据链三环**: 操作记录 → 当时正股/板块/大盘状态 → 同类先例; 缺一环降级"弱猜测"
3. **置信度三级**: `统计事实`(可计数) / `强推断`(≥3 个独立样本同模式) / `弱猜测`(<3, 标"待证伪")
4. **可证伪条款**: 每条必须写"未来出现什么操作会推翻它"; 写不出证伪条件的不许进本文件
5. **反例优先**: 他违反自己规则的操作优先记录——反例比正例更能校准画像

## 规则格式(模板)

```markdown

### R<n> <一句话规则名>

- **规则**: 给定情境 X, 他倾向做 Y
- **置信度**: 统计事实 / 强推断 / 弱猜测
- **竞争假设**: 假设A(当前主选, 证据…) | 假设B(未排除, 证据…)
- **证据链**: <日期+操作> × n 条, 每条带当时行情状态
- **证伪条件**: 若未来出现 ___ 操作, 本条作废或降级
- **验证状态**: [待验证] / [样本 n] / [已回测]
- **反例**: (有就列, 没有写"暂无")
```
