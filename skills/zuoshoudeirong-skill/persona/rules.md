### R9 持仓当日盘中冲高≥+6% 即当日清仓, 不论已持天数与浮盈(补 R1) [画像]（10/18 历史全量挖掘新增）

- **时间状态**: 建立 2026-10-18 · 最后验证 2026-10-14 · 状态 活跃
- **规则**: 当持仓票当日盘中最高 ≥+6% 时, 他当日清仓 74%(n=34: 清仓 25 / 减仓 2 / 持有 7; 全部持仓日基线清仓 55%); 叠加"持 1 天"升到 92%(n=25), 叠加"平开±2%"为 100%(n=10), 叠加"昨收浮亏 0~10%"为 89%(n=27)。卖出时刻 上午 13 / 开盘5分钟 7 / 尾盘 3 / 午后 3; 清仓后次日均 +2.1%(n=25)。R1 只讲 T+1 触板即卖/早盘兑现, 本条把触发扩到任意持有天数、未触板的 +6% 冲高, 且覆盖昨收浮亏的仓(冲高即离场)
- **口径警示**: ① "浮亏 0~10%"箱含大量"涨停价买入、收盘仍封板"的 T+1 仓(浮盈显示 -0.0%), 组合项 27 笔里真正浮亏的有几笔材料未拆; ② 卖出时刻≠冲高时刻——10-14 博纳 14:15、10-08 福建水泥 14:52 都是冲高回落后才卖
- **证据链**: hold_mining 单项「盘中=盘中最高≥+6%」条 + 组合「持1天×盘中最高≥+6%」「浮亏0~10%×盘中最高≥+6%」「平开±2%×盘中最高≥+6%」三条; 例 10-09 上海洗霸(开 +0.0 / 高 +10.0 / 收 +9.6, 持 1 天, 09:42:06 清, 次日 +0.2)、10-14 博纳影业(开 -3.8 / 高 +6.9 / 收 +1.6, 浮盈 -3.5%, 持 2 天, 14:15:10 清, 次日 -8.2)
- **竞争假设(合计 100%)**: A 主动出场规则"冲高就走, 不赌收盘"——若成立应见卖腿多贴近日内高点 **35%**; B 与 R1 是同一现象——冲高日多为 T+1 打板溢价日, 本条只是换了切法(持1天组合 92% 支持) **45%**; C 其他/证据不足 **20%**
- **证伪条件**: 10/18 后新增 ≥10 个"持仓日盘中最高≥+6%"中当日清仓 <55% → 作废
- **验证状态**: [样本 34 · 时间外通过(清仓 78%, n=18, 基线 60%)]; 组合项 [样本 25 / 27 / 10 · 时间外通过(89% n=9 / 86% n=14 / 100% n=6)]
- **消费警告**: 他冲高后常拖到午后回落才卖, chain 跟本条时以"冲高≥+6% 当时"为卖点, 不抄他的实际卖腿时刻

### R11 大盘低开日(≤-0.5%)他多半不动持仓, 而持有后次日平均再跌 [画像]（10/18 历史全量挖掘新增）

- **消费警告**: 持有后次日均 -1.7%, 不动并没有换来反弹; 10/25 改: 提醒——模拟他照做(不动), 但不要把它当成有收益的纪律

### R12 持仓拖到第 2~3 天时减仓概率升高(补 R2) [画像]（10/18 历史全量挖掘新增）

- **时间状态**: 建立 2026-10-18 · 最后验证 2026-09-30 · 状态 活跃
- **规则**: 当持仓已持 2~3 天时, 他减仓 18%(n=22: 清仓 5 / 减仓 4 / 加仓 1 / 持有 12; 基线减仓 6%), 卖出时刻 尾盘 3 / 午后 1 / 上午 4; 减仓后次日均 -3.2%(n=4), 即减对了的多。同一情境持有也占 12/22, 说明拖过 T+1 后他转入"分批处理/继续拿"而不是一笔清(与 R2 拖延同源)
- **口径警示**: 减仓=收盘仓位降 >8pp。三个例子里 05-14 方正科技(R4 反例: 05-18 才卖掉剩下的 100 股)、08-18 天洋新材(R1 表: 买 3700 卖 3600)都是"卖掉几乎全部、留 100 股尾巴", 09-30 福建水泥是 R7 的"低吸新批卖旧批"——"减仓"有相当部分可能是零股残留或换批, 不是主动分批
- **证据链**: hold_mining 单项「持有天数=持2~3天 → 减仓」条; 例 08-18 天洋新材(开 +10.0 / 高 +10.0 / 收 -4.8, 浮盈 +10.0%, 15:00:00 卖, 次日 -10.0)、05-14 方正科技(开 +0.1 / 高 +1.0 / 收 -7.0, 浮盈 -0.8%, 14:11:07 卖, 次日 -5.3)
- **竞争假设(合计 100%)**: A 真分批减仓——拖过 T+1 后先卖大头、留观察仓 **25%**; B 口径假象——零股尾巴/换批被记成减仓 **50%**; C 其他/证据不足 **25%**
- **证伪条件**: 机械层剔除"减后剩余 ≤100 股"和"同日同票买新批"两类后, 持 2~3 天减仓率 ≤ 基线 6% → 作废
- **验证状态**: [样本 22 · 时间外通过(减仓 6%, n=16, 基线 2%)](时间外绝对值很低, 只是方向一致)

### R13 加仓只加弱势仓: 持仓不涨、已拖 ≥2 天时在下跌中补(补 R2/R7) [教训]（10/18 历史全量挖掘新增）

- **时间状态**: 建立 2026-10-18 · 最后验证 2026-09-30 · 状态 活跃
- **规则**: 当持仓票当日盘中最高 <+2% 时, 他加仓买入 25%(n=24, 基线 10%); 已持 2~3 天时 18%(n=22)、已持 4 天+ 时 19%(n=16)。加仓那一刻票的当日涨跌(挖段 n=8): 跌≥3% 50% / 跌 0~3% 38% / 涨≥3% 12%; 加仓前浮盈: 浮亏 0~10% 75% / 浮盈 0~10% 25%——即左侧摊低, 不做右侧确认加仓。fingerprint 六"同票加仓 2 次"假设分布: 拆单分批≈34% / 左侧摊低≈28% / 右侧确认≈21%
- **口径警示**: hold_mining 加仓买入 = 昨收已持有的票当日又有买入(共 10 次), fingerprint 的"同票加仓"= 首笔 5 分钟后同日加仓(2 次), 两个口径不同不能合并; 若昨收只剩 100 股尾巴(见 R12), 次日买回会被算成"加仓"(疑似 08-20 天洋新材低吸, R2 记为非涨停价买入), 实为 R6 回锅
- **证据链**: hold_mining「建仓侧 · 加仓买入」节(加仓时涨跌 / 加仓前浮盈 / 什么情境下更常加仓三条); 例 09-30 福建水泥(09-28 打板买入, 09-29 竞价跌停不动, 09-30 开 -3.2 低吸新批后 11:03:28 卖旧批 6400@7.03; 浮盈 -4.7%, 已持 2 天; 见 R7、O3)
- **竞争假设(合计 100%)**: A 摊低成本等回本(处置效应, 与 R2 假设 A 同源) **35%**; B 做 T 换批——低吸新批是为了当天卖旧批, 不是增加敞口(R7) **30%**; C 口径假象(零股尾巴次日回锅) **15%**; D 其他/证据不足 **20%**
- **证伪条件**: 10/18 后新增 ≥5 次加仓买入中, 加仓时当日涨≥3% 的 ≥3 次 → "弱势摊低"作废
- **验证状态**: [事件 10 · 情境三项时间外通过(盘中最高<+2% 6% n=17 / 持2~3天 6% n=16 / 持4天+ 25% n=4, 基线 4%)]; 价位与浮亏子句 [小样本 n=8 · 时间外样本不足(n=2)]
- **消费警告**: 本条是偏差, 与 R2"亏损仓拖延"叠加放大亏损; 10/25 改: "不得抄"→提醒(他本人会这样加, 模拟他照做, 附本条分布)

### R17 卖在冲高途中: 卖价在当日区间中上部, 很少挂涨停价等板(补 R1) [画像]（10/18 历史全量挖掘新增）
