# 银行股 skill · 品种画像

## 定位与逻辑(手写, 10/18; 用户观点 + 数据检验)

- **长持选股(10/18 晚裁决: 中国银行 601988; 用户倾向工行, 原选农行)**: 买银行的目的 = 底仓稳健增长 + 日内 T 降成本。2018-07~2026-10 日线(收益含分红)对比:

  | | 工行 | 农行 | 交行 | 建行 | 中行 |
  |---|---|---|---|---|---|
  | 年化 / 8 年 | 11.3% / +141% | 15.1% / +216% | — / +126% | — / +165% | 14.2% / +198% |
  | 最大回撤 | -20% | -29%(2025-11→2026-07) | -26% | -22% | **-17%** |
  | 滚动 1 年: 最差 / 为正占比 | -15% / 66% | -12% / 70% | | | **-10% / 80%** |
  | 上证 ≤-1.5% 日: 自身中位 / 跑赢上证 | -0.81% / 92% | -0.87% / 93% | -0.86% / 92% | -1.04% / 85% | **-0.64% / 96%** |
  | 三段上证熊市(上证 -15/-19/-27%) | -7/-13/+26% | -2/-11/+52% | +1/-18/+54% | -10/-15/+27% | **-1/-10/+63%** |
  | 自身跌 ≥1.5% 后 5 日收益中位 | -0.14% | +0.44% | | | **+0.55%** |
  | 做 T 空间: 近 1 年日内区间中位 / 熊市段 / 机械两腿成交 | 1.72% / 1.12% / 13% | 2.07% / 1.09% / 13% | 1.64% | 1.91% | 1.91% / 1.08% / 13% |

  - 裁决理由: 按"底仓稳健增长"这个目的, 中行在回撤、最差一年、大跌日、熊市段、跌后修复 5 项全部第一; **做 T 空间和工行基本打平**(不能说中行 T 得比工行好), 所以胜负在底仓不在 T。农行收益最高但回撤最深、离高点 -13%, 不符合"稳"。
  - 不确定: 只有一条 8 年路径; 中行熊市三段 +63% 很大一块是 2023 "中特估" 股息重估, 不一定重演; 估值抬高后股息率下降。工行 / 中行差距是"中等"不是"压倒"。招行(股份行)熊市三段 -37%, 和沪深 300 一样跌 → 护盘只护国有大行。
- **护盘属性(用户观点)**: 银行 / 保险 / 证券是国家队护盘手段, 上证长期 3000 点附近, 牛转熊时银行会被护。
  - 数据检验见上表和下方 ④: **跌得比指数少、熊市段明显抗跌 = 成立; 不等于不跌**(用户 10/18 亦确认"大盘跌不代表银行不跌"; 大跌日中行当天收涨只有 16%)。
  - 反方: 证券是高弹性品种, 不放进本 skill; 2023 起大涨主要来自股息重估 + 险资 / 国家队配置, 涨幅不能外推。
- **对做 T 的含义**: 大盘大跌日银行相对抗跌、常被拉 → 大跌日的低吸单比平时更容易做成正 T; 大盘普涨的情绪日银行常跑输(资金去追弹性) → 适合反 T 先卖。
- **成本(用户券商实收, 10/18 从 9/28 成交单核出)**: 每笔最低 5 元(佣金+其他费用合计 5.00, 不免五) + 卖出印花税 0.05%。按 1 万做 T、底仓约 5000 元: 1/3 档一笔约 1500 元 → 来回约 0.7%; 全档约 5000 元 → 来回约 0.25%。**小档位费用吃掉大半振幅, 规模档要往大了做或者干脆不做**。T+1, 当天买入不能卖, 正 T 的卖出要用底仓。
- **除权**: 每年分红除权日价格会下跳(股息), 不是跌; 振幅统计用 close/pre_close 已经剔除。
