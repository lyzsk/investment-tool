# 银行股 skill · 每周复核(distill)

> 频率: 每周末一次(LLM, 一次调用); 输入 = persona/cases.md 全部日卡 + rules.md + profile.md 数据画像 + t_knowledge.md。
> 产出: 改 rules.md(每条更新 时间状态 / 证据; 新规则样本 ≥2 才进; 被日卡反驳的标 已否定 不删), 并在 cases.md 顶部写一行本周结论。

步骤:
1. 统计本周日卡: 事后最优是正T 还是反T 的天数; 决策T 做对方向的天数; 决策T vs 机械T vs 不T 的累计净值差
2. 对每条规则: 找支持和反驳它的日卡(写日期), 更新证据和时间状态
3. 找日卡里反复出现、规则没覆盖的情景(≥2 次)→ 新规则草稿, 标 `[画像]`, 跑满下一周再决定能不能升 `[可跟]`
4. 只改本 skill 文件, 不碰导师 skill
