# 盘前预测工作流 v2（多因子版）

触发口令：「盘前预测」「竞价怎么样」「盘中 xx」「盘后复盘」「周复盘」。
归档：investment-tool/strategy/yyyyQx/yyyy-MM-dd/yyyy-MM-dd-predict.md（三级：季度文件夹 → 当日文件夹 → 当日全部文件 md+png 都放当日文件夹里）。
画图：scripts/draw_predict.py（盘前三情景）/ draw_intraday.py（盘中实测vs剧本）/ draw_today_kline.py（日K预测）/ draw_minute.py（分时+推演）/ draw_predict2.py（多股三情景），matplotlib + 微软雅黑，Y轴左百分比右价格。

- 期货情绪（2026-08-25 用户要求加入）：hq.sinajs.cn/list=hf_NQ（纳指100迷你期货 NQ00Y）、hf_CHA50CFD（富时A50期货 CN00Y）——A50 竞价前看方向，NQ 看隔夜美股盘中情绪
- 历史题材：stocks/ 每日涨停 md + strategy/data/backtest_full.json（妖股惯性回测）

## 权重纪律（2026-08-25 用户明确）
**本 skill 的因子框架只占总判断的 5%-10%**（策略刚启动、样本太少，规则可信度低）。主要判断必须来自当日实时数据+更广义的盘面推理；因子规则仅作轻量先验。命中样本积累到 20+ 个交易日后再逐步提权。

## 预测因子框架 v2（2026-08-24 复盘后修正，权重按此排）

1. **事件冲击（最高权重）**：巨型 IPO 分四节点定价——受理日=相关ETF/板块情绪冲击 **-2~-4%**（8/24 长存330亿受理→588200 收-3.67% 实锤）；招股启动=业绩狂欢（长鑫 7/9 +9.2%）；申购缴款周=真吸血（长鑫 7/10-7/17 约-25%）；上市日=再砸一波。政策/行业催化同理分级。
2. **外围同板块**：海外同板块龙头跌>3% → A股同板块低开概率×1.5（权重高于大盘指数）。大盘指数（日经/纳指）只做背景。
3. **竞价校准（受限）**：竞价对盘前概率的修正**上限±10%**；9:15-9:20 可撤单阶段价格软，情绪日里竞价平开**不能**推翻"外围+事件"的双空/双多组合。**竞价"强势"更不可信（8/25 实锤）**：可撤单期的涨停竞价/高开>3% 多为虚单（上海洗霸涨停竞价开→收-0.51%，湖南白银+3.66%开→收-5.85%）。短线买入依据只认 9:25 定格后的竞价，且只作开盘后参考，绝不竞价跟单。
4. **板块先锋/跟风强度比**：先锋涨停而跟风弱（涨幅<先锋一半或冲高回落）→ 跟风股当日大概率高开低走，不买不加仓（8/24 ST天际案例，正确）。
5. **均线关键位**：MA120/年线等大级别均线是真实支撑但**会被刺穿**（8/24 刺穿1.1202至1.110收回1.130）——挂买单放均线上能成交，止损需留刺穿余量（约-1%）。
6. **尾盘修复**：非恐慌日里，午后低点→14:30后尾盘修复概率>50%（8/24 牧原 -1.9%→-0.6%）。恐慌日（放量+板块崩）不适用。
7. **量能定性**：放量下杀（量增>30%）→ 次日低开/还有低点；缩量阴跌→企稳；缩量反弹→不可信。
8. **外围利空按时间衰减（8/25 验证）**：隔夜外围暴跌（费半-4%级）主要压制开盘30分钟，日内由本土流动性/事件接管（8/25 588200 低开-1.5%后翻红+0.44%；午后拉升催化=中美1.5轨对话，午间12:02电报）。外围冲击权重：开盘40%→午盘10%。
9. **昨日强势板块延续性（8/25 复盘）**：昨日全天强势板块（涨停潮级）次日延续概率高，震荡避险市尤其明显（农业案例：牧原+2.4%超预期）。盘前预测时对"昨日最强板块"的持仓给更高乐观概率。
10. **埋伏仓 vs 趋势仓的止损纪律（8/25 用户纠正，重要）**：对已设硬止损的埋伏仓（如ST题材），日内**不再增设更紧的盘中减仓线**（会卖在最低点）；硬止损线才是唯一纪律，且价格**逼近硬止损线反而是赔率最佳的加/抄点**（风险=到止损的距离，如天际17.18买/17.0止损=风险1%对上方+11%）。唯一纪律：①收盘前能否收复关键位 ②收盘破硬止损必须走。
11. **巨头财报映射（8/27 新增）**：英伟达/台积电等海外巨头财报超预期 → 次日 A 股对应产业链（算力/半导体/光模块）高开高走概率大，权重高于普通外围情绪；财报前夜要单独评估持仓相关板块。
12. **企稳后爆发（8/27 新增）**：关键均线缩量企稳 + 新催化 → 次日爆发力大，乐观概率上调至 40%+（8/27 588200：基准给+1%实际+3.66%，基准太保守）。

## 午间刷新节点（8/25 确立）
**12:15 前后主动查一次 cls_telegraph 午间新闻精选**——午盘开盘前的二次盘前预测（8/25 午后拉升的催化"中美1.5轨对话"12:02 已发布，13:00 才反应到盘面，早报早占先）。

## 输出规范
- 永远三情景（基准/乐观/悲观+概率），不给单一结论；关键价位精确到支撑/压力/止损。
- 盘中建议只做"条件触发"式（到X价做Y，破位停手），不喊追涨杀跌。
- 盘后复盘必填：实际 vs 三情景、打分（A~D）、错误归因、新因子提炼→更新本 skill 的因子框架。
- 每周日「周复盘」：汇总5天命中率，调整因子权重。

## 坑
- 不要预测具体涨跌点位承诺，只给区间和概率。
- 画图前必须拉真实最新价（qt.gtimg.cn），禁止用过期价。
- 用户持仓/计划：见 strategy/ 当日 predict.md 的"背景"节；ST股止损线写死。
- 画图规则（2026-08-25 用户纠正后修正）：**Y轴必须自适应实际数据范围**（含标记线+推演末端，上下留15%余量），禁止写死 ylim 导致走势顶出图外；**推演路径禁止固定均值回归偏见**，必须三路径动量自适应（A趋势延续=近30分钟斜率阻尼外推 / B收敛均价 / C反向极值），强势股的推演必须包含继续上涨的路径。
